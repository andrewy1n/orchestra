## Description

Fix review finding `rec-7b48bc63` (spec-gap, R1) and `rec-083ab868` (spec-gap, R13). `skills/execute-phase/SKILL.md` names `agents/se-reviewer.md`, which sits outside the skill directory, and the repo carries two divergent definitions of the same reviewer agent. Make the skill self-contained and the canonical prompt the only authored source.

## Approach

- Add `skills/execute-phase/references/se-reviewer.md` generated from `agents/reviewer.prompt.md` by `scripts/build_skills.py`, and change the skill to reference `references/se-reviewer.md` (or describe dispatching the host agent plus the local prompt fallback) without naming an external `agents/` path.
- Make `agents/reviewer.prompt.md` the sole authored reviewer prompt. Either remove `agents/se-reviewer.md` or generate it from the canonical prompt with a drift check, while keeping Claude/Cursor plugin installs working.
- Extend `tests/test_skill_portability.py` to reject bare `agents/...` paths that leave the skill directory.
- Extend `tests/test_agent_generation.py` to prove `agents/se-reviewer.md` matches the canonical source (or is absent and generated).
