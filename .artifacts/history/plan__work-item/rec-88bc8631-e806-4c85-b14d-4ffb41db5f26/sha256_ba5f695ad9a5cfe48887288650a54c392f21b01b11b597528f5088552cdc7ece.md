## Description

R2: Modules under `dashboard/` open the store by calling `adaptive_artifacts.project.open_store`.

## Approach

`dashboard/bin/dashboard` and `dashboard/bin/web` exec `uv run --script` on `dashboard/__main__.py` and `dashboard/web/__main__.py`. Those PEP 723 blocks list textual, or fastapi/uvicorn/textual, and the resulting environment cannot import `adaptive_artifacts`. Make the environment `uv run --script` creates for both scripts able to import `adaptive_artifacts.project`. Keep the launcher argv as `uv run --script`. Do not edit `tests/test_orchestra_callers.py`. Do not change `orchestra/close_batch.py`.
