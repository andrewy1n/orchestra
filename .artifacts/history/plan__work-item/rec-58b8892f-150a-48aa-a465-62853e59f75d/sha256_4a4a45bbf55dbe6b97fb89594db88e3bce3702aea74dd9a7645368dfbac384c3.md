## Description

Add `scripts/dashboard_model.py` (stdlib only). It calls `adaptive-artifacts list` through `artifact_store` and builds, per live effort: the goal; each phase with ordinal, title, state, and done/total task counts; task rows (running, ready, waiting, done, withdrawn) with title, phase, assignee, and wave; needs-you items (open blocking and non-blocking questions, needs-human findings, unsigned manual check-runs that are not corrected); and recent activity (assignments, execution-reports, check-runs from the last 24h, newest first). A change token lets callers detect store changes.
