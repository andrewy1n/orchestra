## Description

Fix the apply regression that blocked the phase review.

R19: `Project.apply` persists each operation in the given sequence and returns each result.

The command's apply NDJSON verbs at the phase base are create, update, supersede, correct, and contradict. At 206fcd0, Project.apply and cmd_apply accept only create and update.

## Approach

Make Project.apply accept those five verbs and persist each one, with the same continue-and-report behavior as the previous command: one bad line does not abort the others. cmd_apply keeps calling Project.apply. The dedicated update, supersede, correct, and contradict commands stay in the command module. Do not edit tests/test_open_store.py, tests/test_project_ops.py, or tests/test_command_facade.py.
