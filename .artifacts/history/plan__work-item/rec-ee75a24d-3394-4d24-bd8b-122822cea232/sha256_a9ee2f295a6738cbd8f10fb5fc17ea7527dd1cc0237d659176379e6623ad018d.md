## Description

Prove the phase exit criteria hold together: both skills name the same landing, and each skill's own checks pass.

## Approach

Add `tests/test_phase_landing.py`. It reads `skills/plan-phase/SKILL.md` and `skills/execute-phase/SKILL.md` and asserts both contain branch `phase/<phase-slug>`, worktree `<repo-parent>/<repo-name>--<phase-slug>`, base `main`, merge into `main`, the store commit on the primary checkout, and push only as a human stop.

Run:

`python3 -m pytest tests/test_plan_landing.py tests/test_execute_landing.py tests/test_phase_landing.py -q`

Do not edit the two skill files in this task. Those belong to `plan-landing-rules` and `execute-landing`.
