## Description

Fix review finding `rec-615efcde` (invariant-violation, R6/R7). Skills still name importable module APIs (`orchestra.reviewer.build_reviewer_brief`, `orchestra.suite.load_suite_policy` / `start_suite_background` / `poll_suite` / `collect_suite` / `record_suite_check_run`, and `orchestra.aa`) that the CLI does not expose, so a `uv tool install` has no documented invocation from a work repo.

## Approach

- Inspect the exact call sites in `skills/execute-phase/SKILL.md` and `shared/ensure-store.md`, and the functions in `orchestra/reviewer.py`, `orchestra/suite.py`, and the `orchestra.aa` target.
- Add CLI subcommands that wrap them: at minimum `orchestra review-brief`, `orchestra suite` (`policy`, `start`, `poll`, `record` as needed), and whatever `orchestra.aa` does (for example `orchestra store ensure`).
- Rewrite the skill and shared references to call the named commands, never modules or checkout paths.
- Add `tests/test_cli_surface.py` proving each new command’s `--help` and a smoke call, and add a `runtime` selector in `tests/test_skill_portability.py` that fails on `orchestra.<module>` API references.
