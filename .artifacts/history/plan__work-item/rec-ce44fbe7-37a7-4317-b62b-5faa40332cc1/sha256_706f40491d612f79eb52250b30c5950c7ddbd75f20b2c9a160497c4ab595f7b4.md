## Description

R3: For a non-empty `claim`, close invokes verdict at the green revision.
R4: For a non-empty `claim`, close invokes recheck for that claim.
R5: When verdict fails and recheck passes, close refuses and the error names verdict.
R6: When recheck fails and verdict passes, close refuses and the error names recheck.
R7: When verdict and recheck both fail, close refuses and the error names verdict and recheck.

## Approach

In `orchestra/close_batch.py`, change `_run_aff_claim_gate` to run `run_verdict(cwd, revision, None, [claim_id])` and `recheck(cwd, claim_id)` independently. Collect the clocks that raise or return a non-pass result; raise one `CloseRefused` naming every failed clock (`verdict`, `recheck`, or both) with the claim id. Keep the missing-import refusal that names affidavit. Update the claim-gate tests in `tests/test_close_batch.py` for verdict-only, recheck-only, and both-failing messages. Do not edit `tests/test_claim_clocks.py`.
