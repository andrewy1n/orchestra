## Description

R8: `open_store` raises when the contract `format` is not a format this build lists as supported.

## Approach

In `adaptive_artifacts.project._open`, after `meta.json` exists, load the contract JSON that meta names and read `format`. The supported set is the strings this build writes: `adaptive-artifacts/project-design@0.3.0` and `adaptive-artifacts/resolved-contract@0.3.0`. Raise `StoreBindingError` for any other value, including `adaptive-artifacts/project-design@0.0.0`. Do not fall through to another store. Live stores open the resolved contract, so that format stays supported.
