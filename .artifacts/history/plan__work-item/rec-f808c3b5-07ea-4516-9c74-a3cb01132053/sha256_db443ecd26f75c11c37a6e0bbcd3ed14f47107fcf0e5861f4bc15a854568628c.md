## Description

Extend the phase-detail model with specification and design bodies, tab sets for structured vs simple phases, and a decision log with effort scope and superseded chains.

## Approach

1. Grow `load_phase_detail` to return `spec_body`, `design_body`, and `structured` from one list each for specification and design on the phase.
2. Add `tabs_for(detail)` returning the full or simple tab tuple per R1.
3. Add `load_decision_log(target, effort, phase, history)` grouping by phase ordinal and attaching superseded entries under successors (R7).
4. Cover with `-k phase_screen` model tests. Do not edit `app.py`.
