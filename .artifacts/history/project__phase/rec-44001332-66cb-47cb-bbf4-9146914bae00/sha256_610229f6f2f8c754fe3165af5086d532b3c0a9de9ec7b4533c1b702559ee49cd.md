## Problem

`uv tool install` puts each package in its own environment, and orchestra declares no dependencies. Cursor plugin install does not pull dependencies, so orchestra searches plugin roots and sibling checkouts for the `adaptive-artifacts` binary. The parked `version-compat-check` item asked for a `--version` string comparison, which is the command-line version of a missing dependency.

## Approach

Decide the installer details at settle-phase. The behavior is already chosen: the Python dependencies match the import graph. Plugin install places the same packages. Agents find the commands on `PATH`. `open_store` rejects a contract format this build does not understand.

## Exit criteria

Every acceptance on this phase passes. An integration check installs into a clean environment and runs `orchestra --help`, `adaptive-artifacts`, and a close that needs affidavit. A fixture store whose contract format this build does not understand fails to open.
