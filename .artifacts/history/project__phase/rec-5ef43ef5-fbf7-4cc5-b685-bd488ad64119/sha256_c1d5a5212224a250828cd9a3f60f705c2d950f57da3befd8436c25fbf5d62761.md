## Problem
Neither adaptive-artifacts nor affidavit ships a pyproject.toml. Install is plugin checkout + PATH symlinks. `uv tool install git+…@tag` and later PyPI need a proper package layout first—especially adaptive-artifacts, whose runtime still lives under `tools/` with sys.path hacks.

## Approach
Not yet scoped — discuss chooses between AA-first git+ install, dual-repo packaging, and wrapping the current layout without a real package move. PyPI publish may stay deferred.

## Exit criteria
Decide at plan-phase. At minimum: a documented install path that does not require a sibling checkout of adaptive-artifacts, verified by a real entry-point command against a throwaway or seeded store.
