## Problem

Phase detail is mostly prose sections across tabs, so structure (progress, requirements, next action, waves) is hard to see at a glance — and every tab feels like plain text.

## Approach

Give the phase overlay shared structured chrome on every tab: status chips, progress, next-action line, clickable requirements strip, and wave summary. Improve each tab's body UI (structured sections/lists/cards) while keeping tab roles distinct. Do not redesign the home/main left-heavy layout in this phase (discuss after). Decisions: `phase-overview-layout`, `phase-overview-requirements`, `phase-overview-home-layout-defer`.

## Exit criteria

- Shared structured chrome appears on all phase tabs, not only Overview.
- Requirements strip opens requirement overlays when present.
- Tab bodies use improved UI elements rather than bare prose-only dumps.
- Home/main layout unchanged (deferred).
- UI tests and a manual look pass.

## Proof

kind: demo

A human opens a phase overlay, switches among Overview/Spec/Tasks (or equivalent), and sees shared chrome plus improved content UI on each tab.
