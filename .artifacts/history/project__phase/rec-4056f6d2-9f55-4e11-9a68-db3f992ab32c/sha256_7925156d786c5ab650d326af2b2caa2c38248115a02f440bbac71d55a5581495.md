## Problem

Affidavit starts a new process to write evidence records. A source scan forbids the text `adaptive-artifacts` and `project:`, so those strings are built from pieces. Orchestra's close path learns affidavit's answers from exit codes.

## Approach

Decide the module layout at settle-phase. The behavior is already chosen: affidavit imports adaptive-artifacts, the source scan goes away, and `is_assertion_level_red`, `run_verdict`, and `recheck` are functions. The `aff` command stays a wrapper around them. Verdict still runs when the project has no artifact store.

## Exit criteria

Affidavit's tests call those functions and write a record through the store library, with no subprocess for that write. `aff --help` still lists the commands. Verified by the affidavit test suite. The cross-package close is proved later by `library-e2e`.
