## Problem

se-workflow requires adaptive-artifacts, but install is two separate marketplace adds with no declared dependency. Users can install se-workflow alone and hit missing-runtime failures. Each repo hosts a one-plugin marketplace.

## Approach

Shared marketplace hosted in the se-workflow repo (decisions: marketplace-topology, marketplace-host). List both plugins in `.claude-plugin/marketplace.json` (se-workflow as `./`, adaptive-artifacts via github source). Declare `adaptive-artifacts` in se-workflow `.claude-plugin/plugin.json` `dependencies`. Update README Claude install to one marketplace add; keep Cursor as clone/sync + PATH. Do not merge repos or rename to agent-affidavit in this phase.

## Exit criteria

1. Installing se-workflow through the se-workflow Claude marketplace also enables adaptive-artifacts (same-marketplace dependency) — verified by `claude plugin validate .` on the changed manifests plus a documented install dry-run checklist in the task notes or README.
2. README Install steps match the manifests (single marketplace add for Claude) — verified by reading the Install section against `.claude-plugin/*.json`.
3. Cursor install path remains documented without claiming Claude-only dependency auto-install — verified by README review.
