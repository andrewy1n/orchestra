## Problem

verify-budget removed the full suite from per-phase verification for cost. There is no regression gate at the phase head, and the phase gate does not require passes at that SHA.

## Approach

Decisions: tiered-verification-scope (tier-2 first; defer affected-test selection and flaky auto-retry), tier2-execution (background tmux in phase worktree). Structured work: specification and design `tiered-verification`.

Keep scoped per-task `verify_command` as tier-1. After verification + reviewer, run full suite once at phase head in background tmux; record tier-2 check-run; gate on head-SHA acceptance passes + tier-2; failures become retry-loop fix tasks; dashboard shows tier-2 status. Out of scope: testmon/path-map, CI-owned tier-2, approval UX.

## Exit criteria

- Background full-suite run at phase head records a tier-2 check-run; agent is not blocked for the duration.
- Phase gate requires head-SHA acceptance passes and passing tier-2 before merge.
- Tier-2 failure creates fix work-item(s) under retry budget (tests).
- Dashboard shows tier-2 status; skills/README/verify-budget tests updated; skill↔contract consistency green.
