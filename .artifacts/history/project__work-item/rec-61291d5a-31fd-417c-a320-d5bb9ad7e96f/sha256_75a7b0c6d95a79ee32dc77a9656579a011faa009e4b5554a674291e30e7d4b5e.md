## Description

R5: `orchestra install` into a clean environment leaves that environment able to import `adaptive_artifacts`.
R6: `orchestra install` into a clean environment without the evidence extra does not install affidavit.

## Approach

Add `installer/runtime_deps.py`. It reads the installed orchestra distribution's `requires()`, drops every requirement whose marker names the `evidence` extra, and runs `uv pip install --python sys.executable` on what remains. If that interpreter can already `import adaptive_artifacts`, skip the install so existing host-install tests do not hit the network. Never install the `evidence` extra. Do not read `ADAPTIVE_ARTIFACTS_BIN`, plugin-root variables, or search sibling checkouts.

Call it at the start of `installer.runner.run` unless the request is `list_only`, `dry_run`, or `uninstall`, and before host detection. Add no CLI flags.

The integration test creates a temporary virtualenv, installs this checkout's orchestra into it with `--no-deps`, runs that environment's `orchestra install` with `--home` pointed at a temp directory and `--non-interactive`, then asserts `adaptive_artifacts` imports, `affidavit` does not, and `orchestra --help` exits 0.
