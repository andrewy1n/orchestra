## Description

R2: The host prompt lists every provider in the matrix with its id, name, project detection status, and global detection status.

## Approach

Add `installer/detect.py` with a frozen `HostStatus` plus `detect_hosts`, `detected_ids`, and `installed_ids`. Build one adapter per provider and scope with `build_adapter`; call `BaseAdapter.detect()` against the project base (cwd) and global base (HOME). When `--home` is set, use that directory for both bases and do not read the real HOME. Return statuses in matrix order. Add focused tests in `tests/test_installer_wizard.py` that create project and global host directories, assert both labels and `detected_ids`, and assert `--home` never reads the real HOME. Keep detection read-only.
