## Description

Prove that uv tool install from the adaptive-artifacts git URL yields a
working CLI without a sibling checkout. Waits on the installable package
and shims.

## Approach

1. Add an integration script under ~/adaptive-artifacts (for example
   scripts/prove_uv_tool_install.sh) that installs from the git URL/ref
   into an isolated tool env.
2. From that install, run adaptive-artifacts --help and one
   store-touching command (init or validate) against a temporary
   store/contract.
3. Ensure the proof does not require a checkout on PATH; the installed
   entry point alone must work.
