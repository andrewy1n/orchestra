## Description

R1: On phase Overview, when a phase has three or more tasks, the UI shows a dependency graph laid out in columns by wave (left to right).
R2: Each graph node is a task in that phase and reflects status visually.
R3: Graph edges follow depends_on relationships among those tasks.
R4: Activating a graph node opens the task overlay for that task.
R5: A task list or wave strip remains available on Overview or Tasks so ready/running work is still scannable as a list.
R6: When a phase has two or fewer tasks, the graph is omitted.

## Approach

Add `buildWaveGraph(tasks)` and render an SVG/HTML wave-lane graph in the phase Overview (under shared chrome). Skip when tasks.length <= 2. Node click → taskHref. Keep Tasks tab / wave strip. Tests in taskGraph.test.ts.
