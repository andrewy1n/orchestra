## Description

R1: Running `orchestra install` with no host flags on an interactive TTY launches the host-selection wizard instead of selecting every provider.
R8: The wizard prints the full plan and asks for confirmation before writing.
R9: Declining confirmation exits without writing a host payload.
R10: `--list` prints the provider matrix with project and global detection and exits without writing.
R11: `--scope {project,global}` selects the install scope and conflicts with `--global`.
R12: `--interactive` forces the wizard when standard input is not a TTY.
R13: `--non-interactive` or `--yes` suppresses prompts; host selection uses `--only` or `--all` when given, otherwise detected hosts.
R14: With no host flags and no TTY, or with `--yes`, the installer selects detected hosts; if none are detected it exits 2 with guidance and writes nothing.
R15: Explicit `--only` and `--all` select exactly those providers and skip the host prompt.
R16: `--dry-run` with the wizard prints the plan and writes nothing without asking for confirmation.
R17: `--uninstall` remains flag-driven and never launches the wizard.

## Approach

Extend `InstallRequest` with `scope`, `list_only`, `interactive`, and `non_interactive`. Add `--list`, `--scope {project,global}`, `--interactive`, and `--non-interactive`/`--yes` to `orchestra/cli.py`; keep `--global` as an alias and reject `--scope` with `--global`. Map the arguments in `orchestra/install.py`.

In `installer/runner.py`, compute detection once with `installer/detect.py`. Short-circuit `--list` to print the matrix and write nothing. Determine `wants_wizard` from the TTY, `--interactive`, and explicit host flags. With no host flags and no TTY or `--yes`, use detected hosts, and exit 2 with guidance when none are detected. When the wizard runs, use `installer/wizard.py` to prompt hosts, scope, and mode. Build the plan, print it, and ask for confirmation before `apply`; `--dry-run` prints the plan and returns without confirmation. Preserve `--only` request order, `--all`, idempotency, and flag-driven uninstall.

Add focused subprocess tests in `tests/test_installer_wizard.py` for the TTY decision, plan and confirmation, decline, `--list`, scope, interactive, non-interactive, empty detection, explicit flags, dry-run, and uninstall. Add one real-entry-point integration test in `tests/integration/test_installer_wizard.py` that pipes wizard input through `python -m orchestra` and installs only the selected host.
