## Description

R31: The Vite dev server proxies /api to the FastAPI server.
R35: A fresh load of the page uses the light theme.
R36: A theme control switches the document between the dark theme and the light theme.

## Approach

- Create `dashboard/web/ui` as a Vite, Svelte 5, TypeScript, and Tailwind app. The npm `test` script is not required; acceptances call `vitest` through `npm exec`.
- Tailwind dark mode uses the `dark` class on `document.documentElement`. A fresh load leaves that class off. A theme control adds it and removes it. Dark colors follow the spike's `html[data-theme="dark"]` tokens.
- `vite` `server.proxy` forwards `/api` to the FastAPI port. Hash routes render an empty shell.
- Make the R31, R35, and R36 cases in `dashboard/web/ui/src/scaffold.test.ts` pass.
