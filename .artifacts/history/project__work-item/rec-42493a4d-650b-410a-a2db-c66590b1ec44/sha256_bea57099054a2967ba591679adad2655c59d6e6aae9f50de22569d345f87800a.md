## Description

R8: One installer accepts `--only`, `--all`, `--global`, `--copy`, `--dry-run`, and `--uninstall`.
R9: Re-running the installer leaves exactly one registration per selected host.
R14: The installer never copies `.artifacts/`, `.worktrees/`, or dashboard/store state.

## Approach

Add `installer/` with a provider matrix (`providers.toml` or `.json`) and an adapter protocol of `detect/plan/apply/verify/remove`. Wire `orchestra install` with the flags, a plan renderer for `--dry-run`, idempotent apply and remove, and an explicit copy allowlist (`skills/`, `contract/`, `hosts/<host>/`, `agents/`). Add `tests/test_installer.py` covering every flag, dry-run, idempotency, uninstall, and the copy allowlist. Host-specific behavior lands in the next task.
