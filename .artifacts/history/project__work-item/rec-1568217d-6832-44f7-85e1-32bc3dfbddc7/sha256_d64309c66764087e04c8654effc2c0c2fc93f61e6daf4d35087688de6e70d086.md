## Description

R7: `aff assertion-red` exits 0 when `is_assertion_level_red` is true.
R8: `aff assertion-red` exits 1 when `is_assertion_level_red` is false.
R9: `aff verdict` calls `run_verdict` without opening an artifact store to decide the gate.
R10: `run_verdict` returns a verdict for a repository that has no artifact store.

## Approach

Leave `is_assertion_level_red`, `run_verdict`, `recheck`, and the `aff` wrapper as they are. `run_verdict` does not open a store. Cover the assertion-red exit codes and a `run_verdict` call on a temporary repository that has a manifest and no `.artifacts` store. Do not edit `affidavit/observation.py`, `affidavit/binding.py`, or `tests/test_evidence_layout.py`.
