## Description

R5: When an acceptance names a claim id that exists in `.affidavit/manifest.json`, `orchestra close-batch` refuses transition `done` unless `aff verdict` exits 0 for that claim at the close revision.
R6: When an acceptance names a claim id that exists in `.affidavit/manifest.json`, `orchestra close-batch` refuses transition `done` unless `aff recheck` exits 0 for that claim.

## Approach

In `orchestra/close_batch.py`, detect manifest-backed acceptances (claim id present in `.affidavit/manifest.json` for the close cwd). Before allowing `done`, subprocess `aff verdict` at the close revision and `aff recheck` for that claim; non-zero → `CloseRefused`. Tests mock or fixture the `aff` binary so fail/pass of each verb is observable without a full Affidavit checkout dependency in CI.
