### Design / decisions (quote)

Invariants:
- Detection, `--list`, `--dry-run`, and a declined confirmation write nothing.
- Planning happens before any apply; a declined plan leaves the tree untouched.
- The selected scope and mode are visible in the rendered plan.
- `--only` preserves request order and `--only` plus `--all` remains an error.
- A second install with the same inputs is idempotent.
- `--uninstall` removes only entries named by a registration.
- `--home` redirects both detection bases and prevents reads of the real HOME.
- Existing host adapters and payload layouts are unchanged.

Assumptions:
- `sys.stdin.isatty()` and `sys.stdout.isatty()` are the interactivity signal.
- `--interactive` is available for tests and demos without a PTY.
- The project base is the cwd, the global base is HOME, and `--home` replaces both.
- A host is detected when its marker exists or any provider `detect` path exists at the base.
- A prompt EOF or Ctrl-C is a cancel, not an install error.
- The provider matrix's `detect` paths remain relative to the install base.

Decisions:
- `installer-detection-both-scopes`: `project-and-global` (alternatives: `selected-scope-only`).
- `installer-default-detected`: `detected-require-choice` (alternatives: `detected-native-fallback`, `all-providers`).
