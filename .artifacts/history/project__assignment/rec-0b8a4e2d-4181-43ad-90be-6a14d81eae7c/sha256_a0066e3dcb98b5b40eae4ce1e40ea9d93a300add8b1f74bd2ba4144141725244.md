Design invariants: A check-run records what happened; an assessment records what it means. Manual criteria never go through `check`. CLI is not a second store; it only shells to adaptive-artifacts. Parent session remains the authority that invokes the CLI and writes assessments.

Design assumptions: `payload_enum` enforcement already rejects illegal enum values at create time. Plugin packaging can expose `bin/se-workflow` similarly to `dashboard/bin/dashboard`. Subagents return evidence; the parent (or human) runs `se-workflow check` against the worktree.
