## Rationale

The tiles already carried the counts; making them tabs turns them into the filter the user actually needs. Active as the default keeps done work out of the way, so `d` is redundant.

## Counter-argument

A single tab filter cannot combine statuses the user might want together, such as ready plus needs-you.
