## Rationale

Hard authority and dirty-pass refusal only work if there is a commit to name. execute-phase today can defer commits to phase close, which is why task evidence is often dirty. Requiring a commit per task on the phase branch gives every intended pass a real SHA and matches the existing one-commit-per-task dashboard constraint spirit.

## Counter-argument

Committing only at phase close keeps the branch quieter and avoids noisy WIP commits. Passing evidence would then need dirty overrides or wait until close, weakening the runner's default.
