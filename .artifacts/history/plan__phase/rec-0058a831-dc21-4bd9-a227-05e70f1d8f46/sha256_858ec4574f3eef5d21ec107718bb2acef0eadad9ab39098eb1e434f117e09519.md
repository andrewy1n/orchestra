## Problem

Needs-you items stay visible after the human has already answered in chat, because skills open continuity-questions, needs:human findings, and unsigned manual checks but almost never clear them; only plan-review is answered on approval. The dashboard correctly mirrors open records, so the user has to tell an agent to close them by hand.

## Approach

Mixture of skill close rules and dashboard dismiss, same clear model:

- engage-remind: engage lists open human-dismissible Needs-you for the focus and reminds the agent to clear them when settled; it does not block routing.
- dismiss-human-gates: dashboard (and skills) clear only questions, needs:human findings, and unsigned manual checks — not merge, integration, or loop-route.
- dashboard-cli-writes: dashboard dismiss invokes adaptive-artifacts CLI, matching skill mutations.

Skills that open those gates document the matching clear. Spec and design live on this phase.

## Exit criteria

Skills close or clear human-dismissible Needs-you sources when the user answers them in an agent session; engage reminds without gating; the dashboard dismisses those kinds via CLI and refuses non-human kinds; skill-contract consistency and dashboard dismiss pilot tests pass.
