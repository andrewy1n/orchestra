## Problem

The store is visible only through the Textual dashboard in tmux. A browser spike under `spikes/web-dashboard` already renders the same model, but it is not part of the product.

## Approach

Decide in this discussion. Starting point is the spike: a stdlib HTTP server over `dashboard.model`, plus a no-build browser UI. The terminal dashboard stays until this phase chooses otherwise.

## Exit criteria

A person can open a local page and see the current store's efforts, phases, and tasks. The command that serves that page, and the check that proves it, are fixed once the approach is chosen.
