## Problem

After you pick an empty status tab, the task table loses focus: arrows do nothing and enter acts on the first row. Narrowing the window keeps the wide phase and assignee columns until the next reload.

## Approach

Refocus the table when a status tab change shows it again. Relayout columns on resize from the new width. Decide details at plan-phase.

## Exit criteria

A popup test picks an empty tab, returns, and moves the cursor with arrows. A popup test narrows below 90 columns and sees the narrow column set without a reload.
