## Problem

Each package's own tests can pass while a real close still starts another process, or while one package opens a different store than the others.

## Approach

**Generated temp repo** (`e2e-temp-repo`, `call-style`).

One orchestra integration test builds a temporary git repository with a local store and a manifest claim. It runs `adaptive-artifacts` and `orchestra close-batch` as commands, then calls the Python close and fails if that call starts `aff` or `adaptive-artifacts`.

## Exit criteria

R1–R6 in the phase specification hold. The integration test passes in an environment where all three packages are installed.

## Proof

kind: claims

A human reads the integration test and its passing run: the command writes a record the opener can read, and the Python close accepts the fixture without starting the other commands.

- branch: `phase/library-e2e`
