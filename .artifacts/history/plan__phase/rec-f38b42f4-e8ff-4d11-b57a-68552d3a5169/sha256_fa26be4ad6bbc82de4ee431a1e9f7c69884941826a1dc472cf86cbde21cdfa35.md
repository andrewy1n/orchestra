## Problem

A rendered view is a static file. It goes stale while execute-phase changes records.

## Approach

Not yet scoped. Direction: an adaptive-artifacts `watch --id <view>` command that polls the view's store-state digest and redraws in place. Decide at plan-phase. The phase ends with a verification task that depends on every other task in it.

## Exit criteria

Details decide at plan-phase. Gate: every acceptance has a passing check-run, and an integration test shows `watch` redraws after a record write and does not redraw when nothing changed.
