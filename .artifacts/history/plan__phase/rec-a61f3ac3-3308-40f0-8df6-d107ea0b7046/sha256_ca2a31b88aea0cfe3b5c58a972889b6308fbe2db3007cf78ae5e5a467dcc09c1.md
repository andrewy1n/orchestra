## Problem

`orchestra/aa.py`, `orchestra/aa_resolve.py`, and `dashboard/artifact_store.py` each find the store and start `adaptive-artifacts`. Close-batch judges affidavit by process exit codes. The package declares no dependencies, so importing affidavit at startup used to crash `orchestra --help` on a machine that does not have it.

## Approach

Decide the call sites at settle-phase. The behavior is already chosen: orchestra and the dashboard call `open_store` and affidavit's functions. The affidavit import stays inside close, so `orchestra --help` works when affidavit is not installed. The duplicate resolvers are deleted.

## Exit criteria

Orchestra tests pass with no subprocess to `adaptive-artifacts` or `aff` for store writes and assertion-red. `orchestra --help` exits 0 in an environment where affidavit is not installed. Verified by pytest in this repo.
