## Problem

A task has no record of how big it is or how long the agent who will do it should take. The phase body records session shape as `one sitting` or `more than one`, and the work-item records `executor` as `inline` or `subagent`. Neither is a duration. The dashboard cannot show an estimate that was never written.

## Approach

Decisions: task-agent-estimate, glance-run-facts.

Each new work-item stores `size` (`S`, `M`, or `L`) and `hours` (a non-negative number) for its executor. Absent means unset, and zero hours is a real estimate. `plan-phase` writes both with the executor. A missing executor means the hours are for a subagent. Size and hours are not derived from each other.

The phase does not store either field. Inline hours in a wave add. A subagent wave's elapsed estimate is its longest task. Phase elapsed time adds those wave figures in wave order. The sitting line stays.

Dashboard display waits for a later phase. When that phase shows the sitting line and the executor, it uses title suffixes. This phase does not render size, hours, the sitting line, or the executor.

## Exit criteria

`contract/project-design.json` allows optional `size` (`S`, `M`, `L`) and optional `hours` on `project:work-item`. `skills/plan-phase/SKILL.md` requires both on each new work-item and states the inline sum, the subagent-wave maximum, the phase elapsed time, and the sitting line. `python3 -m pytest tests/test_skill_contract_consistency.py -q` passes. The phase does not change `dashboard/`.
