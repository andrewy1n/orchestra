## Problem

The raw markdown frame is hard to read. It has no counts, no progress, and no color.

## Approach

A stdlib model builds a snapshot from `adaptive-artifacts list` JSON. A Textual app renders that snapshot. `scripts/dashboard` launches the app through `uv run --script`.

## Exit criteria

`scripts/dashboard` shows every live effort with its goal, phase progress, count tiles, a color-coded task table, a "needs you" list, and recent agent activity. It refreshes on store change and stays readable in the 40% tmux side pane. The user signs off on how it looks.
