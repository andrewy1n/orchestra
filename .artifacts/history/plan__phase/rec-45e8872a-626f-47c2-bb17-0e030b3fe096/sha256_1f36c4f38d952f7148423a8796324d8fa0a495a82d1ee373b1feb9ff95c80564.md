## Problem

Waiting task rows append every unfinished dependency slug as `waits on a, b, c, …`. The task column allows wrap, so long lists become multi-line rows, stretch the table, and push other tasks off screen ([issue #3](https://github.com/andrewy1n/se-workflow/issues/3)).

## Approach

Decision: drop-waits-on-from-row. Remove the `waits on …` note from `title_cell` so waiting rows show only title plus the size/estimate/executor suffix. Full dependency lists stay on task detail (Depends on). Model `waits_on` may remain; row rendering drops it. Update tests that expected the note in the table.

## Exit criteria

- Waiting rows with many unfinished dependencies stay one line at typical widths with no `waits on` in the title cell (unit + pilot tests).
- Task detail still lists Depends on links for those dependencies.
- Suites that previously asserted row `waits on …` pass against the dropped form.
