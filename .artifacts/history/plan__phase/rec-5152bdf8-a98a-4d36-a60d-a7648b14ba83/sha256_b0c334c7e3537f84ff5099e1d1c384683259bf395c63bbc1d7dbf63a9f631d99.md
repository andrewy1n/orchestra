## Problem

No view answers "what needs me, what is running, what is next" at a glance. The plan view prints unlabeled payload values and mixes finished and live work.

## Approach

1. adaptive-artifacts: a `label_fields` view parameter renders `field: value` instead of bare values.
2. adaptive-artifacts: a selection clause on `recorded_at` with a relative window, so a view can show recently finished work.
3. se-workflow: a `dashboard` view. Roles, in order: goal, current phase, needs-you (blocking questions, open non-blocking questions, findings with needs=human, unsigned manual checks), running (in_progress work-items with assignee), ready (planned, derived.ready true), waiting (planned, derived.ready false), done in the last 24h.

Steps 1 and 2 are independent. Step 3 depends on both.

## Exit criteria

`adaptive-artifacts view --id project:dashboard` renders every section, with labeled fields, against a seeded test store. Contract self-consistency and runtime tests pass.
