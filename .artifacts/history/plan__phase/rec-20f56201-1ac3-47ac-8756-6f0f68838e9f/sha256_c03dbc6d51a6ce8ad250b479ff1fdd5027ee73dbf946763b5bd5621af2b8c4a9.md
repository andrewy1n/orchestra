## Problem

The count tiles do not filter, waiting has no tile, phases read like a task column rather than structure, a built phase awaiting sign-off looks the same as one in progress, and the keyboard cannot move through tasks or reach Activity.

## Approach

Fix focus first: the task table takes focus on load, on effort switch, and on return from detail; arrows and j/k move rows; PgUp/PgDn scroll the pane; arrows scroll detail and commit screens. Replace the tiles and `d` with status tabs (Active default, Running, Ready, Waiting, Needs you, Done, All) that filter the table. Group the table into phase sections with header rows; in-progress and awaiting-sign-off phases expand, done and planned collapse, and more than two done phases fold into one "N earlier phases done" row. A phase detail screen shows the phase body, decisions, constraints, and tasks. The progress bar covers the whole effort.

## Exit criteria

Keyboard-only tests move through tasks, tabs, phase headers, and Activity; status tabs filter; phase sections group, collapse, fold, and open a phase detail; "awaiting sign-off" shows for a phase whose tasks wait only on a manual check; the full suite passes; the user signs off.
