## Problem

A flat task list does not show how a phase's tasks depend on each other or how waves line up.

## Approach

Add a wave-lane dependency graph to phase Overview for phases with three or more tasks; keep a list or strip for actions. Enrich task JSON with depends_on ids so the client can draw edges without N+1 fetches. Decisions: `task-graph-layout`, `task-graph-edge-data`, `task-graph-tiny-skip`.

## Exit criteria

- Overview shows a wave-lane graph with status-colored nodes and depends_on edges when ≥3 tasks.
- Graph omitted for ≤2 tasks; list/strip remains.
- Task JSON includes depends_on ids; tests and a manual look pass.

## Proof

kind: demo

A human opens a multi-wave phase Overview, sees tasks in wave columns with dependency edges, and opens a task from a node.
