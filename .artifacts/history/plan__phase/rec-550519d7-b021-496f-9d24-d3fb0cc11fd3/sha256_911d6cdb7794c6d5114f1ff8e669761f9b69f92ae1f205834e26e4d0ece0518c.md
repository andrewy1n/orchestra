## Problem

A new user must edit `~/.tmux.conf` to source a conf file by path, and the README has no numbered quick start. Other tmux plugins install through TPM and bind keys from their own script.

## Approach

Decisions: tpm-entry-script, drop-tmux-conf-fallback.

Add `se-workflow.tmux` at the repo root. It binds the popup and side-pane keys, reads the options `@dashboard-popup-key` and `@dashboard-pane-key` (defaults `A` and `S`), and finds the launcher from its own directory. Remove `dashboard/tmux.conf` and the `SE_WORKFLOW_DASHBOARD` variable. Add a numbered Quick start to the README: TPM first, then `run-shell` for users without TPM. Update the tmux tests to drive the new script.

## Exit criteria

1. `se-workflow.tmux` binds both keys and starts the dashboard from its own directory, with no path variable.
2. The key options rebind the keys, and the defaults are `A` and `S`.
3. `dashboard/tmux.conf` is gone and nothing refers to it.
4. The README has a numbered Quick start that covers TPM and `run-shell`.
5. The full suite passes, including the tmux tests.
