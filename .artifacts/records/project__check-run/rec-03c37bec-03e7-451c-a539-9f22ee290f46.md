                 {check,close-batch,install,contract,project-field,sessions,review-brief,suite,store}
                 ...

orchestra CLI: checks, contracts, reviewer briefs, phase suite, and store
access through the artifact library.

positional arguments:
  {check,close-batch,install,contract,project-field,sessions,review-brief,suite,store}
    check               Run an acceptance verify_command and write a
                        project:check-run
    close-batch         Build NDJSON apply batch that closes a work-item
    install             Install orchestra payload for one or more agent hosts
    contract            Print the bundled project-design contract
    project-field       Align a design file's project field with orchestra
    sessions            Summarize Claude Code session transcripts
    review-brief        Build the phase-end reviewer brief from allowed store
                        records and git diff <base>..<phase-head>
    suite               Phase suite: contracted policy, background run,
                        collect, record
    store               Open the bound store and read or write it through the
                        library

  -h, --help            show this help message and exit
