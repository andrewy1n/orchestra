## Rationale

The pane is 60 columns, and a new column drops off below 90 the way assignee does. Sitting shape, elapsed minutes, size, task minutes, and executor are one suffix line, so one phase should own it. The header shows how long the phase should take under the wave rule. Each task shows its own size and minutes, so the long task is visible without opening it. A partial total without an unset count would look like the whole phase. Task detail repeats the same facts as chips.

## Counter-argument

Putting only the elapsed minutes on the header, and leaving size and per-task minutes on the detail screens, keeps the table short. At 60 columns the suffix cuts the task title, and every existing task gains an executor word even when it has no estimate.
