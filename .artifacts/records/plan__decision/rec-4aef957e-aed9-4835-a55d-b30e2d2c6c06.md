## Rationale

Dual-store merge needs runtime support and unclear write authority. Exclusive local or global matches how projects actually want to work and keeps failure modes obvious.

## Counter-argument

Ordered fallback (home-then-repo) would have unblocked today's drift without a preference file, but it hides which store is authoritative and recreates silent shadowing when both exist.
