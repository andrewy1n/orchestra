## Rationale

The backlog item and prior packaging specs already marked PyPI as later. Dogfood still installs via plugins and git. Publishing freezes names, entry points, and layout before outside users exist. This phase proves git+ tool install; PyPI waits for settled format and real external demand.

## Counter-argument

Publishing to PyPI now would make `pip`/`uv` install trivial for strangers and force the layout to be "real" sooner. The cost is premature public API surface and version/release ceremony that this effort already parked until a release process exists.
