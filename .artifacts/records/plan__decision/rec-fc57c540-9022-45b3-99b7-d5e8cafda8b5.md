## Rationale

TPM is how tmux users install plugins. TPM runs each `*.tmux` file at the repo root, so a `se-workflow.tmux` script needs no `source-file` line and no path variable: it finds its own directory. Key options (`@dashboard-popup-key`, `@dashboard-pane-key`, default `A` and `S`) let users rebind keys without editing a copy. A user without TPM runs the same script with `run-shell`. The user chose this.

## Counter-argument

The current `source-file` conf is one static file with no logic, so it is easy to read and test. A script adds shell code to maintain and test, and TPM users are only part of the audience. Users who install only the Claude Code plugin get no benefit, because TPM clones the repo and the plugin cache is elsewhere.
