## Rationale

Single-directory installs are the common denominator across harnesses: `npx skills add`, Cursor, Codex, OpenCode, and most hosts copy or symlink one skill directory. Generating `references/ensure-store.md` and `references/kinds-and-focus.md` into each skill at build time keeps one authoritative source while making every skill standalone, so no host needs the plugin root. A drift test is cheap and catches the one failure this design invites: a source edit that never reached the generated copies.

## Counter-argument

A single umbrella `orchestra` skill with all shared references is fewer files and has no drift risk, but it loses per-skill discovery and progressive disclosure, which is the reason the skills were split in the first place. Keeping `../` shared docs and requiring whole-root installs preserves the current tree exactly, but rules out `npx skills add`, single-skill installs, and global installs on most hosts — the problem this phase exists to fix.
