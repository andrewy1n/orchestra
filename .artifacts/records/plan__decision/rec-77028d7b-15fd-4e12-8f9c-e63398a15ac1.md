## Rationale

The Svelte screens are styled with Tailwind. The spike's layout still names the screens: effort rail, main pane, side column, and detail overlays. Tailwind replaces the mock's hand-written stylesheet, so the visual design is rebuilt in utilities instead of being copied from `styles.css`.

## Counter-argument

The design mock already has tokens, a light theme, a dark toggle, and overlay styling that match the information on screen. Porting that CSS would keep a look we have seen, without a utility framework or a restyle. Tailwind spends the first UI work on appearance instead of on wiring the API.
