## Rationale

Questions, needs:human findings, and unsigned manual checks are already human-owned verbs on Needs you (Answer / Decide / Sign off). Letting the dashboard fire those same clears matches how the user already thinks about the panel. Merge, integration, and loop-route need agent or git work beyond a single dismiss key.

## Counter-argument

Dismissing every Needs-you kind would remove more clutter with one UX; the risk is a one-key “Merge branch” or “Route to design” that pretends work finished when it did not.
