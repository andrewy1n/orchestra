## Rationale

Affidavit writes records and must not depend on orchestra, so the rule for which directory is the store has to live in adaptive-artifacts. `SE_WORKFLOW_STORE` only says `local` or `global` for one process. The binding files already hold the durable choice, and `ARTIFACTS_STORE` or `--store` already holds a one-shot path.

## Counter-argument

Renaming the variable, instead of removing it, would keep a one-word override that beats the gitignored binding file without a path. The cost is a third switch beside `ARTIFACTS_STORE` and `--store`, under a name that still has to be taught.
