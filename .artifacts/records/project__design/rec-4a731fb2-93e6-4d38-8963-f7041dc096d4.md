## Architecture

Single clean-break rename in the affidavit plugin tree:

1. Rename Python package directory `se_workflow/` → `affidavit/`; update imports and `bin/aff` launcher (delete `bin/se-workflow`).
2. Set Claude/Cursor plugin + marketplace names to `affidavit`; update `scripts/sync-plugin.sh` (and any hardcoded local plugin paths) for the new name.
3. Set `contract/project-design.json` `"project": "affidavit"`; copy into `.artifacts/project-design.json` and `adaptive-artifacts resolve` on the primary checkout; rewrite ensure-store / kinds-and-focus / skills text that gated on `se-workflow`.
4. Retarget skills, README, AGENTS, CLAUDE, agents, tests from `se-workflow` / `se_workflow` to `affidavit` / `aff`.
5. Landing: `gh repo rename affidavit` (or equivalent) on `andrewy1n/se-workflow`; fix any remaining github URLs; reinstall/sync plugins; open AA-gate follow-up for adaptive-artifacts docs that still name se-workflow.

Phase branch/worktree naming follows Landing (`phase/rename-agent-affidavit`); the phase subject string stays for record continuity.

## Interfaces

- CLI: `aff check …`, `aff close-batch …` (same flags as today’s se-workflow CLI).
- Plugin id: `affidavit` in `.claude-plugin/` and `.cursor-plugin/`.
- Contract: `"project": "affidavit"`; ensure-store foreign check compares to that string.
- GitHub: `https://github.com/andrewy1n/affidavit` after rename.
- Tests: rename test modules as needed (`test_se_workflow_*` → `test_affidavit_*` or keep filenames if imports alone change—prefer clear names).

## Invariants

- No permanent `se-workflow` CLI or plugin alias after the phase.
- Store history is not bulk-rewritten for branding.
- AA runtime code unchanged without AA-gate approval.

## Assumptions

- Operator can rename the GitHub repo and update local plugin checkouts in Landing.
- GitHub redirects old clone URLs for a transition period.

## Tradeoffs

- Full break vs soft aliases: more install churn once, no dual-name debt.
- Keeping phase subject `rename-agent-affidavit` vs renaming the phase record: subject stays; product string is `affidavit` everywhere user-facing.

## Risks

- Missed string in skills/tests breaks dogfood until fixed—mitigate with greps and skill-contract tests.
- GitHub rename timing vs pushed marketplace URLs—Landing orders rename then URL fix then sync.
- AA docs lag until gate approval—explicit Landing follow-up so it is not forgotten.
