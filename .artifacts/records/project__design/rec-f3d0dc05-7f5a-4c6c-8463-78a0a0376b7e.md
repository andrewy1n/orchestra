## Architecture

Replace the flat `.stepper` in `App.svelte` with a Phases block when `effort.milestones?.length`. Group `effort.phases` by `phase.milestone` (empty string → Ungrouped). Render milestone groups in `effort.milestones` order, then Ungrouped. Keep the existing stepper path when there are no milestones.

Client-only UI state: a set of expanded milestone subjects. Initialize from R7/R8 whenever the selected effort or resolved phase changes. Do not persist expand state across reloads.

Reuse `selectPhase`, `openPhase`, `defaultPhase`, and `resolvedPhase`. No FastAPI or model changes.

## Interfaces

- Type `MilestoneRow` in `types.ts` (subject, title, ordinal, state, done, total, optional id) and type `EffortView.milestones` as `MilestoneRow[]`.
- Pure helpers in `efforts.ts` (or a small `milestones.ts`): `groupPhasesByMilestone(effort)`, `initialExpandedMilestones(effort, phaseSubject)`, used by the view and by tests.
- Markup: milestone headers as buttons (toggle expand); phase rows as buttons (select / open-on-reselect); All phases control beside or under the block.
- Tests: vitest against helpers and rendered App fixtures for R1–R9 behaviors that are automatable.

## Decisions

- `web-calm-phase-split`
- `milestone-nav-layout`
- `milestone-nav-collapse`
- `milestone-nav-click`
- `milestone-nav-web-only`

## Invariants

- When milestones exist, the flat stepper is not shown for that effort.
- Task scoping still goes through `resolvedPhase` / `filteredTasks`.
- Expand/collapse never changes the selected phase by itself.

## Assumptions

- Spike `phaseSection` in `spikes/web-dashboard/static/app.js` is the visual reference, not a runtime dependency.
- Milestone `state` values match `dashboard.model._milestone_state` (including `done`).

## Tradeoffs

- A taller main pane for efforts with many open milestones, in exchange for scannable grouping.
- Collapse state is session-local, so a reload re-applies defaults (simpler; no URL noise).

## Risks

- Efforts with many simultaneous non-done milestones can still feel long; later calm phases do not fix that height.
- If snapshot milestones and phase.milestone slugs ever disagree, Ungrouped may show orphans — trust model output; do not invent client-side repair beyond grouping by the phase field.
