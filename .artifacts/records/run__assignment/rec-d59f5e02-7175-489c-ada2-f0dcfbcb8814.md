## Approach

- On the app from `web-read-api`, add POST `/api/needs` with JSON `{effort, id, action, note?}` and POST `/api/backlog` with JSON `{effort, id, action}`.
- Reload the item, set the revision the client sent onto that item, and call `dashboard.dismiss.dismiss_item` or `dashboard.backlog.dismiss_item` / `promote_item`.
- The signer is `dashboard.dismiss.default_signer()`. Ignore a signer field on the request.
- Map the stale `DismissError` to 409. Map a refused kind, a bad action, and a missing required note to 400.
- Drop the snapshot cache after a successful write.
- Make the R21, R22, R23, R24, R25, R26, R28, R29, and R34 tests in `tests/test_web_dashboard.py` pass.
