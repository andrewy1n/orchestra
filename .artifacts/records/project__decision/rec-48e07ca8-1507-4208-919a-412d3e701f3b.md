## Rationale

The store has to be usable with no workflow types, and verdict has to run with no artifact store. Separate repos keep those two facts true. Orchestra is the only package that needs both.

## Counter-argument

One package would remove the call boundary and the version skew in a single install. The cost is that using the store would drag in close rules, and verdict could no longer be used on its own.
