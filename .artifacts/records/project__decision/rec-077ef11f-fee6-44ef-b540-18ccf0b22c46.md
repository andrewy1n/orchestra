Waves already encode parallelism; a left-to-right lane layout makes dependency order obvious without a chaotic force-directed graph. Edges from depends_on complete the picture the glyph strip only hints at.

A graph-only overview would maximize the structural view. That was rejected because users still need a scannable action list for ready/running tasks.
