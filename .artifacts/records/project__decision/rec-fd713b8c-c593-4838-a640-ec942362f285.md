## Rationale

The parent session already owns store writes and verify-work. Letting it approve oracle amendments keeps a single writer and avoids blocking every interface guess on the owner, while still refusing silent hash changes.

## Counter-argument

Owner-only approval would make freeze stronger against a rogue parent agent and give a human signal on amendment rate. The cost is latency on every interface mismatch during execute.
