## Rationale

integration-report is for semantic merge of parallel work (Interfaces/Assumptions/Invariants/Conflicts). Human proof is a different job: Look/Machine/Attention/Diff. A dedicated observation type keeps those authorities clear and lets handoff select latest-proof without overloading merge semantics.

## Counter-argument

Extending integration-report would avoid a new type and one more create at phase end. It would also force every human-facing Look path through merge-oriented sections and break incidental phases that skip the report.
