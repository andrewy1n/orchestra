## Rationale

Requirements status should stay visible while switching tabs so Spec/Evidence work does not hide health. The strip remains clickable into requirement overlays.

## Counter-argument

Showing the strip only on Overview would reduce chrome on Spec/Design. Rejected because the user wants better UI elements everywhere, and requirement health is cross-cutting.
