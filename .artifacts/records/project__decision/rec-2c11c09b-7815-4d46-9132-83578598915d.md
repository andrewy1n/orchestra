## Rationale

The user chose direct imports. `open_store` is the public surface, so orchestra and the dashboard call it and the two copied resolvers are deleted. Close calls affidavit's functions. The import stays inside close, so `orchestra --help` still runs when affidavit is absent.

## Counter-argument

An `orchestra.store` wrapper would let the dashboard avoid naming `adaptive_artifacts` and would give one place to adapt if `Project` changes. The cost is a new pass-through in the same role as the resolvers this phase deletes.
