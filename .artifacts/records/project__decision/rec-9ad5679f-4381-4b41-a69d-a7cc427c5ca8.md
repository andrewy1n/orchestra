## Rationale

Marketplace installs place plugins under host-managed roots and export plugin-root env vars. Hardcoding `~/.cursor/plugins/local/se-workflow` or assuming a sibling git checkout fails for Claude marketplace installs and for users who keep checkouts elsewhere. Preferring `${CLAUDE_PLUGIN_ROOT}` / `${CURSOR_PLUGIN_ROOT}`, then skill-relative layout, matches how the hosts already locate the plugin.

## Counter-argument

PATH-only resolution is simpler and avoids teaching agents about host env vars. It fails when plugins are installed but CLIs are not on PATH, which is the common Cursor/Claude plugin layout today — the failure mode this phase exists to fix.
