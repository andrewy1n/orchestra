## Rationale

The user chose to swap the client. `is_assertion_level_red`, `run_verdict`, and `recheck` already exist, and `aff` already calls them. Observation and binding are the only store writers, so they call `Project` and the subprocess clients go away. The word-ban test goes away with them.

## Counter-argument

A single gateway module would keep `import adaptive_artifacts` in one file, so a Project signature change would touch one module. The cost is a new wrapper around a facade that was just created to be the public surface.
