## Rationale

Handoff alone is easy to miss after a phase closes. The dashboard is where the user already opens a finished phase. Surfacing Look and Attention on phase detail makes the proof packet the default human path without adding a blocking Needs-you item (we still require only the packet write, not a signature).

## Counter-argument

Handoff-only would ship faster and keep dashboard unchanged. That recreates the original pain: finished-with-summary and no obvious place to open proof.
