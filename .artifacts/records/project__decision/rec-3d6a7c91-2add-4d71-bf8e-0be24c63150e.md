## Rationale

A shared marketplace lets se-workflow declare a same-marketplace dependency on adaptive-artifacts. Claude then installs the runtime with the product plugin, without cross-marketplace allowlists or a second `marketplace add`. That matches the backlog intent and the documented dependency model.

## Counter-argument

Cross-marketplace dependency keeps each repo's marketplace as the sole catalog for that plugin and avoids listing AA in two places. The cost is allowlist maintenance and a worse first-install story, which is the main pain this phase exists to fix.
