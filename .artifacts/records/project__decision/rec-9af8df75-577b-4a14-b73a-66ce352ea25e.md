## Rationale

The backlog already ordered the work: restructure adaptive-artifacts into a proper package so `uv tool install git+…` works, and leave PyPI until outsiders use it. Affidavit already has an importable `affidavit/` package and `bin/aff`; the blocker for tool install is AA's `tools/` + sys.path layout. Shipping AA-only in this phase cuts cross-repo Landing risk and keeps affidavit's plugin story unchanged.

## Counter-argument

Packaging both repos together (dual-repo git+) would give one install story for the whole stack and avoid a second packaging phase for affidavit. That still requires the AA restructure first, and affidavit is usable today via plugins—so the incremental value of affidavit pyproject in the same Landing is lower than finishing AA.
