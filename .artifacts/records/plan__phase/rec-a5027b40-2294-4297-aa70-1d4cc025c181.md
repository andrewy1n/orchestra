## Problem

The skills go straight from an ask to a plan. Nobody settles the approach with the user before tasks get written, and nothing makes the user review the plan before subagents run.

## Approach

- New `discuss` skill: read the phase and the code it touches, present 2-3 approaches with trade-offs and a recommendation, let the user choose, then write `project:decision` records and the chosen approach into the phase body. No work-items, no code.
- engage routes new `deliver`/`repair`/`evaluate` phases through `discuss` before `plan-phase`, unless the user already fixed the approach.
- plan-phase checks for a decision on the phase (or the user's fixed approach) before writing tasks.
- Review gate: plan-phase ends by opening a blocking `continuity-question` on the focus with `scope` = `plan-review:<phase-slug>`. execute-phase already refuses to dispatch while a blocking question is open; a `plan-review:` question blocks only its phase. The user approves by answering it. It shows in the dashboard under needs-you.

## Exit criteria

- `skills/discuss/SKILL.md` exists, writes only decisions, the phase body and questions, and passes the skill/contract consistency test.
- engage, plan-phase, execute-phase and README route through discuss and the review gate; the consistency tests pass.
