## Problem

`orchestra/aa.py`, `orchestra/aa_resolve.py`, and `dashboard/artifact_store.py` each find the store and start `adaptive-artifacts`. Close-batch judges affidavit by process exit codes. The package declares no dependencies, so importing affidavit at startup used to crash `orchestra --help` on a machine that does not have it.

## Approach

**Direct imports** (`orchestra-imports`, `dependency-direction`, `store-resolution`).

Orchestra and the dashboard call `adaptive_artifacts.project.open_store`. `aa_resolve.py` and `dashboard/artifact_store.py` are deleted. Close calls `is_assertion_level_red`, `run_verdict`, and `recheck`, and that import stays inside the close command (`call-style`). `pyproject.toml` depends on adaptive-artifacts. Affidavit stays optional. Claim-gate policy changes wait for `claim-clocks`.

## Exit criteria

R1–R10 in the phase specification hold under pytest in this repo. `orchestra --help` exits 0 when affidavit is not importable. A close that needs affidavit names it in the error when it is missing.

## Proof

kind: claims

A human reads tests that fail if the old resolvers exist, spies that show close calls affidavit functions, and a help run with affidavit hidden.

more than one sitting. Human stops: none. The dashboard has many `artifact_store` call sites, and close-batch's existing tests assert the old `aff` process boundary, so the two implementation tasks stay in separate waves.

## Collision

`replace-resolvers` owns `orchestra/aa.py`, `orchestra/aa_resolve.py`, `dashboard/artifact_store.py`, every module and test that imports them, and `pyproject.toml`. It may edit `orchestra/close_batch.py` only so store access still works after `aa_resolve` is gone. It does not replace `aff` subprocess calls.

`close-library` depends on that task and owns the `aff` call sites in `orchestra/close_batch.py`, `tests/test_close_batch.py`, and `tests/test_affidavit_import_boundary.py`.

`verify-orchestra-callers` runs in the phase worktree. It does not take a task branch and it does not edit the tree.
