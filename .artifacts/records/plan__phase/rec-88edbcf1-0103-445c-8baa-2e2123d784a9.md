## Problem

adaptive-artifacts can store records, but it has no public function other packages can call. Orchestra and the dashboard each decide whether the store is in the repo or under the home directory. Affidavit only passes `--root`, so a project pinned to the home store is invisible to it. `SE_WORKFLOW_STORE` is a leftover name for a one-shot `local` or `global` switch.

## Approach

**Project facade** (`library-facade`, `store-resolution`, `call-style`).

`adaptive_artifacts.project.open_store` resolves one store. Order: a path passed by the caller, then `ARTIFACTS_STORE`, then `.artifacts/store-binding.local.json`, then `.artifacts/store-binding.json`, then `<root>/.artifacts` if it has `meta.json`, otherwise `~/.artifacts/<root name>` if that has `meta.json`. A chosen store with no `meta.json` raises. `SE_WORKFLOW_STORE` is not read.

`Project` exposes get, list, create, and apply. The `adaptive-artifacts` command uses `open_store` for its path and calls those four for create, get, and apply. List query flags stay in the command, over that same store. Other commands keep their current bodies. This phase does not edit orchestra or affidavit (`three-repos`).

Session shape: one sitting. Human stops: none. The request to execute the libraries milestone is the plan-review approval, and push is not a stop.

Collision: code lands only in adaptive-artifacts. Wave 1 is `open-store` (new `src/adaptive_artifacts/project.py`). Wave 2 is `project-ops` (same module, plus any create/apply helpers moved out of `cli.py`). Wave 3 is `command-facade` (`cli.py` and fixtures that assumed the git-common-dir fallback). Wave 4 is `verify-aa-library` in the phase worktree, no task branch. Each implementation task depends on the one before it, so no two tasks write those files in one wave. Executor is subagent for every wave.

## Exit criteria

R1–R21 in the phase specification hold under the adaptive-artifacts test suite. The command creates and reads a record with no `--store`, in the store `open_store` would open. Nothing in the package reads `SE_WORKFLOW_STORE`.

## Proof

kind: claims

A human reads tests that open a temporary repo at each resolution step, and a test that `adaptive-artifacts create` and `get` hit the same store as `open_store`.
