## Problem

The dashboard app, model and status line live in scripts/ next to unrelated tooling. dashboard_app.py has 1726 lines, with the task table, filter, sections and task detail mixed with the other screens.

## Approach

Decisions: dashboard-package-layout, dashboard-task-split.

Create a top-level `dashboard/` package next to `scripts/`: `model.py`, `artifact_store.py`, `app.py`, `status.py`, `__main__.py`, `tmux.conf`, and the executables `bin/dashboard` and `bin/dashboard-status`. Leave no wrappers in scripts/. `artifact_store.py` has no other user, so it moves with the dashboard. The PEP 723 inline-dependency run through `uv run --script` stays.

Task order: move the files and fix imports, entry points and test paths first. Then update install and docs. Then split the task table code, then the task detail code, out of the app. The verification task runs last.

## Exit criteria

1. The dashboard code lives in its own package outside scripts/.
2. The task code is in its own modules, not in app.py.
3. The plugin install and the tmux entry points still start the dashboard.
4. The full suite passes, including the tmux tests.
