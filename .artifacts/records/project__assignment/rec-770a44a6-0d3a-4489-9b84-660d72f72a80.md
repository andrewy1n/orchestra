### Work-item (quote)

## Description

R1: Inside a git repository, `open_store` uses `git rev-parse --show-toplevel` of the given directory as the project root.
R2: Outside a git repository, `open_store` uses the given directory as the project root.
R3: A store path passed to `open_store` selects that directory, and binding files are not read.
R4: With no store path argument, `ARTIFACTS_STORE` selects the directory, and binding files are not read.
R5: With no store path argument and no `ARTIFACTS_STORE`, `.artifacts/store-binding.local.json` at the project root selects `local` or `global`.
R6: With no store path argument, no `ARTIFACTS_STORE`, and no local binding file, `.artifacts/store-binding.json` selects `local` or `global`.
R7: With no store path argument, no `ARTIFACTS_STORE`, and no binding file, `open_store` opens `<root>/.artifacts` when that directory contains `meta.json`.
R8: With no store path argument, no `ARTIFACTS_STORE`, and no binding file, `open_store` opens `~/.artifacts/<root name>` when `<root>/.artifacts` has no `meta.json` and the home directory contains `meta.json`.
R9: A store path argument whose directory has no `meta.json` raises, and the home store is not opened.
R10: `ARTIFACTS_STORE` set to a directory with no `meta.json` raises, and binding files are not read.
R11: A binding file whose selected directory has no `meta.json` raises, and the other location is not opened.
R12: A binding value other than `local` or `global` raises.
R13: With no store path argument, no `ARTIFACTS_STORE`, no binding file, and no `meta.json` in either location, `open_store` raises.

## Approach

Add `src/adaptive_artifacts/project.py` with `open_store(directory, *, store=None) -> Project` and `StoreBindingError`. Do not import orchestra or affidavit.

Project root is `git -C <directory> rev-parse --show-toplevel` when that succeeds, otherwise the given directory resolved.

Stop at the first match. Never fall through to another store.

1. If `store` is not None, use that path and do not read `ARTIFACTS_STORE` or binding files. Raise `StoreBindingError` when that directory has no `meta.json`.
2. Else if `ARTIFACTS_STORE` is set, use that path and do not read binding files. Raise `StoreBindingError` when it has no `meta.json`.
3. Else if `<root>/.artifacts/store-binding.local.json` exists, read JSON `store`. Only `local` (`<root>/.artifacts`) and `global` (`~/.artifacts/<root name>`) are valid. Any other value raises `StoreBindingError`. If the selected directory has no `meta.json`, raise `StoreBindingError` and do not open the other location.
4. Else if `<root>/.artifacts/store-binding.json` exists, apply the same rules.
5. Else if `<root>/.artifacts/meta.json` exists, open `<root>/.artifacts`.
6. Else if `~/.artifacts/<root name>/meta.json` exists, open that directory.
7. Else raise `StoreBindingError`.

`Project` carries the project root, the store path, the contract path taken from `meta.json`'s `contract` field the same way `contract_path_from_meta` resolves it, and the binding that won (`local` or `global`, plus the source: argument, `ARTIFACTS_STORE`, the binding file path, or default).

Do not read `SE_WORKFLOW_STORE`. Do not use `git rev-parse --git-common-dir`. Do not implement get, list, create, or apply in this task. Do not edit the command, orchestra, or affidavit.
