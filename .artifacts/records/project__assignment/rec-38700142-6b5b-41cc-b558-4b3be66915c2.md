## Orientation

Territory: ~/adaptive-artifacts/.artifacts only (extension-gate capture). No affidavit tree edits. No AA code merge until this amendment is approved.

Concurrency: parallel with affidavit-readme-git-tool (affidavit README only). No shared files.

Operational: use adaptive-artifacts --root ~/adaptive-artifacts (or cwd there). Follow AGENTS.md "Changing the extension".

### Requirements

R8: Layout and packaging changes in the adaptive-artifacts repo follow that repo's extension gate (capture in its store; apply only with human approval).

### Design invariants

- Public contract is the CLI, not Python import stability for third parties.
- Shim paths remain runnable after the package move.
- Record/store formats unchanged.
- Affidavit product code does not gain a dependency on importing adaptive_artifacts.

### Design assumptions

- Hatchling or setuptools is fine for the build backend.
- Distribution name can be adaptive-artifacts with import package adaptive_artifacts.
- Human approval in the AA store happens before AA code merges.
