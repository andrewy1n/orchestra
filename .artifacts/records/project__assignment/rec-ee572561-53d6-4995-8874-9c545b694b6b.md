### Design / decisions (quote)

#### Invariants
- When milestones exist, the flat stepper is not shown for that effort.
- Task scoping still goes through `resolvedPhase` / `filteredTasks`.
- Expand/collapse never changes the selected phase by itself.

#### Assumptions
- Spike `phaseSection` in `spikes/web-dashboard/static/app.js` is the visual reference, not a runtime dependency.
- Milestone `state` values match `dashboard.model._milestone_state` (including `done`).

- milestone-nav-layout: Port the spike Phases block: milestone headers with phase rows; flat stepper only when there are no milestones
- milestone-nav-collapse: Finished milestones collapsed by default; milestone containing the selected or default phase stays expanded
- milestone-nav-web-only: Implement milestone grouping only in dashboard/web/ui; Textual unchanged
