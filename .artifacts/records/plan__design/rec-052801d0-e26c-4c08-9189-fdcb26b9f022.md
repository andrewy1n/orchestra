## Architecture

Affidavit's `pyproject.toml` depends on adaptive-artifacts. Orchestra's `pyproject.toml` depends on adaptive-artifacts and offers an `evidence` extra that depends on affidavit. `orchestra install` installs the runtime dependencies into the environment that provides the `orchestra` command, including the extra only when evidence is requested. Orchestra code no longer reads `ADAPTIVE_ARTIFACTS_BIN` or plugin-root variables to find the store. `open_store` reads the contract `format` and raises `StoreBindingError` when it is not supported.

## Interfaces

`open_store` grows the format check on top of the `aa-library` signature. `orchestra install` gains no new host flags in this phase; evidence follows whether the extra is installed in that environment. The supported format is the string the build already writes, `adaptive-artifacts/project-design@0.3.0`.

## Decisions

- `install-graph`: pyproject dependencies, plugin install places them, discovery is the import.
- `version-check`: a dependency specifier plus the contract format, not a `--version` string compare.
- `dependency-direction`: affidavit is the optional extra, not a required dependency.

## Invariants

Importable adaptive-artifacts after a normal install. No affidavit unless the extra was requested. Unknown contract format fails open.

## Assumptions

Plugin hosts can run a package installer. `uv tool install` honors the dependency and the extra.

## Tradeoffs

An existing plugin checkout that only copied files, and never installed the package, stops resolving the store until it is reinstalled. There is no fallback search.

## Risks

Cursor's plugin install does not pull dependencies today. This phase has to add that step inside `orchestra install`, or a Cursor install still lacks `adaptive_artifacts`.
