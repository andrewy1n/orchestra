## Architecture

Keep two git repos. Change only Claude packaging metadata and docs in se-workflow (and README install steps). se-workflow's `.claude-plugin/marketplace.json` becomes the shared catalog: plugin entry `se-workflow` with `source: "./"`, plugin entry `adaptive-artifacts` with a github source to `andrewy1n/adaptive-artifacts`. se-workflow's `.claude-plugin/plugin.json` gains `dependencies` naming `adaptive-artifacts` (add a semver range if release tags already exist; otherwise bare name is enough for this phase). AA's own marketplace may remain for standalone installs. Cursor manifests are out of the auto-dep path; document sync/PATH only.

## Interfaces

- `.claude-plugin/plugin.json` → `dependencies` array (Claude plugin dependency API).
- `.claude-plugin/marketplace.json` → two `plugins[]` entries; AA via github source object per Claude marketplace reference.
- README Install → one marketplace add + `claude plugin install se-workflow@…`.
- Validation: `claude plugin validate .` in se-workflow.

## Decisions

- marketplace-topology: shared-marketplace
- marketplace-host: se-workflow-hosts-both

## Invariants

- No monorepo merge.
- Dependency resolves inside the se-workflow-hosted marketplace (no `allowCrossMarketplaceDependenciesOn` required for the happy path).
- AA remains installable on its own.

## Assumptions

- Claude resolves github-sourced marketplace entries for the dependency install.
- Listing AA in both marketplaces does not confuse install ids for users who only use the se-workflow marketplace.

## Tradeoffs

- AA appears in two catalogs (its repo + se-workflow's). Accepted to get one-add install.
- Cursor users still do a manual two-piece setup; this phase does not invent a Cursor dependency mechanism.

## Risks

- Github source shape or auth differs from local `./` — mitigate with `claude plugin validate` and a manual install dry-run before calling the phase done.
- Pending rename to agent-affidavit will churn marketplace/plugin names — keep this phase on current names; rename backlog owns the cutover.
