## Description

Since the Needs you panel became a focusable list (2066784), tab from a live effort with Needs you items to an effort whose task table is hidden (for example a finished effort on the Active tab) bounces back: focus falls back from the hidden TaskTable to the sibling NeedsList and TabbedContent re-activates that pane. Move focus into the new pane (its table, else its Needs you list) or clear it before switching. Add the pilot repro as a regression test.
