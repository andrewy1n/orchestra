## Description

Restructure adaptive-artifacts into an installable package with
pyproject.toml and console-script entry point, keeping thin
compatibility shims at historical paths. Waits on the approved AA
packaging amendment.

## Approach

1. After amendment approval, in ~/adaptive-artifacts: add root
   pyproject.toml (hatchling or setuptools) with project name
   adaptive-artifacts and [project.scripts] adaptive-artifacts pointing
   at the package main.
2. Move tools/runtime (and CLI from tools/artifacts.py) into
   src/adaptive_artifacts/ (or equivalent import package); fix internal
   imports.
3. Replace bin/adaptive-artifacts and tools/artifacts.py with thin shims
   that invoke the package entry (no sys.path reopening of
   tools/runtime).
4. Keep plugin layouts pointing at bin/adaptive-artifacts. Run AA's own
   tests if present; prove shims with --help plus one store-touching
   command on a temp store.
