## Description

R30: When the Vite production build is present, GET / returns that Svelte app.

## Approach

- Add `dashboard/web/__main__.py` with a PEP 723 header for fastapi and uvicorn, and `dashboard/bin/web` that resolves the store the way `dashboard/bin/dashboard` does.
- Bind only `127.0.0.1`. Mount `dashboard/web/ui/dist` at GET `/` when that build exists. When it does not, return a short message that names `npm run build`.
- Make `tests/test_web_dashboard_launch.py` pass for R1, R2, and R30.
