## Description

R8: `orchestra close-batch` does not import the `affidavit` Python package.
R9: For oracle-backed closes that need assertion-level red classification, Orchestra obtains that classification only by invoking an Affidavit CLI command.

## Approach

In the Affidavit repo, expose a thin `aff` subcommand that wraps `affidavit.oracle_red.is_assertion_level_red` (stdin or file of check-run JSON → exit 0/1). In Orchestra, replace the deferred `import affidavit.oracle_red` in `close_batch` with a subprocess to that CLI; remove checkout `sys.path` probing used only for that import if nothing else needs it. Update `tests/test_affidavit_import_boundary.py` so close_batch must not import `affidavit` at all. Refuse oracle-backed close clearly when the CLI is missing.
