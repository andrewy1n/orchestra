## Description

Make illegal check-run result/method values fail validation, and allow optional runner metadata fields.

## Approach

1. In `contract/project-design.json`, add `payload_enum` for `check-run.result` (`pass|fail|blocked|insufficient`) and for `method` on both `check-run` and `acceptance` (`tdd|check|manual`).
2. Add optional payload fields: `exit_code`, `duration_s`, `output_sha256`, `runner`, `diff_sha256` (list them in `optional_payload` and `payload` as the contract pattern requires).
3. Flip assertions in `tests/test_evidence_loop.py` and `tests/test_assess_routing.py` that require `result` not to be an enum; keep `tests/test_contract_self_consistency.py` green.
4. Do not edit skills or the CLI in this task.
