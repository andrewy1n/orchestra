## Rationale

The user chose quiet tabs and a collapsed phase history. Each status tab is a word plus a dim tally in parentheses (`Active (3)`), so the number reads as a count on that filter. Shortcut digits stay on keys `1`-`6` and in the footer, and leave the label, which is what was colliding with task and phase numbers. The stepper replaces the green check per finished phase with a muted `N done` count, the current phase, and one next phase. Activating the count expands the finished titles. Every tally stays visible, and the finished names stay one activation away.

## Counter-argument

Showing a tally only on the selected tab, and a stepper of only the current phase plus the next one, would remove still more numbers from the header. Waiting's count would appear only after selecting Waiting, and finished phase names would leave the header entirely.
