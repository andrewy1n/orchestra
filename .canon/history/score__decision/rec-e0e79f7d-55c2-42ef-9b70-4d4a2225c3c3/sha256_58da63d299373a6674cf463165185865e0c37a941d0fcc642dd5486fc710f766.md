## Rationale

`evidence-kind` is the next phase of this effort, and its exit is a close refusal, so `aff close-batch` stays in this repo where that phase can extend it. The evidence-layer goal says an orchestration client gets gate answers through `aff` verbs, so `check`, `close-batch`, and `verdict` stay on `aff`. Reviewer, suite, and tier2 are the loop the skills import, so they move with the skills, the dashboard, and the session scripts. `affidavit.aa` stops importing the dashboard before that tree leaves.

## Counter-argument

A verdict-only affidavit matches the standalone goal more closely. `check` and `close-batch` write the artifact store through adaptive-artifacts, so they behave as orchestration. Moving them would let this repo's tests import only the manifest and the verdict, and `evidence-kind` could become a verdict rule instead of a close rule.
