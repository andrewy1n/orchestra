## Problem

About 40 modules outside `orchestra/canon/` read store files directly. A storage change cannot land while they depend on the file layout.

## Approach

Route every read and write through the `orchestra.canon` API. Add API calls where a reader needs data the API does not expose. Decide at settle-phase how many readers exist and whether to split this phase.

## Exit criteria

- A test finds no module outside `orchestra/canon/` that opens a file under `.canon/`. Verified by that test passing.
- The full test suite passes unchanged in behaviour. Verified by the configured phase suite.
- `canon validate` passes. Verified by running it.
