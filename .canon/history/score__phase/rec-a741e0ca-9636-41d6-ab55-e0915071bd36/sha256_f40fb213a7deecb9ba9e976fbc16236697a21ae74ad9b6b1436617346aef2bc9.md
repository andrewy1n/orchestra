## Problem

Oracle hashes cover only the test files. An agent can still earn a pass by editing `conftest.py`, fixtures, or `pytest.ini`, adding a skip elsewhere, changing the runner command, or making source detect that it runs under test.

## Approach

Adopt `support-files-schema` and `freeze-lint`. Wave 1 runs `env-freeze` (R1, R2) and `witness-lint` (R3, R4) in parallel as subagents. Wave 2 is `verify-frozen-environment`. Manifest declares `support_files`; claims may list support paths; hashes and a canonical runner-argv digest join the signed amendment chain; lint reports no-assert witnesses and new skips. Phase-end reviewer runs (campaign milestone).

## Exit criteria

- Verdict fails when a declared support file or the runner digest changes without a covering amendment.
- Lint flags a no-assert witness and a newly added skip.
- Existing oracle amendment pass/fail cases still hold.

Wave 2 runs acceptance commands and does not add features.
