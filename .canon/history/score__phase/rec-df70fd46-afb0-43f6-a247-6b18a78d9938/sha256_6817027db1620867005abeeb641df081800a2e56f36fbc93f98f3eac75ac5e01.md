## Problem

A `score:effort` carries one goal string. Agents have no recorded why, who for, or how success is measured for a new effort, so each phase re-derives them or guesses.

## Approach

**A separate `score:brief` record per effort** (`brief-storage`, `brief-enforcement`).

- Add a `brief` type to the `score` schema module (lifecycle `current`, `effort` ref, sections `Problem`, `Users`, `Success measure`, `Non-goals`) and bump the module to `1.1.0`. Existing efforts stay valid; nothing backfills them.
- The init skill creates a brief for a new `deliver` effort and none for `repair`, `evaluate`, or `incidental`. The settle-phase skill reads the effort's brief as context.
- `orchestra analyze` does not check for a brief. At Landing the parent runs `canon schemas sync` on the live store.
