## Problem

CI runs no Node tooling. A broken Svelte or TypeScript change merges unchecked. The repo has no lint or format standard for TypeScript and Svelte, and `AGENTS.md` has no section for them.

## Approach

Add one `web` CI job that always runs: `npm ci`, `npm run lint`, `npm run check`, `npm test`, `npm run build` in `dashboard/web/ui` (decision `web-ci-job-shape`). Add Biome with full Svelte support at an exact version, configured by `biome.json` (decision `ts-lint-tool`). Fix the existing findings and keep the gate at zero findings (decision `lint-findings-policy`). Add a TypeScript and Svelte section to `AGENTS.md`. The UI stays at `dashboard/web/ui`. The job uses Node 22 through `actions/setup-node` with the npm cache.

## Exit criteria

- R1: The CI `web` job runs `npm ci`, `npm run lint`, `npm run check`, `npm test`, and `npm run build` in order, with no path filter (test that parses `.github/workflows/ci.yml`).
- R2: `npm run lint` exits 0 on the tree with no findings (command).
- R3: Biome is a pinned devDependency (exact version, no range) and `biome.json` exists (test).
- R4: `AGENTS.md` has a TypeScript and Svelte section that names the three commands (test that greps `AGENTS.md`).
- R5: A deliberate type error fails `npm run check`, and a deliberate lint finding fails `npm run lint` (local test on a temporary copy).
- R6: The `web` job commands pass in order from the real entry point, the `ci.yml` run lines (integration test).
- R7: The `web` job passes on a pushed branch, and two pushed branches with a deliberate type error and a deliberate lint finding fail it (observation in CI runs).

## Proof

kind: commands. A human looks at the green `web` job in a CI run and at the two failing runs for the deliberate type error and lint finding.
