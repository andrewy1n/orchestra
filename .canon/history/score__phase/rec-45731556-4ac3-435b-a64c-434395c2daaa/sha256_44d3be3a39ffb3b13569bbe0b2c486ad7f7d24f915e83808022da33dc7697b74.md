## Problem

Git subprocess wrappers are copied across canon, conductor, tuner, the CLI, and the dashboard. Four modules each define a record-payload getter. `conductor/check.py` and `conductor/suite.py` each define `parse_failing_node_ids` and `_output_sha256`. Tuner calls `ssh-keygen` from `amendment.py`, `attestation.py`, and `human_claim.py`. The stdlib server and the FastAPI app each list the same 11 API routes.

## Approach

Decide at plan-phase. The homes already named are: git and record-payload helpers in `orchestra.canon`; the failing-test parser and output hash in `orchestra.conductor.check`, with suite calling those; signing in `orchestra.tuner`; one route table in `dashboard` used by both servers.

## Exit criteria

- Every acceptance passes.
- An integration check through the real entry points passes: `orchestra check`, suite failing-node parsing, tuner signature verification, and both dashboard web servers answering the same routes. The exact commands are chosen at plan-phase.
