## Problem

Product planning has no home. Ideas live as `score:backlog-item` and `score:feedback`, which belong to work planning. The monorepo plan names `orchestra.composer` with `composer:idea` and `composer:area`, but `composer:area` has no definition yet.

## Approach

Add the `orchestra.composer` package and its `composer` schema module (version 1.0.0) with `composer:idea` and `composer:area`. Register it in the `canon.schemas` entry points. Extend `tests/test_boundaries.py` with composer's import direction. settle-phase defines what an area is and how an idea links to an effort.

## Exit criteria

- `canon init --schemas score,conductor,tuner,composer` creates a store, and `canon create` writes an idea and an area (integration test against a temporary store).
- `tests/test_boundaries.py` passes with composer's import rules.
- `canon schemas add composer` on the live store passes `canon validate`.
