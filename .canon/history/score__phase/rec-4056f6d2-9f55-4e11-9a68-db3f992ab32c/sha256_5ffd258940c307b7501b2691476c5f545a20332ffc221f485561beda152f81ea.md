## Problem

Affidavit starts a new process to write evidence records. A source scan forbids the text `adaptive-artifacts` and `project:`, so those strings are built from pieces. Orchestra's close path learns affidavit's answers from exit codes.

## Approach

**Swap the client** (`affidavit-store-client`, `call-style`, `dependency-direction`).

`observation` and `binding` call `adaptive_artifacts.project.Project` for create and list. The subprocess clients are deleted. The word-ban test is deleted. `is_assertion_level_red`, `run_verdict`, and `recheck` stay the functions they are, and `aff` stays a wrapper. `run_verdict` still does not open a store. This phase edits the affidavit repo only (`three-repos`).

## Exit criteria

R1–R10 in the phase specification hold under the affidavit test suite. `aff --help` still lists verdict, recheck, and assertion-red. No affidavit module starts `adaptive-artifacts`.

## Proof

kind: claims

A human reads tests that spy on `Project.create` and `Project.list`, a test that `run_verdict` returns without a store, and the assertion-red exit codes.
