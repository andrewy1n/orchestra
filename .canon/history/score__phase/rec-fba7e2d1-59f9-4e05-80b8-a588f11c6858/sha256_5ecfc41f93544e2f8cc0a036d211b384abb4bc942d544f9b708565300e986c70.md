## Problem

Audit, probes, and later techniques still emit one-off JSON. The evidence interface only helps if every technique records observations in the same envelope.

## Approach

Plumb `aff audit` (blocks/mutants) and probes through the shared recorder (decision: `technique-record-default`). When a store is usable, runs leave unbound `project:evidence-observation` rows with technique id and replay metadata; advisory JSON stdout stays. Binding remains `aff bind`. Spec/design: `evidence-technique-ingest`.

**Size:** one sitting.

**Human stops:** plan-review only. Landing merge and store commit are mechanical (no push).

**Collision notes:** owns `affidavit/audit.py` recording hooks and shared recorder call sites for audit/probes. Coordinate with `evidence-bind` if the recorder signature is still moving; prefer bind landing first.

## Exit criteria

- Audit/probe runs with a store leave trail-visible unbound observations with technique id and replay metadata.
- `aff trail --technique` filters those rows.
- Without a store, audit JSON/exit unchanged.
- No bindings created by the audit path.
- Phase tests for the above pass under `python3 -m pytest` for the touched files.
