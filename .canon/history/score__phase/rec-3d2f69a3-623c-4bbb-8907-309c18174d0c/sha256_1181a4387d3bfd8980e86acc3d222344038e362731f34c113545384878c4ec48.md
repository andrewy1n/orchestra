## Problem

The dashboard shows status and task details, but you cannot narrow a long task list, hand a task to your Claude session, or see the code a task produced.

## Approach

Store-free actions in the Textual app. `/` filters the task table by text and `d` hides done and withdrawn tasks; the Tasks panel title shows the active filter. `c` copies the selected task's slug to the clipboard (OSC 52) from the dashboard and the detail screen. `g` on the detail screen opens a commit screen for the task's latest reported revision (`git show --stat` plus the commit message, from the repo root). Nothing in the dashboard writes to the store.

## Exit criteria

Filter, hide-done, copy, and commit view work from the keyboard in the popup and the side pane, the footer lists them within 60 columns, the README lists the keys, and the full suite passes. The user signs off on the actions.
