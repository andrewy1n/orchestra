## Problem

The live store exists only as files. Moving it to a DB needs a lossless import, and the team needs a backup path that does not depend on git.

## Approach

Add `canon export` (deterministic JSONL) and `canon import`. Import the real store into a DB and fold every chain. Decide at plan-phase.

## Exit criteria

- Import the real store, fold every chain, and compare each revision hash to the current `records/`. All hashes match. Verified by a script run against a copy of the store.
- Export then import into an empty DB reproduces the same records. Verified by a round-trip test.
