## Problem

`pyproject.toml` installs `orchestra` and its subpackages only. `dashboard` and `installer` import from a checkout because tests and launchers put the repo root on `sys.path`. `orchestra install` imports `installer` lazily and exits 2 when that import fails. `orchestra/cli.py` catches `ModuleNotFoundError` for canon, suite, and check and binds those names to `None`. Session code loads through the `orchestra/_scripts` symlink and a `sys.path` insert. `orchestra.score` holds the schema and an empty package; `effort_rollup` lives in `scripts/effort_rollup.py`. `[project] dependencies` is empty, while the dashboard imports `textual` and `rich` and the web launcher imports FastAPI and uvicorn. `scripts/test.sh` passes `--no-project` and supplies pytest and textual with `--with`, so a declared project dependency would not reach the suite.

## Approach

`dashboard` and `installer` stay top-level packages in the one orchestra wheel (`top-level-dashboard-installer`). The explicit setuptools package list grows to include `dashboard`, `dashboard.web`, `installer`, and `installer.adapters`. `textual`, `rich`, `fastapi`, and `uvicorn` are required dependencies. Session modules move into `orchestra.sessions`, and `effort_rollup` moves into `orchestra.score`. The `_scripts` symlink and the `sys.path` insert go away (`explicit-wheel`).

pytest, pytest-xdist, httpx, pip, setuptools, and wheel go in the `dev` dependency-group. `scripts/test.sh` runs `uv run pytest` and does not pass `--no-project` or `--with` (`suite-project-env`).

## Exit criteria

- An editable install imports `dashboard`, `dashboard.web`, `installer`, and `installer.adapters` with the repository root absent from `sys.path`, and that install imports `textual`, `rich`, `fastapi`, and `uvicorn`.
- Importing `orchestra.cli` raises `ModuleNotFoundError` when canon, suite, or check cannot be imported.
- `orchestra.sessions` loads session code without inserting a directory on `sys.path`, `orchestra/_scripts` is not a symlink, and `effort_rollup` imports from `orchestra.score`.
- `scripts/test.sh` runs `uv run pytest` with no `--no-project` and no `--with`, and it exits 0.
- Every acceptance passes.
