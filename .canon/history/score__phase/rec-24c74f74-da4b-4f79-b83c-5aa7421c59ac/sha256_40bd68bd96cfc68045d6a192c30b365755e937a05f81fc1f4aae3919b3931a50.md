## Problem

The wheel does not ship the built UI. An installed wheel reports "No web build". Nothing tests the real UI against the real server.

## Approach

Run this phase after `wheel-smoke` of the `ci` effort (decision `wheel-smoke-ownership`). The release build runs `npm run build`, and package data ships `dashboard/frontend/dist` (decision `dist-packaging`). Extend the wheel smoke to request `GET /`. Add one Playwright test that starts the server on a seeded store and checks that a seeded effort shows in headless Chromium (decision `e2e-browser-tool`). A source checkout without `dist` shows a message that names the build command.

## Exit criteria

- The built wheel contains `dashboard/frontend/dist/index.html`, and `dist` is gitignored (test).
- The wheel smoke job installs the wheel in a clean environment, and `GET /` returns the UI index (CI job).
- The Playwright test passes locally and in CI.
- Full CI is green on a pushed branch.
- Every acceptance passes, and the installed wheel serves the dashboard (integration check through the real entry point).

## Proof

kind: commands. A human looks at the wheel smoke run and the Playwright test run in CI.
