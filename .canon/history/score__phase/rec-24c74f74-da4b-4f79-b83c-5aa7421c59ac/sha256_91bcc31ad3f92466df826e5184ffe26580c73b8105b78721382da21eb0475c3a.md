## Problem

The wheel does not ship the built UI. An installed wheel reports "No web build". Nothing tests the real UI against the real server.

## Approach

Build the frontend in CI and package `dist` as package data. Extend the wheel smoke test to install the wheel in a clean environment and request the page. Add an end-to-end smoke test that starts the server on a seeded store and checks that the page renders. Decide the browser tool at plan-phase.

## Exit criteria

- The wheel smoke job installs the wheel in a clean environment, and `GET /` returns the UI index (CI job).
- The end-to-end smoke test passes against a seeded store (command named at plan-phase).
- Full CI is green on a pushed branch.
- Every acceptance passes, and the installed wheel serves the dashboard (integration check through the real entry point).
