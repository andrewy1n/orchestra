## Problem

Recording an observation is not the same as asserting that it earns a claim. Without an explicit bind step, every technique run looks like acceptance.

## Approach

Adopt a separate binding record (decisions: `binding-record`, `verdict-no-auto-bind`). Add `project:evidence-binding` and `aff bind` / `unbind` / `recheck`. Observations stay append-only and queryable while unbound. `aff verdict` still records observations when a store is present and never auto-binds. Spec/design: `evidence-bind`.

**Size:** one sitting.

**Human stops:** plan-review only. Landing merge and store commit are mechanical (no push).

**Collision notes:** bind contract and CLI own `contract/project-design.json` for the binding type and `affidavit/` bind/recheck surfaces. Do not start technique-ingest edits to the shared recorder until this phase’s bind API is stable enough to call.

## Exit criteria

- Contract validates with `project:evidence-binding`.
- Fixture: unbound observation → bind → recheck exits 0; unbind or broken pins fail recheck.
- Verdict with a store records an observation and creates no binding.
- Unbound observations remain on `aff trail`.
- Phase tests for the above pass under `python3 -m pytest` for the touched files.
