## Problem

`uv tool install` puts each package in its own environment, and orchestra declares no dependencies. Cursor plugin install does not pull dependencies, so orchestra searches plugin roots and sibling checkouts for the `adaptive-artifacts` binary. The parked `version-compat-check` item asked for a `--version` string comparison, which is the command-line version of a missing dependency.

## Approach

**Dependencies and PATH** (`install-graph`, `version-check`, `dependency-direction`).

Affidavit depends on adaptive-artifacts. Orchestra depends on adaptive-artifacts. The `evidence` extra depends on affidavit. `orchestra install` installs that graph into the environment that provides the command. Discovery through `ADAPTIVE_ARTIFACTS_BIN`, plugin roots, and sibling checkouts is removed. `open_store` raises when the contract format is not one this build supports. Version tags stay on the packaging backlog.

## Exit criteria

R1–R8 in the phase specification hold. A clean install can import `adaptive_artifacts` and run `orchestra --help`. A clean install without the evidence extra cannot import affidavit. A store with format `adaptive-artifacts/project-design@0.0.0` fails to open.

## Proof

kind: commands

A human runs `orchestra install` in a clean environment, imports `adaptive_artifacts`, sees `orchestra --help` succeed, sees affidavit absent, and sees `open_store` reject a store whose contract format is unsupported.
