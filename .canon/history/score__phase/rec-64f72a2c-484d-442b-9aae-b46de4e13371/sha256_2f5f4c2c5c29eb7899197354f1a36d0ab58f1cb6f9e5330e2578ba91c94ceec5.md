## Problem

Phase detail is mostly prose sections, so structure (progress, requirements, next action, waves) is hard to see at a glance.

## Approach

Make the Overview tab a structured dashboard: status chips, progress, next-action line, clickable requirements strip, and wave summary. Leave other tabs as they are. Decisions: `phase-overview-layout`, `phase-overview-requirements`.

## Exit criteria

- Overview shows structured blocks rather than only phase body markdown.
- Requirements strip opens requirement overlays when present.
- Other tabs retain their roles.
- UI tests and a manual look pass.

## Proof

kind: demo

A human opens a structured phase overlay on Overview and can read status, requirements health, and waves without opening Spec.
