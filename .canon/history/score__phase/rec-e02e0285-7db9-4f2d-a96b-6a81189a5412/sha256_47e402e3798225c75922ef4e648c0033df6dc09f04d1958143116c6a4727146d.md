## Problem

`App.svelte` has 1,268 lines. The UI has no component structure, and its pieces are hand-built.

## Approach

Move the UI from `dashboard/web/ui` to `dashboard/frontend`. Split `App.svelte` into screens and components under `src/lib/`. Adopt shadcn-svelte after checking its current version. Migrate tabs and dialogs first. Keep behavior and appearance the same. Update the paths in the Vite config, tsconfig, server, CI, and docs. Decide the screen cut lines at plan-phase.

## Exit criteria

- `npm run check`, `npm test`, and `npm run build` pass in `dashboard/frontend` (commands).
- `components.json` exists and the UI imports shadcn-svelte components (`grep -rn "components/ui" dashboard/frontend/src`).
- The server serves `dashboard/frontend/dist` (`tests/test_web_dashboard_launch.py::test_r30_serves_build`).
- The CI `web` job passes.
- Every acceptance passes, and the built UI renders the snapshot from this repo's store (integration check through the real entry point).
