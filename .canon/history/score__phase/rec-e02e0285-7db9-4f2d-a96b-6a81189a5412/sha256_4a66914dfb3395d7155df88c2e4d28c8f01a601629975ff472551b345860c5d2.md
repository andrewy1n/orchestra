## Problem

`App.svelte` has 1,268 lines, and 613 are script. The UI has no component structure, and its pieces are hand-built.

## Approach

Move `dashboard/web/ui` to `dashboard/frontend`. Move polling, journal, and overlay state into `.svelte.ts` modules, and split the markup into Home, Journal, Overlay, and Side rail components (decision `app-split`). Initialize shadcn-svelte with a `$lib` alias and adopt its default theme (decisions `shadcn-svelte` and `shadcn-appearance`). Migrate tabs and dialogs first. Update the Vite config, tsconfig, server path, CI, and docs for the new folder.

## Exit criteria

- `dashboard/web` is gone, the server serves `dashboard/frontend/dist`, and `App.svelte` has fewer than 150 lines (test that checks the tree).
- `components.json` exists with `$lib` aliases, and the tab and dialog components import shadcn-svelte (grep).
- `npm run lint`, `npm run check`, `npm test`, and `npm run build` pass in `dashboard/frontend`.
- The existing router and deep-link Vitest files pass unchanged.
- Every acceptance passes, and the built UI renders the snapshot from this repo's store with the shadcn theme (integration check through the real entry point).

## Proof

kind: demo. A human looks at the running UI to confirm every screen renders in the new theme.
