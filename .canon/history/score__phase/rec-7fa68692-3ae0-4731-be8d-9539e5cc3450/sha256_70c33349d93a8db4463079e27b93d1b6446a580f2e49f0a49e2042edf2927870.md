## Problem

The session that builds also grades. Acceptances can pass while the work-item description is unmet (dogfood: `status-tabs`). There is no independent, read-only review of the phase diff against task specs before merge.

## Approach

Decisions: phase-reviewer-scope (phase-end core; defer per-task and pre-dispatch coverage), reviewer-inputs (specs + acceptances + invariants + phase diff only). Structured work: specification and design `phase-reviewer`.

Ship a read-only reviewer agent; parent records `method: review` check-run and findings; fixable gaps become retry-loop fix tasks with one re-run; integration report from reviewer output; phase gate requires passing review at head. Out of scope: per-task review, plan-time coverage check, tier-2 suite.

## Exit criteria

- Reviewer agent exists with restricted tools; execute-phase invokes it at phase end with input limits proven by test.
- Parent records review check-run + findings; reviewer writes nothing.
- Fixable NEEDS_WORK creates fix tasks under retry budget; one re-run; budget exhaustion escalates.
- Phase gate requires passing review at head before merge.
- `status-tabs` fixture returns NEEDS_WORK / spec-gap.
- Integration report comes from reviewer output; skill↔contract consistency stays green.
