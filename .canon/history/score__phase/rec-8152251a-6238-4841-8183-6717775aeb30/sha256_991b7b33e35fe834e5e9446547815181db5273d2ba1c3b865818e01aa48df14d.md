## Problem

Interaction-level bugs escaped because tests ran at the wrong evidence level. A unit test can fail at base and pass at head while the feature is still broken.

## Approach

not yet scoped — discuss when this phase is current. Direction: a manifest claim declares `evidence_kind` (unit, integration, interaction). Verdict refuses a witness whose tests or runner template do not match the declared kind. The runner adapter gains templates for interaction runners (tmux-driven, CLI end-to-end, browser) so the declaration can be met.

## Exit criteria

Decide at plan-phase. At minimum: verdict fails a claim declared `interaction` whose witness is a unit test, and passes one witnessed through an interaction runner template.
