## Problem

The phase opens as an overlay with its own tabs. It sits outside the drill-down that `area-levels` adds, so the breadcrumb ends at the effort.

## Approach

Build on `area-levels`. The phase becomes the fourth level, a routed page at `#/phase/<effort>/<phase>`: breadcrumb `Product › Area › Effort › Phase`, a header with state, stats, status tabs and the task list. The sections of today's phase overlay (evidence, journal, task graph) become sections of the page. Phase rows on the effort screen link to it. The left rail lists the phases of the effort. Existing `#/phase/...` deep links keep working.

The overlay is removed once the page covers its tabs.

## Exit criteria

Decide at settle-phase. The phase still ends with every acceptance passing and the Playwright test opening a phase page through the real server.
