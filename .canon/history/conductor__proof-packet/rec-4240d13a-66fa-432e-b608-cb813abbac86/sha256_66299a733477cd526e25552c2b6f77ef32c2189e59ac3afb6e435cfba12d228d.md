## Look

kind: demo. Run the dashboard from the phase worktree (`cd /home/andrewyin/orchestra/.worktrees/phase-level/dashboard/frontend && npm run build`, then start the dashboard server) and open `#/effort/<effort>`.

1. The effort page lists its phases as rows, each with a done/total count and a progress bar. It has no task table and no status tabs.
2. Click a phase row. The URL becomes `#/phase/<effort>/<phase>`. The phase renders in the main pane, not in a dialog. The breadcrumb reads `Product › <area> › <effort> › <phase title>`, or `Product › <effort> › <phase title>` when the effort has no area.
3. The header shows the phase title and state. Chips, the next action and one button per requirement sit under it. The tabs switch the page between overview, spec, design, tasks and evidence. The overview tab carries the task graph, the status tabs and the task list.
4. The left rail lists the phases of the effort and marks the current one. Done phases fold behind a button.
5. Click a task row, or a requirement button. The task or requirement opens as a modal and the phase page stays behind it. Close it, and the URL returns to the phase page.
6. Press Esc on the phase page. The effort page opens.
