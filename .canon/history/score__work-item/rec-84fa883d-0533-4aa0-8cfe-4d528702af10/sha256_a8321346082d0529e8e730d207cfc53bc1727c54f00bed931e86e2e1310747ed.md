## Description

In ~/adaptive-artifacts, add watch --id <view> [--interval S] [--once]. Each interval it re-renders the view through the terminal formatter and redraws in place only when the text changes. A header line shows the store path and the last change time. Ctrl-C exits 0. A render error shows in place and the loop keeps trying. --once prints one frame and exits. Waits for terminal-view-format.
