## Description

R12: `orchestra.sessions.report` does not insert a directory on `sys.path`.
R13: `orchestra.sessions.aggregate` does not insert a directory on `sys.path`.
R14: `orchestra/_scripts` is not a symlink.

## Approach

This branch starts from `phase/wheel-contents` after `declare-wheel` and `score-effort-rollup` have merged. `orchestra/score/effort_rollup.py` is already in place. The import-block change from `propagate-import-errors` is already in `orchestra/cli.py`.

1. Replace `orchestra/sessions.py` with the package `orchestra/sessions/`. `report` and `aggregate` stay the functions `orchestra.cli` imports.
2. Move these modules from `scripts/` into `orchestra/sessions/`: `session_report`, `session_aggregate`, `record_join`, `record_reader`, `session_fields`, `session_metrics`, `session_outliers`, `session_tools`, and `tool_skill_rollup`. Their cross-imports become `orchestra.sessions` package imports. `session_aggregate` imports `effort_rollup` from `orchestra.score`.
3. Delete the `sys.path` insert and the `ORCHESTRA_SCRIPTS` lookup. `report` and `aggregate` import their submodules directly.
4. Delete the `orchestra/_scripts` symlink. Leave `scripts/build_skills.py`, `scripts/check_orchestra_plugin_names.py`, and `scripts/test.sh` in `scripts/`.
5. Add `orchestra.sessions` to `[tool.setuptools] packages`.
6. In the `sessions` command in `orchestra/cli.py`, stop catching `ModuleNotFoundError`. Leave the top-of-file canon, suite, and check imports as `propagate-import-errors` left them.
7. Update tests that import the old script modules (`tests/test_session_report.py`, `tests/test_session_aggregate.py`, `tests/test_analyze_sessions_targets.py`, and any other `import session_report` / `import session_aggregate`) so they import from `orchestra.sessions`. Do not edit `tests/test_wheel_contents.py`, `tests/test_cli_packaging.py`, `orchestra/composer/`, or any `idea-triage` worktree.
