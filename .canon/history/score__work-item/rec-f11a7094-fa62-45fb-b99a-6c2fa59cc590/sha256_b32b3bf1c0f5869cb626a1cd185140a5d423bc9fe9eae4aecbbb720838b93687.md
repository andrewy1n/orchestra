## Description

Add a detail screen to `scripts/dashboard_app.py`. Enter or a mouse click on a task row pushes it. It shows the header, the description as rendered markdown, acceptances with result glyphs, the timeline with collapsible report bodies, and related records. It scrolls, refreshes on store change, and Esc returns to the dashboard on the same row. Footer shows the new keys. Update the README keys. Waits on the loader.
