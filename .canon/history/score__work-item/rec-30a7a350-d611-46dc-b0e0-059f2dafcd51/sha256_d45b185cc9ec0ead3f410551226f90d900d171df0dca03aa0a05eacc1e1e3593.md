## Description

R9: The dashboard backlog panel lists each open `composer:idea` that carries an effort, grouped by effort.
R10: Dashboard promote supersedes an open `composer:idea` to status `promoted`.
R11: Dashboard dismiss supersedes an open `composer:idea` to status `dismissed`.

## Approach

In `dashboard/backlog.py` set `BACKLOG_TYPE` to `composer:idea`; keep function names and signatures. In `dashboard/model.py` replace every `score:backlog-item` string (the type lists near the top, the `BacklogItem.record_type` default, `_backlog_items`, and the `listed.get(...)` call in the model build) with `composer:idea`. The panel keeps its shape: open ideas that carry an effort, grouped by effort. Update the existing tests that create `score:backlog-item` records (`tests/test_dashboard_app.py`, `tests/test_dashboard_model.py`, `tests/test_web_dashboard.py`, `tests/test_web_fastapi_writes.py`) to create `composer:idea`. Do not edit `tests/test_idea_dashboard.py`; it is a frozen oracle.
