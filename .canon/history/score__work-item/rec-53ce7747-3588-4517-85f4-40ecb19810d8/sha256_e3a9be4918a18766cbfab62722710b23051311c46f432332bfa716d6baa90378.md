## Description

R1: `orchestra idea "<title>"` creates an open `composer:idea` whose subject is the slugified title.
R2: `orchestra idea` writes the title as the first line of the idea body.
R3: `orchestra idea --area <slug>` sets the idea's area.
R4: `orchestra idea --effort <slug>` sets the idea's effort.
R5: `orchestra idea --source <text>` sets the idea's source.
R6: `orchestra idea --body-file <path>` appends the file text to the idea body below the title.
R7: `orchestra idea` exits non-zero and writes nothing when an idea with the derived subject exists.
R8: `orchestra idea` exits non-zero and writes nothing when `--area` names no active `composer:area`.
R9: `orchestra idea` exits non-zero and writes nothing when `--effort` names no active `score:effort`.

## Approach

Create `orchestra/composer/idea.py` (imports only `orchestra.canon`): `slugify(title)` (lowercase ASCII via NFKD, runs of non-alphanumerics become one hyphen, trimmed, capped at 60 characters, an empty result raises `IdeaError`), `class IdeaError(Exception)`, and `capture(project, title, *, area=None, effort=None, source=None, body=None)` that checks no `composer:idea` with that subject exists, builds the body as `# <title>` then a blank line and `body` when given, and calls `project.create(record_type='composer:idea', subject=slug, payload={'status':'open', plus area/effort/source when given}, body=...)`. Canon refuses unknown area or effort refs; let that error surface as `IdeaError` and write nothing. In `orchestra/cli.py` add an `idea` subcommand (`title`, `--area`, `--effort`, `--source`, `--body-file`) that opens the store from the cwd with `open_store(Path.cwd())`, calls `capture`, prints the subject, and exits 1 with a message on `IdeaError` or store errors. Add `idea` to any command allow-list the CLI keeps. Write `tests/test_idea_capture.py` covering R2, R4, R5, R6 and R9 through the real command line. Do not edit the frozen oracle `tests/test_idea_command.py`.
