## Description

On the combined layout branch, test_stepper_wraps_by_pane_width_and_keeps_glyph_with_label fails about 3 in 10 runs: the stepper is laid out for a content width that a vertical scrollbar later narrows, and EffortPane.on_resize does not fire for a scrollbar change, so the stepper (and anything else sized from inner) stays too wide and soft-wraps. Confirm the cause, then fix it (for example scrollbar-gutter: stable on the effort pane, or re-show when the scrollable content width changes). Make the test deterministic.
