## Description

Prove the phase exit criteria hold together: run `bin/aff` as the entry point, then the orchestra commands, the import boundary, and the skill command scan.

## Approach

1. `python3 -m pytest tests/test_standalone_cli.py -q -k verdict_without_runtime`
2. `python3 -m pytest tests/test_standalone_cli.py -q -k rejects_store_commands`
