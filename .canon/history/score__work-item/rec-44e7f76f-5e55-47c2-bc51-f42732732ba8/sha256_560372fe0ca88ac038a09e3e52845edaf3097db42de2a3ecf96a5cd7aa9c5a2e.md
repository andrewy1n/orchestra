## Description

R1: The CI job `web` runs `npm ci`, `npm run lint`, `npm run check`, `npm test`, and `npm run build` in `dashboard/web/ui`, in that order. The integration test that runs these lines must not change the real `node_modules`.

## Approach

In `tests/test_web_gate.py`, run every `web` job line, including `npm ci`, in a temporary copy of the UI that has its own `node_modules`. Do not symlink the real `node_modules` for that test. The test keeps asserting that the job exists and that every line exits 0. Oracle-author amends the test; the parent re-freezes the hashes.
