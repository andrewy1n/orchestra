## Description

R1: An editable install imports `dashboard` when the repository root is absent from `sys.path`.
R2: An editable install imports `dashboard.web` when the repository root is absent from `sys.path`.
R3: An editable install imports `installer` when the repository root is absent from `sys.path`.
R4: An editable install imports `installer.adapters` when the repository root is absent from `sys.path`.
R5: That install imports `textual`.
R6: That install imports `rich`.
R7: That install imports `fastapi`.
R8: That install imports `uvicorn`.
R19: `uv run python -c "import pytest"` succeeds at the repository root.
R20: `uv run python -c "import xdist"` succeeds at the repository root.
R21: `uv run python -c "import httpx"` succeeds at the repository root.
R22: `uv run pip --version` succeeds at the repository root.
R27: `installer.matrix` loads `providers.json` from the installed `installer` package.

## Approach

Edit `pyproject.toml` only, plus `uv.lock` if resolving the new dependencies rewrites it.

1. Append `dashboard`, `dashboard.web`, `installer`, and `installer.adapters` to `[tool.setuptools] packages`. Leave `orchestra.sessions` off this list; `sessions-package` adds it.
2. Add `installer = ["providers.json"]` under `[tool.setuptools.package-data]`. Keep the existing orchestra and schema entries. `installer.matrix` already reads `providers.json` via `Path(__file__).with_name("providers.json")`; package-data is what puts that file next to the installed module.
3. Set `[project].dependencies` to `textual>=0.80`, `rich`, `fastapi`, and `uvicorn`.
4. Add `[dependency-groups] dev` with `pytest`, `pytest-xdist`, `httpx`, `pip`, `setuptools`, and `wheel`. Do not put those on `[project].dependencies`.
5. Do not edit `orchestra/composer/`, `tests/test_cli_packaging.py`, `tests/test_wheel_contents.py`, or any `idea-triage` worktree.
