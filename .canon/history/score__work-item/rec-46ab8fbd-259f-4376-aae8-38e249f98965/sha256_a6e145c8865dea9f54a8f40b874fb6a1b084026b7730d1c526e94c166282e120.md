## Description

The full suite takes 3-5 min, run serially. Most time is `adaptive-artifacts` subprocess calls (~0.22 s each): every test seeds a fresh temp store record by record, and each dashboard load runs 8 `list` calls. Build each seeded store once per session and copy it per test; give pure layout pilot tests a built snapshot instead of the CLI, keeping a few end-to-end tests on the real CLI. Do not add pytest-xdist: parallel runs raise CPU load and tmux lag. Start after task-navigation is done, since it edits the same tests.
