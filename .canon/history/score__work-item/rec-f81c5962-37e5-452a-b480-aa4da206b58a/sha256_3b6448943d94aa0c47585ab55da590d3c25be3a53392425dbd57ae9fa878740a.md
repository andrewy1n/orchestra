## Description

R3: GET /api/snapshot returns that store's efforts, phases, tasks, needs-you items, and backlog items produced by dashboard.model.
R4: GET /api/token returns the current dashboard.model.change_token value for that store.

## Approach

- Add an importable FastAPI app at `dashboard/web/app.py` with `create_app(target)`.
- Cache `dashboard.model` snapshots by `change_token`, including lazy detail loads, the way the spike `Cache` does.
- Serve GET `/api/token`, `/api/snapshot`, `/api/phase`, `/api/task`, `/api/journal`, `/api/record`, `/api/requirement`, `/api/needs`, and `/api/backlog`. Snapshot efforts use the spike `effort_summary` fields. Phase responses include `tabs_for` and the decision log. Needs responses include `revision` and `approval.confirm_choices`.
- Do not add CORS. Do not add write routes in this task.
- Make `tests/test_web_dashboard.py::test_r3_snapshot` and `test_r4_token` pass.
