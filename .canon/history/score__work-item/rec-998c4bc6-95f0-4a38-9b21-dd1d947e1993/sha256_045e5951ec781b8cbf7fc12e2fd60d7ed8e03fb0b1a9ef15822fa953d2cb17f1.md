## Description

`execute-phase` still shows one-line `git commit -m "<task-slug>"` messages, and ensure-store's records commit is one line with an empty body.

## Approach

1. In `~/orchestra/skills/execute-phase/SKILL.md`, replace the three snippets `git commit -m "<task-slug>"`, `git commit -m "<phase-slug>"`, and `git commit -m "<phase-slug> store"` with heredoc commits. 2. In `~/orchestra/skills/ensure-store.md`, replace `git commit -m "records: <what changed>"` with the same shape.
3. Extend `tests/test_task_commit.py` so a subject with an empty body fails, all three execute-phase snippets match the pattern, the task body names the task slug, and the ensure-store records commit matches the same pattern.
