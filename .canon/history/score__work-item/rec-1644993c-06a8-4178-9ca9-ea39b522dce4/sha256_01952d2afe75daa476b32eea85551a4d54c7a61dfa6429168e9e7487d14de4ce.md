## Description

Prove the phase exit criteria together: the CLI accepts the new fields, the contract and skill tests pass, `dashboard/` is unchanged, and the full suite passes.

## Approach

Depends on `estimate-contract` and `estimate-skill`.

1. Add `tests/test_estimate_cli.py`. Use `build_store` and the CLI subprocess the way `conftest.py` does. Do not import the adaptive-artifacts runtime. Create a phase, then a work-item with `size` `L` and `estimate_minutes` 25, and assert validate succeeds and get returns those values. Assert `estimate_minutes` 0 succeeds, a work-item that omits both succeeds, and `size` `XXL` is rejected. Assert a phase payload still has no `size` or `estimate_minutes`.
2. Run `uv run --with pytest python -m pytest tests/test_estimate_cli.py tests/test_estimate_contract.py tests/test_estimate_skill.py tests/test_skill_contract_consistency.py tests/test_plan_wave_rules.py tests/test_plan_trace.py -q`.
3. Confirm `git diff --name-only main -- dashboard/` is empty.
4. Run the full suite: non-tmux tests in parallel, then the tmux tests.

Do not edit `dashboard/` or `~/adaptive-artifacts`.
