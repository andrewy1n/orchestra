## Description

R1: `aff audit` runs declared probes (a command or function plus inputs) at base and at head and compares results.
R2: The audit reports a difference that no cited claim id accounts for.
R3: The audit does not report a difference that is covered by a cited claim id.

## Approach

1. Add a committed probe declaration (`.affidavit/probes.json` or manifest `probes`) with entries `{id, kind, ...}` where `kind` is `cli` (argv list) or `function` (module:callable + args), plus optional `claims` (claim ids that cover expected diffs).
2. In `affidavit/audit.py`, load probes, run each at base and head worktrees, compare with coarse CLI comparison by default (stdout/stderr/exit_code normalized), and append unclaimed diffs to the advisory JSON as `diffs` (empty when none).
3. A diff is unclaimed when no cited claim id is listed on that probe (or the cite does not match); a probe that lists a claim id that exists in the head manifest suppresses reporting that probe's difference.
4. Extend `aff audit` only; do not change verdict. Do not edit frozen oracles after freeze.
