## Description

Read the committed manifest and allowlist from a git revision, and hash oracle files at that revision. No test run and no signature check.

## Approach

Add `affidavit/manifest.py`.

- `resolve_commit(cwd, rev)` runs `git -C cwd rev-parse --verify <rev>^{commit}` and raises if the revision is not a commit.
- `merge_base(cwd, at, main='main')` returns `git merge-base`.
- `load_manifest(cwd, revision)` reads `.affidavit/manifest.json` with `git show <revision>:.affidavit/manifest.json`. Parse `claims` into id, text, tests (node-id list), and oracle_hashes (`{relpath: "sha256:<hex>"}`). Return `amendments` as parsed objects without checking signatures. Missing file or invalid JSON raises a typed error.
- `load_allowlist(cwd, revision)` returns the raw bytes of `.affidavit/allowed_signers` from `git show`.
- `hash_oracle_files(cwd, revision, relpaths)` hashes each path via `git show <revision>:<relpath>` and returns `sha256:<hex>`. A missing path raises `FileNotFoundError`.

Tests in `tests/test_manifest.py` use a temporary git repo with two commits. Cover a round-trip parse, a hash that matches the blob at that revision, an allowlist blob that changes between commits, a non-commit revision that fails, and a dirty worktree file that `git show` ignores.

Do not edit `affidavit/cli.py`, `affidavit/verdict.py`, `affidavit/amendment.py`, or `affidavit/oracle_red.py`.
