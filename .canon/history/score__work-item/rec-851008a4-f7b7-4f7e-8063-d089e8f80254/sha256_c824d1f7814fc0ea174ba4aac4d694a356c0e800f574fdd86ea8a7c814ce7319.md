## Description

Once `~/orchestra` has the moved tree, this repo drops those paths and keeps the `aff` verbs.

## Approach

1. Delete `skills/`, `dashboard/`, `scripts/`, `agents/`, `affidavit/reviewer.py`, `affidavit/suite.py`, `affidavit/tier2.py`, and the test modules that were copied to orchestra. Delete `.cursor-plugin/` and `.claude-plugin/` here; the plugin now lives in orchestra.
2. Keep `affidavit/aa.py`, `aa_resolve.py`, `check.py`, `close_batch.py`, `verdict.py`, `manifest.py`, `amendment.py`, `oracle_red.py`, `cli.py`, `policy.py`, and `bin/aff`.
3. In the tests that stay, drop cases that require `scripts/sync-plugin.sh`, `skills/`, `dashboard/`, or `agents/`. `tests/test_affidavit_check.py` currently asserts `dashboard/bin` in the README and runs `scripts/sync-plugin.sh`; move those cases out of this repo's remaining suite. Split `tests/test_aa_resolve.py` so only the `affidavit.aa_resolve` command-resolution cases stay; the dashboard binary case stays in orchestra.
4. Add `tests/test_evidence_layout.py` asserting those four directories are absent, `affidavit.tier2` and `affidavit.suite` do not import, and `affidavit/aa.py` does not mention `dashboard`.
5. Do not edit `~/orchestra`.
