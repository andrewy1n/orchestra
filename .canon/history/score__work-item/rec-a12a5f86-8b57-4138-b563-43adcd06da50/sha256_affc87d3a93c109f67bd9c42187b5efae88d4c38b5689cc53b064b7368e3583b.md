## Description

R16: `scripts/test.sh` invokes pytest through `uv run`.
R17: `scripts/test.sh` does not contain `--no-project`.
R18: `scripts/test.sh` does not contain `--with`.
R23: `README.md` does not contain `--no-project`.
R24: `AGENTS.md` does not contain `--no-project`.
R25: The fallback suite commands in `orchestra.conductor.suite` do not contain `--with`.
R26: The fallback suite commands in `orchestra.conductor.suite` do not contain `--no-project`.

## Approach

1. Rewrite the `run` helper in `scripts/test.sh` to `uv run -q pytest` plus the pytest arguments it already passes (`-q -p no:cacheprovider`, `-n 4`, `--confcutdir`, `--ignore`, and `-m tmux`). Pass no `--no-project` and no `--with`. Keep the four invocations: canon, tuner, the orchestra tree, and the tmux marker.
2. Remove `--no-project` from `README.md` and `AGENTS.md`. Point those suite examples at `uv run pytest` or `uv run python -m pytest`. Change only the command lines that carry that flag. `phase/idea-triage` also edits `README.md`; do not rewrite composer or idea sections.
3. In `orchestra/conductor/suite.py`, rewrite `FAST_SUITE_CMD` and `TMUX_SUITE_CMD` to `uv run` pytest commands with no `--with` and no `--no-project`. Keep the same pytest selection (`-n 4`, `-m "not tmux"`, `-m tmux`).
4. Do not edit `tests/test_cli_packaging.py`, `tests/test_wheel_contents.py`, or any `idea-triage` worktree.
