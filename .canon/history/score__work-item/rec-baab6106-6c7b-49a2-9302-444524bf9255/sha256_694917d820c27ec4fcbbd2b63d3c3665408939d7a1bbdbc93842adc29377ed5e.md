## Description

The task table groups rows under phase header rows in ordinal order. In-progress and awaiting-sign-off phases expand, done and planned collapse; more than two done phases fold into one 'N earlier phases done' row that expands on enter. enter or click toggles a header; p opens a phase detail screen with the phase body, its decisions and constraints, and its tasks. The model marks a phase awaiting sign-off when every open task waits only on an unsigned manual check. The progress bar covers the whole effort. Waits on status-tabs.
