## Description

R1: No Python file under `dashboard/` or `orchestra/` imports `textual`.
R2: `pyproject.toml` does not list `textual` as a dependency.
R3: `pyproject.toml` lists `rich` only if a surviving module imports it.
R4: `orchestra.tmux`, `dashboard/bin/dashboard`, and `dashboard/bin/dashboard-status` do not exist.
R5: The CI file has no tmux job, and `pytest.ini` has no `tmux` marker.
R11: The README has no tmux dashboard section.

## Approach

Delete the Textual modules (`app.py`, `__main__.py`, `matrix.py`, `selection.py`, and the screen modules that are now unused: `phase_screen.py`, `requirement_detail.py`, `task_detail.py`, `tasks.py`, `commit.py`, `display.py`, `pager.py` where nothing survives). Delete `orchestra.tmux`, `dashboard/bin/dashboard`, `dashboard/bin/dashboard-status`, the tmux tests (`tests/test_tmux_entry.py`, `tests/test_tmux_integration.py`, and the Textual tests such as `test_dashboard_app.py`, `test_dashboard_launcher.py`, `test_dashboard_status.py`, `test_dashboard_phase_screen.py`, `test_dashboard_requirement.py`, `test_dashboard_uv_env.py`, and Textual parts of other tests; keep tests of surviving code), the `test-tmux` CI job, and the `tmux` marker in `pytest.ini`. The phase suite command in `.canon/config.json` uses a tmux pass for the suite; leave `.canon/config.json` alone and report it. Remove the README sections on the tmux dashboard. Drop `textual` from `pyproject.toml` and refresh `uv.lock` with `uv lock`; drop `rich` if no surviving module imports it. Fix `tests/test_wheel_contents.py` and `tests/helpers.py` where they name `textual`. Remove baseline entries for deleted files in the basedpyright baseline. The web server must still start after this task: run `uv run pytest tests/test_web_dashboard.py tests/test_web_dashboard_launch.py -q`.
