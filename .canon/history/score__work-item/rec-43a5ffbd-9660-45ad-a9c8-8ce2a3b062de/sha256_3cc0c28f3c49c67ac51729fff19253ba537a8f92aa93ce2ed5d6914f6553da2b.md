## Description

R14: `GET /api/areas` lists, for each area, the promoted ideas whose effort is placed in that area.

## Approach

Edit `dashboard/backend/areas.py`, function `load_areas`. Read the active `composer:placement` records (subject = effort slug, payload `area`). Build a map from effort to area. An idea with status `promoted` and an `effort` joins the area its effort is placed in. When the effort has no placement, the idea keeps the area in its own `area` payload. An open idea keeps its own `area`. The response shape of `GET /api/areas` does not change, so `openapi.json` and `src/api-types.ts` stay as they are. The oracle test for R14 is in `tests/dashboard/test_areas.py` and is frozen: make it pass without editing it. Run `uv run pytest tests/dashboard/test_areas.py tests/dashboard/test_endpoint_shapes.py -q`. Run `uvx ruff@0.13.1 check dashboard tests/dashboard` and `uv run basedpyright dashboard`.
