## Description

R2: `npm run lint` exits 0 on `dashboard/web/ui` with no findings.
R3: `@biomejs/biome` is an exact-version devDependency and `biome.json` exists.

## Approach

In `dashboard/web/ui`, install `@biomejs/biome` at `2.6.4` with `npm install --save-dev --save-exact`. Add `biome.json` with Svelte support enabled, `dist` and `node_modules` ignored, and the recommended lint rules. Add the script `"lint": "biome lint ."`. Run `npx biome lint --write` for safe fixes, then fix the rest by hand. Do not suppress rules to reach zero findings, except a rule that conflicts with Svelte (turn it off in `biome.json` with a one-line reason in the commit). After the fixes, `npm run check`, `npm test`, and `npm run build` must still pass.
