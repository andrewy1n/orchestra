## Description

A pushed full-screen `RequirementDetailScreen` that shows one requirement's evidence. Wave 3 opens it from phase detail, Needs you, and task detail.

## Approach

Create `dashboard/requirement_detail.py` with `RequirementDetailScreen(target, effort, phase, requirement)`, modelled on `dashboard/task_detail.py`: it loads with `model.load_requirement_detail` in a worker, redraws on the app's store-change refresh, binds esc back, c copy, r refresh.

Sections: header chips (id, status, next, phase), requirement text, decisions (subject and choice), traced tasks as a link list where enter pushes `TaskDetailScreen`, acceptances with the latest check result and evidence kind, and the assessment history oldest first (status, level, next, confidence). An unassessed requirement shows `unassessed` with the latest check result dimmed. Use the app palette; no line wider than the pane.

Do not edit `dashboard/app.py`, `dashboard/tasks.py`, `dashboard/task_detail.py`, or `dashboard/model.py`. Pilot tests in the new `tests/test_dashboard_requirement.py` push the screen directly on a seeded store, at 60 and 120 columns.
