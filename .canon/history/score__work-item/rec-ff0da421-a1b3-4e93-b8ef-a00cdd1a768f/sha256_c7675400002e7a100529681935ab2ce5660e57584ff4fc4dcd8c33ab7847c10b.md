## Description

R14: The `init` skill runs `orchestra place <effort> <area>` after it creates a new effort whose routing line names an area.
R15: The `engage` skill's routing line carries `area: <slug>` for a new effort.

## Approach

Fix for the phase review finding on `engage-place-step`: `engage` stops at the handoff to `init`, so a step in `engage` that runs after `init` never executes. In `skills/engage/SKILL.md`, reword step 5: for a new effort, ask which area it belongs to and add `area: <slug>` to the routing line; do not run `orchestra place` there. Keep the words `orchestra place` in that step as the command `init` runs. In `skills/init/SKILL.md`, add a step right after the one that creates the effort: when the routing line names an area, run `orchestra place <effort> <area>`. Keep the wording short. Run `python3 scripts/build_skills.py --check`; if it reports drift, run the generator.
