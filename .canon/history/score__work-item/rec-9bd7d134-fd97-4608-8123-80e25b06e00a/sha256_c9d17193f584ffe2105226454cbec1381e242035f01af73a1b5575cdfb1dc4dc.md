## Description

Add scripts/effort_rollup.py with effort_rollup(rows). Input is session rows from session_report.py --records. A row counts toward each effort in records.efforts. Per effort: sessions, exclusive sessions (only that effort), turns, tool calls, errors, retries, cost_shared (all sessions) and cost_exclusive (exclusive sessions only). Rows without records or with an error key are skipped.
