## Description

Wire navigation into `RequirementDetailScreen` once both wave 2 tasks have merged.

## Approach

- Phase detail requirement list: enter pushes `RequirementDetailScreen(target, effort, phase, id)`; esc returns to the phase detail.
- Needs you: enter on a `loop-route` item pushes the requirement screen; an `integration` item keeps the Needs-you detail.
- `dashboard/task_detail.py`: list the work-item's `requirements` and `decisions` from its payload (no extra CLI call; keep `test_detail_uses_four_cli_calls` green). Requirement entries use link key `req:<phase>:<id>` and open the requirement screen; decision entries show the subject and are not links.

Pilot tests in `tests/test_dashboard_app.py`, names containing `evidence` and `link`.
