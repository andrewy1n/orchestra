## Description

Update the task table helpers so a selected phase scopes counts, rows, and progress while `All phases` keeps today's grouped table.

## Approach

1. Add a `selected_phase` argument to `tasks.counts`, `tasks.tab_tasks`, and `tasks.section_rows`. When a phase is selected, only its tasks count; when `None` (All phases), keep current effort-wide grouping.
2. Add `phase_progress(view, phase)` returning done/total for a single phase.
3. Remove the `wave` column from `task_columns` and drop `wave_cell` usage in `task_cells`.
4. In `All phases` mode keep collapsible phase sections and the fold row. In selected-phase mode emit task rows only with no section headers.
5. Update `tests/test_dashboard_tasks.py` with seeded tests for scoped counts, selected-phase rows, and unchanged All-phases grouping.
