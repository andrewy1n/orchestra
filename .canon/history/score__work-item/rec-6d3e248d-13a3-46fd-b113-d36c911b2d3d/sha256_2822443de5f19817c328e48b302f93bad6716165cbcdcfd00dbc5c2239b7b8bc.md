## Description

R3: Phases with no milestone appear in an Ungrouped group after all milestone groups.
R7: A milestone whose state is done starts collapsed; the user can expand and collapse it.
R8: The milestone that contains the currently selected phase (or the default phase when following) starts expanded.

## Approach

Add `MilestoneRow` to `types.ts` and type `EffortView.milestones` as `MilestoneRow[]`. Add pure helpers `groupPhasesByMilestone(effort)` and `initialExpandedMilestones(effort, phaseSubject)` in `efforts.ts` or a small `milestones.ts`. Cover with vitest fixtures: grouping order, Ungrouped last, done milestones omitted from the initial expand set, current/default phase milestone included.
