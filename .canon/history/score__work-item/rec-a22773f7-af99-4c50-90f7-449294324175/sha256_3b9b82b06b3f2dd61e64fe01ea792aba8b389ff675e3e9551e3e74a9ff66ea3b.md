## Description

Copy the store client into the orchestra package and point orchestra's existing callers at it, leaving the affidavit copies in place for the strip task.

## Approach

Work on branch `phase/standalone-aff` in `~/orchestra`. Do not delete anything from `~/affidavit`.

1. Copy `check.py`, `close_batch.py`, `aa.py`, `aa_resolve.py`, and `policy.py` from `~/affidavit/affidavit/` into `orchestra/`. Rewrite `affidavit.aa` and `affidavit.policy` to `orchestra.aa` and `orchestra.policy`. `close_batch.py` keeps `from affidavit.oracle_red import is_assertion_level_red` and imports `aa` from `orchestra`.
2. Add `orchestra/cli.py` with only `check` and `close-batch`, using the arguments in `affidavit/cli.py`. It imports `orchestra.check` and `orchestra.close_batch`. It does not import `affidavit.cli` or `affidavit.verdict`.
3. Add `bin/orchestra`, the same launcher shape as `~/affidavit/bin/aff`, calling `orchestra.cli.main`. Insert the orchestra checkout on `sys.path` before that import.
4. Copy `~/affidavit/affidavit.tmux` to `~/orchestra/affidavit.tmux`. Orchestra tests already load that path. The script's `dashboard/bin` paths are relative to the file, so they resolve at the orchestra root. Do not rename it.
5. Copy `tests/test_affidavit_check.py`, `tests/test_close_batch.py`, and `tests/test_affidavit_aa.py` into `orchestra/tests/` and retarget their imports to `orchestra`. Merge `~/affidavit/tests/test_aa_resolve.py` into the existing `orchestra/tests/test_aa_resolve.py`. Do not overwrite that file.
6. Retarget callers: `orchestra/suite.py` imports `orchestra.aa`, `orchestra.check`, and `orchestra.policy`. `dashboard/artifact_store.py` imports `orchestra.aa_resolve`. `tests/test_verify_authority.py` imports `orchestra.close_batch`. `orchestra/__init__.py` still puts the affidavit checkout on `sys.path`; its docstring says that is for `affidavit.oracle_red`.
7. Add `tests/test_affidavit_import_boundary.py`. It fails if any `*.py` under `orchestra/` or `dashboard/` imports `affidavit.aa`, `affidavit.aa_resolve`, `affidavit.check`, `affidavit.policy`, or `affidavit.verdict`. It requires `orchestra/close_batch.py` to import `affidavit.oracle_red`. Do not scan `skills/`.
8. Do not edit skill markdown.
