## Description

Fix review finding `rec-60cd2a12` (behavior-bug, R5/R7). `orchestra/cli.py` eagerly imports `orchestra.close_batch`, which imports `affidavit.oracle_red`; a clean-HOME `uv tool install` therefore cannot run any subcommand. Make the installed CLI independent of a `~/affidavit` checkout.

## Approach

- Move the `affidavit` import behind the `close-batch` command or an explicit optional dependency, so `contract`, `project-field`, `sessions`, `check`, and `install` start with no affidavit checkout.
- Keep `close-batch` working when `aff` / the affidavit checkout is present, and fail with a clear message when it is not.
- Add a `standalone` test in `tests/test_cli_packaging.py` that installs to a temporary prefix, sets HOME to an empty temp dir and removes affidavit from PATH/PYTHONPATH, then runs every non-close-batch subcommand from an unrelated cwd.
