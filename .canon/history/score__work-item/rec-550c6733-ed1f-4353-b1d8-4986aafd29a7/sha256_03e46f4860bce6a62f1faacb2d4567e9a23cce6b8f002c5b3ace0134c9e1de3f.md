## Description

R12: One route table lists `GET /api/token`, `GET /api/snapshot`, `GET /api/phase`, `GET /api/task`, `GET /api/journal`, `GET /api/record`, `GET /api/requirement`, `GET /api/needs`, `GET /api/backlog`, `POST /api/needs`, and `POST /api/backlog`.
R13: The stdlib server dispatches those API paths by reading that table.
R14: The FastAPI app registers those API paths by reading that table.

## Approach

Add `dashboard.web.routes` with one table of those eleven routes: method, path, reader method, and query keys. `dashboard.web.service` and `dashboard.web.app` dispatch the API paths from that table. Leave the static `/` mount and each server's error mapping in that server. Do not add or drop an API path.
