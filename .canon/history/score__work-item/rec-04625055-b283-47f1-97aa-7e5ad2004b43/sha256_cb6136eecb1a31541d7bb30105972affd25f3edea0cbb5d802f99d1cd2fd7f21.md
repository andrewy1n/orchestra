## Description

`affidavit.aa` imports `StoreBindingError` and `resolve` from `dashboard.artifact_store`. That import has to move before `dashboard/` is deleted.

## Approach

1. Copy `StoreBindingError`, `Binding`, `Target`, and `resolve`, plus the helpers those need, from `dashboard/artifact_store.py` into `affidavit/aa_resolve.py`. Leave `dashboard/artifact_store.py` unchanged.
2. Change `affidavit/aa.py` so it imports `StoreBindingError` and `resolve` from `affidavit.aa_resolve`.
3. Point `tests/test_affidavit_aa.py` at `affidavit.aa_resolve` instead of `dashboard.artifact_store`. Add an assertion that `affidavit/aa.py` does not mention `dashboard`.
4. Leave `tests/test_aa_resolve.py` green. Do not delete `dashboard/` and do not create `~/orchestra`.
