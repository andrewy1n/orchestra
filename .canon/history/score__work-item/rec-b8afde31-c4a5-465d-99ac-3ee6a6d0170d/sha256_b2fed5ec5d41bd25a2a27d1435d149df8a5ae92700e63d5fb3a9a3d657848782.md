## Description

Load an optional argv runner from the committed manifest. An absent runner is the shipped pytest template. A bad runner fails manifest load. This phase does not hash the template.

## Approach

Work in `/home/andrewyin/affidavit--runner-adapter` on branch `phase/runner-adapter`. Edit only `affidavit/manifest.py` and `tests/test_manifest.py`.

1. Add `DEFAULT_RUNNER` as the tuple `python3`, `-m`, `pytest`, `-o`, `junit_family=xunit1`, `{tests}`, `--junitxml={report}`.
2. Add `runner: tuple[str, ...]` to `Manifest`. When the key is absent, `load_manifest` returns `DEFAULT_RUNNER`. When it is present, it must be a non-empty list of non-empty strings, with exactly one element equal to `{tests}`, and at least one element that contains `{report}`. Any other shape raises `ManifestError`.
3. Add `test_manifest_runner_absent_is_pytest_template` and `test_manifest_runner_invalid_shape`. The invalid cases are a non-list, an empty list, a non-string element, `{tests}` glued inside a longer element, and a list that omits `{tests}` or `{report}`.
4. Do not compare `runner` across revisions, do not hash it, and do not edit `verdict.py` or add `runner.py`.
