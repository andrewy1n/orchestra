## Description

R10: `orchestra view roadmap` groups open and promoted `composer:idea` records by area.
R11: `orchestra view roadmap` lists ideas without an area under a group named `untriaged`.
R12: `orchestra view roadmap` hides dismissed ideas.
R13: `orchestra view roadmap` shows the effort of each promoted idea.
R14: `orchestra view roadmap --effort <slug>` lists only ideas with that effort.

## Approach

In `orchestra/views.py` add `group_default: str | None = None` to `View`; `_group_key` returns `view.group_default` when the group field is missing or empty and a default is set (existing views set none, so they render as before). Add `ROADMAP = View('roadmap', 'Project Roadmap', roles, group_by='area', group_default='untriaged')` with an area role (`composer:area`, fields `('title',)`, active) and an idea role (`composer:idea`, fields `('status','effort','source')`, active and status in open or promoted), and register it in `VIEWS`. Add `roadmap` to the `orchestra view` choices in `orchestra/view_cli.py`. `--effort` already filters by payload effort. Add a `--effort` case to `tests/test_views.py` for R14. Do not edit the frozen oracle `tests/test_roadmap_view.py`.
