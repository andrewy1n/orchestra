## Description

Add `scripts/dashboard_app.py`, a PEP 723 script with a Textual dependency. For each live effort it shows a header with the goal and a phase progress bar, count tiles (running, ready, needs you, done), a status-colored task table, a needs-you panel, and a recent activity feed. It polls the change token and redraws on change. `q` quits. `--once` prints one plain-text frame and exits. The layout stays readable at 60 columns. Waits on the snapshot model.
