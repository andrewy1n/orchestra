## Description

R20: `orchestra idea` and `orchestra view roadmap` run through the installed entry point from an unrelated directory.

## Approach

In `tests/test_cli_packaging.py` add a test using the `installed` fixture: create a temporary git repo with a store (`canon init --schemas score,conductor,tuner,composer` through the installed prefix or the existing helper), then from an unrelated cwd run the installed `orchestra idea "Try roadmap"` and `orchestra view roadmap`, assert exit 0 and that the roadmap lists the idea under `untriaged`.
