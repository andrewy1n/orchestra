## Description

Phase-end reviewer NEEDS_WORK:

1. `_enforce_claim_gates` treats the synthetic unit-test acceptance loader as an unloadable acceptance and refuses, so `build_batch(request, load_check_run=...)` fails 21 legacy close-batch tests. A store-backed close must still refuse a genuinely unloadable acceptance (R8).
2. No test proves the removed `payload.claim_id` fallback is ignored.

## Approach

In `orchestra/close_batch.py`, give the unit-test-only acceptance loader its own exception (a `LookupError` subclass) and skip only that exception in `_enforce_claim_gates`; keep a real `LookupError` from `default_load_acceptance` as `CloseRefused`. Add a test in `tests/test_close_batch.py` where `payload.claim_id` names a manifest claim but `payload.claim` is absent, asserting no verdict/recheck runs and the batch reaches `done`. Do not edit `tests/test_claim_clocks.py`.
