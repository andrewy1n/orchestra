## Description

R10: The installer installs native payloads for Claude Code, Cursor, and OpenCode.
R11: The installer delegates at least one non-native host to `npx skills add` and reports the profile used.
R12: Claude, Cursor, and OpenCode hook adapters are installed when supported, and installation succeeds when they are absent.
R13: The reviewer agent is generated per host from one canonical prompt and restriction set.

## Approach

Implement the three native adapters under `hosts/claude`, `hosts/cursor`, and `hosts/opencode`, keeping the existing manifests valid and adding OpenCode's `skills` source plus a `plugin.js` hook adapter. Generate the reviewer agent from `agents/reviewer.prompt.md` into Claude's `tools:`, OpenCode's `permissions:` plus `mode: subagent`, and Cursor's closest read-only configuration. Add the generic tail adapter that runs `npx skills add -a <profile>` and reports the profile. Hooks are optional: a host without hook support still applies. Add `tests/test_agent_generation.py`; extend `tests/test_installer.py` with native, tail, and hooks cases; add `tests/integration/test_temp_home_install.py` for Claude and OpenCode.
