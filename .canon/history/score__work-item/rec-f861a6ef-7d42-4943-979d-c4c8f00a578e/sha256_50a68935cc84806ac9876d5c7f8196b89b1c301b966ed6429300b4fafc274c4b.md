## Description

Add scripts/record_join.py with a pure function join(sessions, records). It takes session summaries and record metadata as dicts. A record attaches to a session when its store name equals the basename of the session cwd and recorded_at is inside start to end. A record inside two windows attaches to both and is marked ambiguous. Other records stay unattached.
