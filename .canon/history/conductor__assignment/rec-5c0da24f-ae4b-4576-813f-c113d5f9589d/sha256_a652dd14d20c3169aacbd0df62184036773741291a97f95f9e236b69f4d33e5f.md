## Approach

Add `scripts/api_schema.py [--check] [--schema PATH]`: without `--check` it writes the FastAPI app's OpenAPI schema (stable key order, trailing newline) to PATH (default `dashboard/web/ui/openapi.json`); with `--check` it compares the live schema with PATH and exits 1 with a message that names the regenerate command when they differ. Add `openapi-typescript` at an exact version as a devDependency in `dashboard/web/ui` and the npm scripts `api-types` (`openapi-typescript openapi.json -o src/api-types.ts`) and `api-types:check` (regenerate to a temp file and fail on a diff with `src/api-types.ts`); extend the `check` script to also run `api-types:check`. Commit `openapi.json` and the generated `api-types.ts`. Replace the hand-written API shapes in `src/types.ts` with imports from `./api-types` (aliases of the generated schemas are fine; leave UI-only types in `types.ts`). Update every `src/*` import. Wire the Python half into CI by adding a test (or a step in an existing Python CI job, not the `web` job) that runs `python scripts/api_schema.py --check`. Run `cd dashboard/web/ui && npm run lint && npm run check && npm test && npm run build`, then `uv run pytest tests/dashboard/test_endpoint_shapes.py tests/test_ci_workflow.py tests/test_web_gate.py -q` and `uv run basedpyright`.
