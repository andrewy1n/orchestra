### Work-item (quote)

## Description

R3: The host selection accepts provider numbers, provider ids, numeric ranges, comma- or space-separated values, `a` or `all`, and `q` or `quit`.
R4: A blank host selection selects the detected hosts when at least one host is detected.
R5: A blank host selection with no detected hosts refuses to proceed.
R6: The wizard prompts for project or global scope, defaults to project, and prints the resolved base directory.
R7: The wizard prompts for symlink or copy mode, defaults to symlink, and prints the chosen mode.

## Approach

Add `installer/wizard.py` with small, testable functions: `parse_host_selection`, `prompt_hosts`, `prompt_scope`, and `prompt_mode`. `prompt_hosts` renders the matrix rows with `project` and `global` detection labels, accepts the selection grammar in R3, and applies the R4/R5 blank rules. `prompt_scope` returns `project` or `global`, defaults to project, and prints the resolved base. `prompt_mode` returns `symlink` or `copy`, defaults to symlink, and prints the choice. Keep input and output injectable (streams or callables) so tests can drive the prompts without a PTY. Do not call `apply` from this module. Add focused tests in `tests/test_installer_wizard.py` for the parser, blank defaults, empty refusal, scope, and mode. Use only the Python standard library.

### Design / decisions (quote)

Invariants:
- Detection, `--list`, `--dry-run`, and a declined confirmation write nothing.
- Planning happens before any apply; a declined plan leaves the tree untouched.
- The selected scope and mode are visible in the rendered plan.
- `--only` preserves request order and `--only` plus `--all` remains an error.
- A second install with the same inputs is idempotent.
- `--uninstall` removes only entries named by a registration.
- `--home` redirects both detection bases and prevents reads of the real HOME.
- Existing host adapters and payload layouts are unchanged.

Assumptions:
- `sys.stdin.isatty()` and `sys.stdout.isatty()` are the interactivity signal.
- `--interactive` is available for tests and demos without a PTY.
- The project base is the cwd, the global base is HOME, and `--home` replaces both.
- A host is detected when its marker exists or any provider `detect` path exists at the base.
- A prompt EOF or Ctrl-C is a cancel, not an install error.
- The provider matrix's `detect` paths remain relative to the install base.

Decisions:
- `installer-wizard-approach`: `stdlib-wizard-detection` (alternatives: `textual-tui-detection`, `detection-flags-only`).
- `installer-python-runtime`: `python-stdlib` (alternatives: `js-tui-wrapper`, `full-js-rewrite`).
- `installer-default-detected`: `detected-require-choice` (alternatives: `detected-native-fallback`, `all-providers`).
