### Work-item (quote)

## Description

R5: Python files under `orchestra/` and `dashboard/` start the `git` executable only in `orchestra/canon/git_backend.py`.
R6: `dashboard.landing.rev_parse_token` returns `None` when the git command fails.
R7: `orchestra.conductor.check.git_head` raises when `git rev-parse HEAD` fails.

## Approach

Add `run_git` on `orchestra.canon.git_backend` next to `git_root`. Route every `subprocess` argv that starts with `git` under `orchestra/` and `dashboard/` through that runner. Callers keep their argv and their own error policy. `dashboard.landing.rev_parse_token` still returns `None` on failure. `check.git_head` still raises when `git rev-parse HEAD` fails. Canon imports no other orchestra component.
