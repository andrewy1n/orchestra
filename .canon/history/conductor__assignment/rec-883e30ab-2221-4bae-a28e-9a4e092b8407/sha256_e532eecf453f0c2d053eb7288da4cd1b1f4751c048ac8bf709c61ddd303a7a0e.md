## Approach

Add an `orchestra status [DIR]` subcommand to the orchestra CLI (`orchestra/cli.py`). Build it on the snapshot loader in `dashboard.backend` and `gates.landings_for_snapshot`, so the counts match the web dashboard's Needs-you list. Line format: `<effort>: running <n>, ready <n>, needs-you <n>`. `--count` prints the merged needs-you count as a bare integer. `DIR` defaults to the resolved store. The removed `dashboard/bin/dashboard-status` script was the previous implementation; read its git history for the count rules.
