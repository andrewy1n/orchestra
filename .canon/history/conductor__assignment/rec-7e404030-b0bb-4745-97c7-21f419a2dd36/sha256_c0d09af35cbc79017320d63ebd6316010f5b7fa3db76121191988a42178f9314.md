## Approach

Add `pyyaml` to the `dev` dependency group and run `uv lock`. Write `tests/test_ci_workflow.py` first: parse `.github/workflows/ci.yml` with `yaml.safe_load` (the `on` key loads as `True`), and write one test per requirement named `test_r<N>_<what>`. Each test must fail on an assertion, not an import error. Assert that no blocking job sets `continue-on-error` and no `run` step ends with `|| true`.

Then write `.github/workflows/ci.yml`. Triggers: push to `main` and `phase/**`, `pull_request`, `workflow_dispatch`. Add a top-level `concurrency` group keyed on the workflow and ref with `cancel-in-progress: true`. Jobs, none with `needs`: `checks`, `test-canon`, `test-tuner`, `test-orchestra`, `test-tmux`, `types`. Use `ubuntu-latest`, `actions/checkout@v4`, and `astral-sh/setup-uv` with `python-version: "3.10"` and `enable-cache: true`. Install with `uv sync --locked --group dev`. Every job sets `timeout-minutes`.

`checks` runs `python3 scripts/build_skills.py --check`, `python3 scripts/check_orchestra_plugin_names.py`, `uv run canon validate`, and `uvx ruff@0.13.1 check .`. The three test jobs run the pytest commands from R15-R17 with `-q -p no:cacheprovider`. `test-tmux` runs `sudo apt-get install -y tmux`, then `uv run pytest -q -p no:cacheprovider tests --ignore=tests/canon --ignore=tests/tuner -m tmux`. `types` pins mypy, runs it with `continue-on-error: true`. Do not edit `tuner-verdict.yml` or `scripts/test.sh`. Add no comments that explain a change. Commit on the phase branch.
