## Description

Prove the phase exit criteria hold together.

R1: An editable install imports `dashboard` when the repository root is absent from `sys.path`.
R9: Importing `orchestra.cli` raises `ModuleNotFoundError` when `orchestra.canon` cannot be imported.
R12: `orchestra.sessions.report` does not insert a directory on `sys.path`.
R16: `scripts/test.sh` invokes pytest through `uv run`.
R28: `tests/test_cli_packaging.py` passes.
R29: `scripts/test.sh` exits 0.

## Approach

Run the acceptance commands from the phase worktree. Do not edit the tree. Do not write `.canon`. Do not touch `idea-triage` worktrees.

The integration check is the editable-install tests plus `tests/test_cli_packaging.py`, which installs the real package and drives the console script. Then run the import-error tests, the session `sys.path` test, the `scripts/test.sh` flag scan, and `scripts/test.sh` itself.
