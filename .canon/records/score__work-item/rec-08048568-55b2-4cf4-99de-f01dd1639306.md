## Description

Point orchestra skills at `orchestra check` and `orchestra close-batch`, and leave `aff verdict` as the gate. This waits until the orchestra binary and the import edits exist.

## Approach

Work on branch `phase/standalone-aff` in `~/orchestra`.

1. In `skills/`, `agents/`, and `README.md`, replace command invocations of `aff check` with `orchestra check` and `aff close-batch` with `orchestra close-batch`. Leave `aff verdict` as written. A sentence that tells the agent which command records a `tdd` or `check` result, or which command closes a work-item, is an invocation.
2. In `skills/verify-work`, `bin/aff` is the verdict binary from `~/affidavit`. `bin/orchestra` is check and close-batch. README's acceptance-check line uses `bin/orchestra check`.
3. Add `tests/test_orchestra_commands.py`. It fails when a skill file tells the agent to run `aff check` or `aff close-batch`, and it fails when `execute-phase` or `verify-work` drops `aff verdict` for a manifest claim.
4. Update assertions in `tests/test_verify_authority.py`, `tests/test_assess_routing.py`, and `tests/test_skill_evidence_boundary.py` that still require the old command strings. Leave `orchestra.*` imports already written in `tests/test_verify_authority.py` as they are.
