## Description

R6: No Python module remains directly under `dashboard/` except `__init__.py`.
R7: The surviving Python modules live under `dashboard/backend/`, and the web server lives under `dashboard/backend/server/`.
R8: The server serves the built UI from `dashboard/web/ui/dist`.
R12: `uv run basedpyright` passes, and its baseline has no entry for a deleted file.

## Approach

`git mv` each surviving module from `dashboard/` into `dashboard/backend/`, and `dashboard/web/*.py` into `dashboard/backend/server/`. Keep `dashboard/web/ui` where it is. Add `__init__.py` files. Rewrite imports (`dashboard.X` to `dashboard.backend.X`, `dashboard.web.X` to `dashboard.backend.server.X`) in source, tests, `dashboard/bin/web`, `pyproject.toml` package lists, and any docs. Change no code other than imports and the `DIST` path (it must still point at `dashboard/web/ui/dist`; it moves up two parents). Update the wheel/package data lists so the wheel still ships the modules. Update the basedpyright baseline for moved paths. Run the web tests after the move.
