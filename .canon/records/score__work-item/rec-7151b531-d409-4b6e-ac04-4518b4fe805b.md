## Description

R6: Each effort row of `GET /api/snapshot` carries `area`: the placed area subject, or an empty string when the effort has no placement.
R7: The committed `dashboard/frontend/src/api-types.ts` matches the generated API schema, including `area` on the effort row.

## Approach

In `dashboard/backend/snapshot.py` add a `PLACEMENT_TYPE = "composer:placement"` string constant like `AREA_TYPE` in `areas.py`. Read the live placements, map subject to `payload.area`, and set a new `EffortView.area: str = ""`. Ignore a placement whose effort does not exist. Add `area: str` to the effort model in `dashboard/backend/server/schemas.py`. Regenerate `dashboard/frontend/openapi.json` and run `npm run api-types` in `dashboard/frontend`.
