## Description

R5: The page requests /api/token on an interval and requests /api/snapshot again only when the token value changes.
R6: The effort rail shows each effort's name, kind, and needs-you count.
R7: A finished effort with no Needs you items is hidden until the user asks to show finished efforts.
R8: The main pane shows the selected effort's goal.
R9: Selecting one phase limits the task rows to that phase.
R10: Status tabs Active, Running, Ready, Waiting, Done, and All limit the task rows to those states.
R32: A finished effort that has Needs you items stays visible on the rail.
R33: Selecting all phases shows every task in the effort.

## Approach

- Poll `/api/token` about every two seconds and request `/api/snapshot` again only when the token changes.
- The effort rail shows name, kind, and needs-you count. Hide a finished effort with no Needs you items until the user asks to show finished efforts. Keep a finished effort that has Needs you items on the rail.
- The main pane shows the selected effort's goal, a phase control for one phase or all phases, status tabs Active, Running, Ready, Waiting, Done, and All, and the task rows those selections allow.
- Make the matching cases in `dashboard/web/ui/src/main.test.ts` pass.
