## Description

Remove the store client from this repo once orchestra has it, and make `aff` verdict-only.

## Approach

Work in the affidavit phase worktree. Do not edit `~/orchestra`.

1. Delete `affidavit/check.py`, `affidavit/close_batch.py`, `affidavit/aa.py`, `affidavit/aa_resolve.py`, `affidavit/policy.py`, and `affidavit.tmux`. Delete `tests/test_affidavit_check.py`, `tests/test_close_batch.py`, `tests/test_affidavit_aa.py`, and `tests/test_aa_resolve.py`.
2. Reduce `affidavit/cli.py` to the `verdict` subcommand. Drop the `check` and `close_batch` imports. The module docstring must not contain `project:`, `SE_WORKFLOW_STORE`, `store-binding.json`, or `adaptive-artifacts`.
3. Rewrite the module docs in `affidavit/__init__.py` and `affidavit/verdict.py` so those four strings are gone. `verdict.py` can say it does not read a record store.
4. Add `tests/test_standalone_cli.py`. `test_verdict_without_runtime` runs `bin/aff verdict` against a tiny committed manifest, the same shape as `test_verdict_pass_when_hashes_match_and_red_then_green`, with `PATH` entries that contain an `adaptive-artifacts` executable removed, and asserts exit 0. `test_rejects_store_commands` runs `bin/aff check --help` and `bin/aff close-batch --help` and asserts each exits non-zero.
5. Add `test_no_store_tokens` to `tests/test_evidence_layout.py`. It scans `affidavit/**/*.py` for those four strings. Replace `test_aa_py_does_not_mention_dashboard` with an assertion that the five deleted modules are absent. Update `test_protocol_docs_describe_the_evidence_layer` so `README.md`, `AGENTS.md`, and `CLAUDE.md` describe a verdict-only `aff` and send check, close-batch, and the store client to orchestra.
6. If `tests/helpers.py` or `tests/conftest.py` still point at `affidavit.tmux` and no remaining test uses that helper, delete the unused helper. Leave the verdict, manifest, and amendment helpers.
