## Description

R27: Every blocking job passes on a pull request from the phase branch.

Five tests fail only on the GitHub runner (run 40809217152). This task fixes their causes or, where the cause is unknown, adds output that shows it.

## Approach

1. `tests/tuner/test_standalone_cli.py::test_verdict_without_runtime`: the default runner is `python3 -m pytest`. The test drops `.venv/bin` from PATH, so `python3` is the system Python, which has no pytest on the runner. Put a `python3` shim that execs `sys.executable` first on the stripped PATH.
2. `tests/test_dashboard_app.py` (`related_panel_is_hidden_without_related_records`, `blocked_waiting_task_still_lists_Depends_on_links`): `_open_by_click` returns once any detail screen opens, so a missed click opens the wrong task. Make it succeed only when `screen.task_id` equals the requested key; otherwise go back and use the keyboard path.
3. `tests/test_web_dashboard_launch.py::test_r30_serves_build`: the launcher output is invisible on failure. Append the launcher stdout and stderr to the assertion message.
4. `tests/test_tmux_integration.py::test_prefix_a_popup_...`: the Done tab renders with a truncated task column on the runner. Append `tmux -V` and the TERM and LANG values to the assertion message.

Run each test locally, run ruff, commit on the task branch, push the phase branch, and read the new Actions run.
