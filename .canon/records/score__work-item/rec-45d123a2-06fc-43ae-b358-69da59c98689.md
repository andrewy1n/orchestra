## Description

R1: `#/` shows the product index with one card for each area.
R14: `GET /api/areas` lists, for each area, the promoted ideas whose effort is placed in that area.
R18: `#/effort/<name>` shows the Home screen of that effort.

## Approach

Fix four review findings. Frontend commands run in `dashboard/frontend`. Write each test first and see it fail on an assertion. Name each vitest test so it starts with the requirement id and a space. Do not edit `src/deepLinks.test.ts`, `src/detail.test.ts`, `src/detailNav.test.ts` or the frozen `tests/dashboard/test_areas_promoted.py`. Do not add comments that explain a change.

1. R18, finding `review-area-levels-close-fallback`. Write `src/lib/screens/closeFallback.test.ts` with tests named `R18 ...`: a deep link `#/task/<id>` closed with Esc, and a journal Back, each end on `#/effort/<name>`. Keep the existing overlay and back-stack tests passing.

Write `src/lib/state/areasGuard.test.ts` with a test named `R1 a response that is not a list sets the areas error`.
