## Description

R6: A Playwright test starts the server on a seeded store and loads the page in headless Chromium.
R7: The Playwright test asserts that a seeded effort name is visible on the page.
R8: A CI job installs the browser and runs the Playwright test.
Context: the web dashboard UI is built by `cd dashboard/frontend && npm ci && npm run build` into `dashboard/frontend/dist` (gitignored by `dashboard/frontend/.gitignore`). The FastAPI app in `dashboard/backend/server/app.py` serves `DIST` (`dashboard/frontend/dist`) at `/` when it exists and otherwise returns the `MISSING_BUILD` message that names `npm run build`. `scripts/wheel_smoke.py [--wheel PATH]` builds a wheel from `git archive HEAD` in a temp dir with `uv build --wheel`, installs it into a new venv and runs checks from outside the checkout (each prints `<name>: pass|fail`); the CI `wheel` job runs `python3 scripts/wheel_smoke.py` (a frozen test pins that exact run line). `pyproject.toml` lists the packages and package-data; setuptools builds the wheel and needs no Node. The repo has no release workflow; the CI `wheel` job is the build. `ci.yml` jobs: checks, test-canon, test-tuner, test-orchestra, types, web, wheel; a test requires `setup-uv` on Python 3.10 with `enable-cache: true` in every job that uses uv, and every job has `timeout-minutes`. Biome lint must stay at zero findings (`npm run lint` in dashboard/frontend). The seeded-store fixtures in `tests/conftest.py` are reusable from Python tests.

## Approach

In `dashboard/frontend`: add `@playwright/test` as an exact-version devDependency, `playwright.config.ts` (chromium project, headless, one worker, `webServer` that runs the launcher and waits on its URL, `baseURL`), the test `e2e/app.spec.ts` (one test: open `/`, wait for the seeded effort name to be visible with `expect(page.getByText("<name>")).toBeVisible()`; wait on the element, never on time) and the launcher `e2e/serve.py` (starts the server through `uv run`/`python` on a free port, or a port passed by `--port`, on a temporary seeded store built with the canon CLI: one effort with a goal, one phase and one task, effort name `e2e-alpha`; prints the URL; cleans up the temp store on exit; the server must serve the built `dist`, so the test requires `npm run build` first). Add the npm script `e2e` (`playwright test`). Keep Biome at zero findings (lint covers `e2e/`; give `e2e` a tsconfig entry or include so `npm run check` stays green; add `test-results/` and `playwright-report/` to `.gitignore`). Add a CI job `e2e` to `ci.yml`: checkout, `astral-sh/setup-uv@v6` (python 3.10, enable-cache true), `actions/setup-node@v4` (node 22, npm cache), `npm ci`, `npm run build`, `npx playwright install --with-deps chromium`, `npm run e2e` (working-directory `dashboard/frontend`; `timeout-minutes: 20`; no `continue-on-error`). Run it locally if Chromium installs (`npx playwright install chromium`; if system libraries are missing and no sudo is available, say so in observations and verify the config with `npx playwright test --list`). Existing Vitest must not pick up `e2e/*.spec.ts` (vite.config.ts `test.include` is `src/**/*.test.ts`). Run `cd dashboard/frontend && npm run lint && npm run check && npm test && npm run build`, `uv run pytest tests/test_ci_workflow.py tests/dashboard/test_web_packaging.py -q`.
