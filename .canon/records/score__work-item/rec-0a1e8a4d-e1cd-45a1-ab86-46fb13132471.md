## Description

R5: `@biomejs/biome` is an exact-version devDependency of `dashboard/web/ui`.
R6: `biome.json` sets `html.experimentalFullSupportEnabled` to `true`.
R7: `npm run lint` exits 0 on `dashboard/web/ui` with no findings.

## Approach

In `dashboard/web/ui`, install `@biomejs/biome` at `2.6.4` with `npm install --save-dev --save-exact`. Add `biome.json` with `html.experimentalFullSupportEnabled: true`, `dist` and `node_modules` ignored, and the recommended lint rules. Add the script `"lint": "biome check --error-on-warnings ."`. Run `npx biome check --write` for safe fixes, then fix the rest by hand. Tune rules in `biome.json` where Svelte conflicts (for example `noNonNullAssertion`); add no per-line suppressions and no baseline file. After the fixes, `npm test` and `npm run build` must still pass.
