## Description

The web server imports `dashboard.model`, `journal`, `approval`, `backlog`, `dismiss`, `gates`, and `landing`. These pull in modules that import `textual` or `rich` (`task_detail`, `phase_screen`, `requirement_detail`, `tasks`, `commit`, `pager`). After this task, `import dashboard.web.app` and `import dashboard.web.service` work with `textual` blocked.

## Approach

List the names the web server and the surviving modules use from each module that imports `textual`. Move each Textual-free function or type into a surviving module, or into the module that already uses it (`journal.py` keeps its loaders, `gates.py` and `landing.py` keep theirs). Do not move any code that draws a screen or widget. Do not delete the Textual modules in this task; the next task deletes them. After each move, run the web tests: `uv run pytest tests/test_web_dashboard.py tests/test_web_dashboard_launch.py -q`. Update imports in tests that exercise the moved names. Keep the moves free of content changes other than imports.
