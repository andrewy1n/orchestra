## Description

R4: The constraints block lists active constraints from every live effort.
R5: The constraints block omits constraints whose effort is closed.
R6: Each effort section shows only the Goal, Position, In Progress, Blocking Question, Needs Human and Unsigned Manual Check roles.
R7: The start hook context contains no record-id links.
R10: Effort sections appear in order of their effort position recorded_at, newest first.
R11: `orchestra handoff` output keeps its id links, Latest Proof and Backlog sections.

## Approach

In orchestra/views.py, name the HANDOFF roles the hook needs as module constants and add `hook_handoff_sections(records)` returning `(effort, text)` per live effort. Give `_record_line` a `link` flag (default True) so render_view output is unchanged. Order efforts by the recorded_at of their active effort-scoped position, newest first. Change `hook_constraints` to filter on the set of live efforts instead of the first position found.
