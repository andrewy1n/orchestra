## Description

The bundled contract and ensure-store still treat `"project": "affidavit"` as the current design.

## Approach

1. In `~/orchestra/contract/project-design.json`, set `"project"` to `orchestra`.
2. Add `orchestra/project_field.py` with a function that reads a design file and returns one of three outcomes: `orchestra` is already current; `affidavit` is rewritten to `orchestra` in place; any other value is left unchanged and reported as stopped.
3. Rewrite `~/orchestra/skills/ensure-store.md` so the current project id is `orchestra`, an `affidavit` field is rewritten by that function without asking again, and any other value stops the overlay. Remove the branch that treats `affidavit` as the expected project.
4. Add `tests/test_ensure_store_project.py` with two fixture files: one `"project": "affidavit"` becomes `orchestra`; one `"project": "other"` is byte-identical afterward. Assert the bundled contract's project is `orchestra`.
5. Do not edit either checkout's live `.artifacts/project-design.json`. `move-effort-records` applies the rewrite to the live stores.
