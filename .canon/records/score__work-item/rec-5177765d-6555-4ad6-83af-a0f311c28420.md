## Description

R1: `pyproject.toml` sets `typeCheckingMode = "standard"` under `[tool.basedpyright]`.
R2: `pyproject.toml` sets `pythonVersion = "3.10"` under `[tool.basedpyright]`.
R3: The `[tool.basedpyright]` `include` list is `orchestra`, `dashboard` and `installer`.
R4: The `dev` dependency-group pins basedpyright to an exact version.

## Approach

Add `[tool.basedpyright]` after `[tool.ruff.lint]` with `typeCheckingMode = "standard"`, `pythonVersion = "3.10"`, and `include = ["orchestra", "dashboard", "installer"]` on one line. Run `uv add --group dev "basedpyright==1.40.2"` to pin the version and refresh the tracked `uv.lock`. Run `uv run basedpyright --version` to confirm.
