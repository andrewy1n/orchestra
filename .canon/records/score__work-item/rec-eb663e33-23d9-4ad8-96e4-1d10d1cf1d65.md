## Description

Add a derived finished flag on EffortView in dashboard_model.py: true when the effort has phases or tasks and every phase and counted task is done (decision finished-effort-derived). In the app, a finished effort's empty Active tab says "All N tasks done" instead of "No tasks match"; finished efforts sort after live ones in the tab bar and their tab label is dimmed. Keep --once output consistent.
