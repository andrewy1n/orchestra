## Description

R9: The `types` job runs `uv run basedpyright`.
R10: The `types` job does not set `continue-on-error`.
R11: No step in the `types` job sets `continue-on-error`.
R12: No job in `ci.yml` runs mypy.
R13: `README.md` names `uv run basedpyright` as the local type check.

## Approach

In `.github/workflows/ci.yml`, replace the last step of the `types` job (`uvx mypy@1.18.2 orchestra`) with `uv run basedpyright` and delete `continue-on-error: true`. In `tests/test_ci_workflow.py`, the oracle tests replace `test_r22_types_job_runs_mypy_with_continue_on_error` and drop the `types` exemption in `test_blocking_jobs_do_not_continue_on_error`; make those edits only to keep the suite green once the oracle tests exist. In `README.md`, add a short "Type check" paragraph under Testing that names `uv run basedpyright` and says CI runs the same command.
