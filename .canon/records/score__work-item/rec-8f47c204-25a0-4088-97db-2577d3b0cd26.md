## Description

R5: `scripts/wheel_smoke.py` builds the wheel with `uv build --wheel` when `--wheel` is absent.
R6: `scripts/wheel_smoke.py` installs the wheel into a new virtual environment.
R7: `scripts/wheel_smoke.py` runs every check with a working directory outside the checkout.
R8: `orchestra --help` from the new environment exits 0.
R9: `canon --help` from the new environment exits 0.
R10: `canon init --schemas score,conductor,tuner` in a temporary git repository exits 0.
R11: `canon validate` in that repository exits 0.
R12: `orchestra install --list` exits 0.
R13: The `orchestra install --list` output names the `claude` host.
R14: The new environment imports `dashboard`.
R15: The new environment imports `dashboard.web`.
R16: The new environment imports `installer`.
R17: The new environment imports `installer.adapters`.
R18: `scripts/wheel_smoke.py --wheel <path>` installs that wheel and does not build one.
R19: `scripts/wheel_smoke.py` exits non-zero for a wheel that lacks `installer/providers.json`.
R20: `scripts/wheel_smoke.py` leaves the checkout unchanged.

## Approach

Add `scripts/wheel_smoke.py`. Standard library and `uv` only. No new dependency. No comments that explain the change.

Parse an optional `--wheel PATH`. When it is absent, copy tracked files only (`git archive HEAD` or `git ls-files`) into a temporary directory and run `uv build --wheel` there. Do not run `uv build` in the checkout. When `--wheel` is set, install that file and do not run `uv build`.

Create a new virtual environment with `uv venv` and install the wheel with `uv pip install`. Run every check with that environment's executables, a working directory that is not the checkout, and the checkout off `sys.path`:

- `orchestra --help` exits 0
- `canon --help` exits 0
- `canon init --schemas score,conductor,tuner` in a new temporary git repository exits 0, then `canon validate` there exits 0
- `orchestra install --list` exits 0 and its output names `claude`
- imports of `dashboard`, `dashboard.web`, `installer`, and `installer.adapters` succeed

Exit non-zero if any check fails. A wheel without `installer/providers.json` fails `orchestra install --list`, because `installer.matrix` reads that file. Do not assert on or ship `dashboard/web/ui/dist`.

Use only temporary directories so the checkout's git status is unchanged. Do not edit the oracle tests in `tests/test_wheel_smoke.py`.
