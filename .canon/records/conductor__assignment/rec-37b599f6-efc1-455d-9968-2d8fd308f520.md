## Description

R9: The init skill tells the agent to create a `score:brief` with the effort slug as subject when the effort kind is `deliver`.

R10: The init skill tells the agent to create no `score:brief` when the effort kind is `repair`, `evaluate`, or `incidental`.

R11: The init skill gives a `score:brief` body template with the headings `## Problem`, `## Users`, `## Success measure`, `## Non-goals`.

R12: The settle-phase skill's context step lists the `score:brief` record for the focus effort.

R13: `orchestra/score/AGENTS.md` lists `brief` among the score types.

## Approach

Edit `skills/init/SKILL.md` step 6: after the `score:effort` create, add the `canon create --type score:brief --subject "<effort-slug>" --payload '{"effort":"<effort-slug>"}' --body-file "<brief-body.md>"` command for a `deliver` effort, name the four `##` headings of the body, and say that `repair`, `evaluate`, and `incidental` efforts get no brief. Edit `skills/settle-phase/SKILL.md` step 2: add `canon list --type score:brief --subject <focus> --exact-subject --state active --full` to the context reads and say to read the brief when one exists. Add `brief` to the type list in `orchestra/score/AGENTS.md`. Keep each addition short and match the surrounding style. Run the skill-scanner tests (`tests/test_settle_phase_skill.py`, `tests/test_agent_generation.py`, `tests/test_skill_portability.py`, `tests/test_plan_wave_rules.py`, `tests/test_init_idea_promote.py`).
