## Approach

Move the reactive state and actions from `src/App.svelte` script into `src/lib/state/polling.svelte.ts`, `src/lib/state/journal.svelte.ts`, and `src/lib/state/overlay.svelte.ts` (decision `app-split`). Each exports reactive values and actions as Svelte 5 runes-based modules; the screens import them. `src/poll.ts`, `src/router.ts`, `src/api.ts`, and the other plain modules stay where they are unless a state module needs them (import them with relative paths or `$lib`). The router keeps its route names and deep link format. `App.svelte` shrinks but its markup stays in place in this task. All Vitest tests pass unchanged, including `deepLinks.test.ts`, `links.test.ts`, `main.test.ts`, and `scaffold.test.ts`. Run `npm run lint`, `npm run check`, `npm test`, `npm run build`.
