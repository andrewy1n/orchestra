## Approach

Delete the stdlib server (decision `one-fastapi-server`): remove `ThreadingHTTPServer` and `BaseHTTPRequestHandler` code from `server/service.py`, keep what the FastAPI app needs (Reader, Cache, WriteError, the JSON mapping) and delete the rest; the `dashboard/bin/web` launcher keeps working through `uvicorn`/the FastAPI app. Define Pydantic models for every `/api/*` response in `dashboard/backend/server/schemas.py` and set `response_model` on each route (decision `pydantic-api-contract`); map loader output to the models. The JSON must stay byte-for-byte equivalent in shape: fields, nulls, and optional keys must match the stored fixtures (`uv run pytest tests/dashboard/test_endpoint_shapes.py -q`; use `response_model_exclude_none`/`by_alias` settings as needed rather than changing fixtures). Update tests that targeted the stdlib server to the FastAPI TestClient (shape-preserving). Run `uv run pytest tests/dashboard/test_endpoint_shapes.py tests/test_web_dashboard.py tests/test_web_dashboard_launch.py tests/test_web_fastapi_writes.py -q` and `uv run basedpyright`.
