## Requirements

R1: The project contract defines a `project:evidence-observation` record type whose payload can carry technique id, tree revisions, structured outcomes, and replay metadata.
R2: After `aff verdict` finishes judging, when a usable artifact store is available for the subject repo, it creates one `project:evidence-observation` per invoked run via the `adaptive-artifacts` CLI (not a Python import of the runtime).
R3: `aff trail` lists evidence-observations from the store (filterable by claim id when the observation references claims) and prints them as JSON.
R4: A pytest accepts only when a seeded subject with a store shows: `aff verdict` creates an evidence-observation, `aff trail` returns it, and a subsequent `aff verdict` for the same claim still exits 0 on pass.

## Acceptance criteria

- Contract change validates under adaptive-artifacts.
- Without a store, `aff verdict` behavior matches pre-phase stdout/exit semantics.
- With a store, one new `project:evidence-observation` appears after a passing verdict fixture run.
- `aff trail --cwd <repo>` exits 0 and includes that observation's id and technique `verdict`.
- `python3 -m pytest` for the new/updated tests in this phase passes.

## Constraints

- Do not import adaptive-artifacts Python packages from `affidavit/`.
- Claims and `oracle_hashes` remain in `.affidavit/manifest.json` only.
- Explicit bind/unbind is out of scope (phase `evidence-bind`).
- Audit/probe ingestion is out of scope (phase `evidence-technique-ingest`).

## Non-goals

- Public substrate verbs (stimulate/intervene).
- Git-local observation files as source of truth.
- Orchestra skill edits (phase `evidence-workflow`).
- Changing attestation format.

## Invariants

- Verdict judge logic (red/green, hashes, amendments) is unchanged in meaning; recording is additive.
- Store writes use the public CLI only.

## Assumptions

- Subject repos that want a trail will have (or gain) an adaptive-artifacts store, typically via orchestra init.
- A new record type in this repo's `contract/project-design.json` is allowed for evidence-layer needs; mirror to orchestra when skills depend on it.
