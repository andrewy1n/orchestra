## Requirements

R1: The CI job `web` runs `npm ci`, `npm run lint`, `npm run check`, `npm test`, and `npm run build` in `dashboard/web/ui`, in that order.
R2: The `web` job runs on every push and pull request, with no path filter.
R3: The `web` job fails when the UI has a TypeScript type error.
R4: The `web` job fails when the UI has a lint finding of any severity.
R5: Biome is a dev dependency of the UI at an exact version, with no version range.
R6: `biome.json` sets `html.experimentalFullSupportEnabled` to `true`.
R7: `npm run lint` exits 0 on the tree with no findings.
R8: `AGENTS.md` has a TypeScript and Svelte standards section.
R9: The `AGENTS.md` TypeScript and Svelte section names `npm run lint`, `npm run check`, and `npm test` as the commands to run before closing a task.
R10: `npm run check` exits 0 on the tree.

## Acceptance criteria

- R1, R2: read `.github/workflows/ci.yml` (a test parses the job and checks the step order and the absence of `paths`).
- R3: a branch with a deliberate type error fails the `web` job (CI run observation).
- R4: a branch with a deliberate lint finding fails the `web` job (CI run observation).
- R5, R6: a test reads `package.json` and `biome.json`.
- R7: `npm run lint` in `dashboard/web/ui` exits 0.
- R10: `npm run check` in `dashboard/web/ui` exits 0.
- R8, R9: a test greps `AGENTS.md` for the section and the three commands.

## Constraints

- The UI stays at `dashboard/web/ui`. The move to `dashboard/frontend` is phase `ui-structure`.
- Comments in TypeScript and Svelte follow the repo comment rule for Python.
- The workflow pins a Node version that Vite 8 supports. Plan-phase picks it.

## Non-goals

- Branch protection settings on GitHub. Add the `web` job to the required checks by hand after the first green run.
- Moving or splitting the UI code.
- End-to-end browser tests.
- Changes to the Python CI jobs.

## Invariants

- The lint gate allows zero findings. There is no baseline file.
- The `web` job does not depend on the Python jobs.

## Assumptions

- The pinned Biome version keeps the `html.experimentalFullSupportEnabled` option.
- `svelte-check` keeps covering template type errors and accessibility warnings.
