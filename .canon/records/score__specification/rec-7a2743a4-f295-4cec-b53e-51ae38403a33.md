## Requirements

R1: When a usable artifact store is present, `aff audit` creates at least one `project:evidence-observation` whose technique identifies the audit run.
R2: When a usable artifact store is present and probes run as part of `aff audit`, each probe run that produces a reported outcome is covered by an evidence-observation whose technique identifies probes.
R3: Each audit or probe evidence-observation includes replay metadata sufficient to re-invoke that technique against the same revisions.
R4: The audit and probe recording paths create no `project:evidence-binding`.
R5: `aff trail --technique` can restrict the listed observations to the audit and probe technique ids used above.
R6: When no usable store is present, `aff audit` keeps its pre-phase advisory JSON on stdout and exit semantics.
R7: A pytest accepts only when a seeded subject with a store shows an `aff audit` run leaving trail-visible unbound observations with technique id and replay metadata.

## Acceptance criteria

- Audit/probe runs with a store leave evidence-observations queryable by `aff trail`.
- Those observations have empty or non-earning claim linkage and no binding records from the audit path.
- Without a store, audit JSON/exit matches prior behavior.
- Shared recording helper is used (no second ad-hoc create path for the same envelope).
- Phase pytest for the touched files passes.

## Constraints

- Do not import adaptive-artifacts Python packages from `affidavit/`.
- Bind/unbind verbs are owned by `evidence-bind`; this phase only records unbound.
- Advisory JSON stdout for audit remains; recording is additive.
- Orchestra skill edits are out of scope (`evidence-workflow`).

## Non-goals

- Auto-binding audit or probe observations.
- Replacing audit stdout with store-only output.
- New techniques beyond audit blocks/mutants and probes already in `aff audit`.

## Invariants

- Observation envelope matches `evidence-interface` / bind-era recorder.
- Store writes use the public CLI only.
- Verdict judge meaning is unchanged; only the shared recorder may be factored.

## Assumptions

- `evidence-bind` has landed or its recorder/bind seam is available enough to leave observations unbound by construction.
- Probe declarations remain under `.affidavit/probes.json` (or `--probes`) as today.
