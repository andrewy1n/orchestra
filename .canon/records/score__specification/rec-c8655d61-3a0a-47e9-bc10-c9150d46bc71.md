## Requirements

R1: `orchestra --help` does not offer a `plan` subcommand.
R2: `orchestra --help` does not offer a `run` subcommand.
R3: The README skills list names `plan-phase`.
R4: The README skills list names `execute-phase`.
R5: The README CLI section names `orchestra view` for the plan view.
R6: The README CLI section does not document an `orchestra plan` command.
R7: The README CLI section does not document an `orchestra run` command.

## Acceptance criteria

- R1 and R2: `orchestra --help` output.
- R3 to R7: a read of the README skills list and CLI section.

## Constraints

- `orchestra idea` stays in the composer effort.
- `orchestra verify` and `orchestra handoff` stay as they are.

## Non-goals

- An `orchestra plan` alias of `orchestra view plan`.
- A command that runs `plan-phase` or `execute-phase`.
- Changing the composer CLI.

## Invariants

- Planning and execution are skills. The plan view is `orchestra view plan`.

## Assumptions

- The README is the user-facing command list.
