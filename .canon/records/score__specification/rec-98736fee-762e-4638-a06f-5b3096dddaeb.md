## Requirements

R1: An editable install imports `dashboard` when the repository root is absent from `sys.path`.
R2: An editable install imports `dashboard.web` when the repository root is absent from `sys.path`.
R3: An editable install imports `installer` when the repository root is absent from `sys.path`.
R4: An editable install imports `installer.adapters` when the repository root is absent from `sys.path`.
R5: That install imports `textual`.
R6: That install imports `rich`.
R7: That install imports `fastapi`.
R8: That install imports `uvicorn`.
R9: Importing `orchestra.cli` raises `ModuleNotFoundError` when `orchestra.canon` cannot be imported.
R10: Importing `orchestra.cli` raises `ModuleNotFoundError` when `orchestra.conductor.suite` cannot be imported.
R11: Importing `orchestra.cli` raises `ModuleNotFoundError` when `orchestra.conductor.check` cannot be imported.
R12: `orchestra.sessions.report` does not insert a directory on `sys.path`.
R13: `orchestra.sessions.aggregate` does not insert a directory on `sys.path`.
R14: `orchestra/_scripts` is not a symlink.
R15: Importing `effort_rollup` from `orchestra.score` succeeds without inserting `scripts/` on `sys.path`.
R16: `scripts/test.sh` invokes pytest through `uv run`.
R17: `scripts/test.sh` does not contain `--no-project`.
R18: `scripts/test.sh` does not contain `--with`.
R19: `uv run python -c "import pytest"` succeeds at the repository root.
R20: `uv run python -c "import xdist"` succeeds at the repository root.
R21: `uv run python -c "import httpx"` succeeds at the repository root.
R22: `uv run pip --version` succeeds at the repository root.
R23: `README.md` does not contain `--no-project`.
R24: `AGENTS.md` does not contain `--no-project`.
R25: The fallback suite commands in `orchestra.conductor.suite` do not contain `--with`.
R26: The fallback suite commands in `orchestra.conductor.suite` do not contain `--no-project`.
R27: `installer.matrix` loads `providers.json` from the installed `installer` package.
R28: `tests/test_cli_packaging.py` passes.
R29: `scripts/test.sh` exits 0.

## Acceptance criteria

- R1 to R8 and R27: one test builds an editable install and imports each module with the repository root absent from `sys.path`.
- R9 to R11: unit tests block one import at a time and assert `ModuleNotFoundError`.
- R12 to R15: the session and `effort_rollup` tests pass, importing those modules as package members.
- R16 to R18 and R23 to R26: a scan of `scripts/test.sh`, `README.md`, `AGENTS.md`, and the suite fallback strings.
- R19 to R22: those `uv run` commands at the repository root.
- R28: `tests/test_cli_packaging.py` passes under `uv run`.
- R29: `scripts/test.sh` exits 0.

## Constraints

- `dashboard` and `installer` stay top-level packages in the orchestra wheel (`top-level-dashboard-installer`).
- `installer.paths.source_root` stays the parent of the `installer` package, which is the repository root.
- The package list stays an explicit setuptools `packages` list.
- `textual`, `rich`, `fastapi`, and `uvicorn` are `[project].dependencies`. `textual` keeps the `>=0.80` floor the dashboard launcher already declares.
- `pytest`, `pytest-xdist`, `httpx`, `pip`, `setuptools`, and `wheel` are the `dev` dependency-group. They are not `[project].dependencies`.
- `scripts/build_skills.py` and `scripts/check_orchestra_plugin_names.py` stay in `scripts/`.

## Non-goals

- Shipping `skills/`, `agents/`, or `hosts/` inside the wheel.
- Optional extras for the dashboard stack.
- A `src/` layout.
- Keeping `orchestra/_scripts` or `ORCHESTRA_SCRIPTS`.
- Removing the installer's message when `installer` itself cannot be imported.
- Putting pytest on the runtime dependency list.

## Invariants

- The supported install remains an editable install of this repository.
- `tests/test_boundaries.py` still passes. `dashboard` and `installer` stay outside `orchestra.*`.

## Assumptions

- `uv run` includes the `dev` dependency-group by default.
- `httpx` still satisfies `fastapi.testclient.TestClient`. The FastAPI tests skip today because the suite env has no FastAPI; they will collect once FastAPI is a project dependency.
- `pip`, `setuptools`, and `wheel` stay available because `tests/test_cli_packaging.py` builds an install with `pip`.
