## Requirements

R1: The built wheel contains `dashboard/frontend/dist/index.html`.
R2: The release build runs `npm run build` before it builds the wheel.
R3: `dashboard/frontend/dist` stays gitignored.
R4: With the wheel installed in a clean environment, `GET /` returns the UI index.
R5: The `ci` effort's wheel smoke job asserts R4.
R6: A Playwright test starts the server on a seeded store and loads the page in headless Chromium.
R7: The Playwright test asserts that a seeded effort name is visible on the page.
R8: A CI job installs the browser and runs the Playwright test.
R9: A source checkout without `dist` shows a message that names the build command.
R10: Full CI passes on a pushed branch.

## Acceptance criteria

- R1, R2, R3, R9: a test checks the wheel contents, the build script, `.gitignore`, and the message.
- R4, R5: the `ci` wheel smoke job passes with the added check.
- R6, R7, R8: the Playwright test passes locally and in CI.
- R10: a CI run observation.

## Constraints

- Phase `wheel-smoke` of the `ci` effort is done before this phase starts.
- Wheel builds do not require Node. The release job builds `dist` first.
- Playwright is a dev dependency of `dashboard/frontend`.

## Non-goals

- Publishing the wheel.
- A build hook inside setuptools.
- Visual regression tests.

## Invariants

- A source checkout works for Python development without Node.
- `dist` is never committed.

## Assumptions

- GitHub-hosted runners can install headless Chromium with Playwright.
- The seeded store fixture is reusable from the Python tests.
