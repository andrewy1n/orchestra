## Constraints

- The split stays inside the `dashboard` package.
- `dashboard/model.py` is replaced by the `dashboard/model/` package. There is no `dashboard/model.py` beside that package.
- `DashboardApp` stays in `dashboard/app.py`. Widgets that belong to a moved screen move with that screen.

## Non-goals

- A change to what the Textual app or the web launcher shows.
- Colocating a Textual screen in the same module as its row types.
- Splitting `dashboard/web/` in this phase.
- A line-count target.

## Invariants

- Modules under `dashboard/model/` do not import Textual or Rich.
- Existing `import dashboard.model` and `from dashboard.model import ...` sites keep working through the package facade.
