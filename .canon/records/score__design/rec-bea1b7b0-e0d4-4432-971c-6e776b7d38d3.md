## Architecture

One file, `.github/workflows/ci.yml`, with six jobs on `ubuntu-latest`. No job depends on another.

- `checks`: sync, then four named steps: skill sync (`scripts/build_skills.py --check`), plugin names (`scripts/check_orchestra_plugin_names.py`), `canon validate`, and `ruff check`.
- `test-canon`, `test-tuner`, `test-orchestra`: one `uv run pytest -n auto` pass each, with the same selection as `scripts/test.sh`.
- `test-tmux`: installs tmux with apt, then runs the `tmux` marker serially.
- `types`: runs pinned mypy on `orchestra --ignore-missing-imports` with `continue-on-error: true`.

Each job checks out the repo, sets up uv with the cache on and Python 3.10, and runs `uv sync --locked --group dev`. The workflow-level `concurrency` group is keyed on the workflow and ref with `cancel-in-progress: true`. Each job sets `timeout-minutes`.

`pyproject.toml` gains `[tool.ruff.lint] select = ["F"]`. The ruff version is pinned in the workflow, run through `uvx`, so `uv.lock` does not change. The phase also applies the ruff autofix (33 fixes) and fixes the 2 remaining F841 errors by hand.

## Interfaces

- Triggers: push to `main` and `phase/**`, `pull_request`, `workflow_dispatch`.
- Job names are stable (`checks`, `test-canon`, `test-tuner`, `test-orchestra`, `test-tmux`, `types`). The `repo-hygiene` idea uses them as required status checks.
- Reads `uv.lock`, `pyproject.toml`, `scripts/`, and `.canon/`. Writes nothing.

## Invariants

- `tuner-verdict.yml` is unchanged.
- `scripts/test.sh` passes locally.
- A failing step in a blocking job fails the run. Only `types` may fail without failing the run.

## Assumptions

- `wheel-contents` has merged: the `dev` dependency-group exists and `uv sync --locked --group dev` resolves on Python 3.10.
- The repository is public.
- The suite passes on a clean checkout under Python 3.10, and tmux tests run on the hosted runner.

## Tradeoffs

- Pytest arguments appear in YAML and in `scripts/test.sh`. This buys separate job logs and parallel passes.
- Six jobs each run `uv sync`. The uv cache keeps the cost low.
- `F` only gives a small lint signal now. It keeps the diff small.

## Risks

- The suite may fail on a clean runner (missing git identity, home directory, or TTY). The first CI run shows it. Fix in the execute step.
- tmux tests may be flaky without a TTY. If they are, the job reports it, and a later phase decides.
- The ruff autofix touches many files. Running it after the in-flight phases merge limits conflicts.
- The pinned ruff and mypy versions need a manual bump.
