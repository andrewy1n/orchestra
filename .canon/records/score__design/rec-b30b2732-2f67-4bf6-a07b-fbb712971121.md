## Architecture

Remove the home `data-side-journal` entry list from `App.svelte`. Add a `journal` hash route (e.g. `#/journal/{effort}`) as a full-page or overlay shell that fetches `journal?effort=…` and renders open/earlier + filter. For repair/evaluate only, render a single teaser control on the side rail linking to that route.

## Interfaces

- Extend `RouteName` / `parseRoute` with `journal`.
- Helpers: `journalHref(effort)`, filter predicate over `JournalItem`.
- Teaser copy uses `journal.open.length` when the journal payload is loaded; if not yet loaded, show "Journal" without a count or load on effort select as today without listing rows.
- Tests update/remove R12 side-list expectations; add journal-screen tests.

## Decisions

- `side-rail-journal-home`
- `side-rail-journal-screen`
- `side-rail-journal-kinds`

## Invariants

- Needs you and Backlog panels remain.
- Record overlay behavior for journal ids is unchanged.

## Assumptions

- Existing `orderedJournal` and journal fetch-on-effort-select can feed the teaser count without listing rows.

## Tradeoffs

- One extra navigation hop to read journal history, in exchange for a calmer home rail.

## Risks

- Acceptance tests that required `data-side-journal` rows must be rewritten; old R12 side-list oracle is intentionally superseded.
