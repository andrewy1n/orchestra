## Architecture

- `orchestra/composer/idea.py`: capture logic. It slugifies the title, checks for a subject collision, builds the body, and creates the record through the canon `Project` API. It imports only canon.
- `orchestra/cli.py` adds the `idea` subcommand and calls the capture logic. The wiring is top-level, as composer cannot import top-level modules.
- `orchestra/views.py`: `View` gains `group_default`. A `ROADMAP` view has an area role (`composer:area`, active) and an idea role (`composer:idea`, active, status open or promoted), grouped by `area` with default `untriaged`. `VIEWS` and the `orchestra view` choices gain `roadmap`.
- `skills/triage-ideas/SKILL.md`: walks the untriaged ideas, offers per idea an area, a new area, or dismiss, and writes the user's choice. It ends by naming `engage` for promotion.

## Interfaces

- `orchestra idea "<title>" [--area A] [--effort E] [--source S] [--body-file F]`.
- `orchestra view roadmap [--effort E]`.
- `View(group_default: str | None = None)`.
- Skill: `triage-ideas`, using `canon list`, `canon create --type composer:area`, `canon supersede --type composer:idea`.

## Decisions

- `roadmap-group-default`: extend the view engine.
- `idea-command-shape`: title argument, derived slug.
- Earlier: `composer-area-meaning`, `composer-idea-lifecycle`.

## Invariants

- One record or none per `orchestra idea` call.
- composer imports only canon and score.
- Views stay derived; the engine change does not alter existing output.

## Assumptions

- `backlog-to-idea` has merged. Ideas are `composer:idea` everywhere.
- Canon validates the area and effort refs, so unknown refs fail before any write lands.

## Tradeoffs

- The engine change touches code shared by every view for the sake of one view.
- A derived slug makes capture fast and makes the subject depend on wording.
- Triage assigns areas and dismisses only. Promotion waits for phase `engage-from-idea`, so a triaged idea cannot yet become an effort.

## Risks

- A long or non-ASCII title produces a bad slug. Plan-phase sets the length cap and the fallback.
- Two sessions capturing the same title at once. The second create fails on the collision, which is the intended result.
- `orchestra/views.py` and `tests/test_views.py` are shared with phase `backlog-to-idea`. Run the phases in order.
