## Architecture

1. Extend `aff audit` with a probe runner: load declared probes, execute at base and head (worktrees), compare.
2. Default coarse CLI comparison; allow function probes where the spike did.
3. Each reported diff must be clearable by claim cite metadata or left for a human.
4. Fixture recreates the revision-on-tdd relaxation finding.

## Interfaces

- Probe declaration format (plan-phase)
- JSON report entries for unclaimed diffs
- Same CLI family as phase-end-evidence

## Decisions

- `audit-probes`: declared probes + CLI default; not auto-discover; not CLI-only without declarations.
- Campaign milestone: phase-end reviewer runs here.

## Invariants

- Unclaimed ⇒ reported; claimed ⇒ not reported.

## Assumptions

- phase-end-evidence landed the audit package layout.

## Tradeoffs

- Authoring probes vs discovery noise.
- Coarse CLI may miss deep API deltas; function probes remain available.

## Risks

- Nondeterministic probes. Mitigation: require deterministic fixtures in tests.
