# Agent slop standards

## Scope

Repo rules and automated checks that keep agent-written code clean. Covers
type and lint gates in CI, dead-code and dependency checks, the written coding
standard in AGENTS.md, protection of the lint configuration, and the cleanup
of existing modules that fail the new gates.
