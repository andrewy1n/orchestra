## Problem

The wheel packages `_scripts/` through a symlink and declares packages by hand. A packaging break does not show up in the source-tree tests.

## Approach

Not yet scoped. Build the wheel in CI, install it into a clean environment, and run the installed entry points. Wait for the `package-layout` effort's `wheel-contents` phase to settle the wheel shape first. Decide at plan-phase.

## Exit criteria

- A CI job builds and installs the wheel in a clean environment, and `orchestra --help` and `canon --help` exit 0 from the install (observed GitHub Actions run).
- Every acceptance passes (decide at plan-phase).
