## Problem

CI runs no Node tooling. A broken Svelte or TypeScript change merges unchecked. The repo has no lint or format standard for TypeScript and Svelte, and `AGENTS.md` has no section for them.

## Approach

Add one `web` CI job that always runs: `npm ci`, `npm run lint`, `npm run check`, `npm test`, `npm run build` in `dashboard/web/ui` (decision `web-ci-job-shape`). Add Biome with full Svelte support at an exact version, configured by `biome.json` (decision `ts-lint-tool`). Fix the existing findings and keep the gate at zero findings (decision `lint-findings-policy`). Add a TypeScript and Svelte section to `AGENTS.md`. The UI stays at `dashboard/web/ui`. Plan-phase picks the Node version.

## Exit criteria

- The CI `web` job runs `npm ci`, `npm run lint`, `npm run check`, `npm test`, and `npm run build` in order, with no path filter (test that parses `.github/workflows/ci.yml`).
- A branch with a deliberate type error fails the `web` job, and a branch with a deliberate lint finding fails it (observation in two CI runs).
- `npm run lint` exits 0 on the tree with no findings (command).
- `AGENTS.md` has a TypeScript and Svelte section that names the three commands (test that greps `AGENTS.md`).
- Every acceptance passes, and the `web` job passes on a pushed branch (integration check through the real entry point).

## Proof

kind: commands. A human looks at the green `web` job in a CI run and at the two failing runs for the deliberate type error and lint finding.
