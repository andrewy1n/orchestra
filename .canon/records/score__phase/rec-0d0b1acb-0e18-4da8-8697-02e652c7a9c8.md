## Problem

Phase Overview does not show how tasks depend on each other, so wave order and blockers are hard to see.

## Approach

On phase Overview, when a phase has three or more tasks, show a wave-lane dependency graph (columns by wave, edges from depends_on). Enrich phase/snapshot task JSON with depends_on task ids. Keep a task list or wave strip for scanning. Omit the graph for two or fewer tasks. Decisions: `task-graph-layout`, `task-graph-edge-data`, `task-graph-tiny-skip`.

## Exit criteria

- Overview shows a wave-lane graph for ≥3 tasks with status-aware nodes and depends_on edges.
- Node click opens the task overlay.
- List/strip remains; graph omitted for ≤2 tasks.
- Task JSON includes depends_on ids; unit/UI (and model) tests pass; manual multi-wave look passes.

## Proof

kind: demo

A human opens a multi-wave phase Overview and sees lanes and edges that match task dependencies, then opens a task from a node.
