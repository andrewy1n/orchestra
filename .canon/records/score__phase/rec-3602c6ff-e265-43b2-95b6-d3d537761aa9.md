## Problem

The monorepo plan lists `orchestra plan` and `orchestra run` as task verbs. The CLI does not implement them. `orchestra view plan` prints the plan. `plan-phase` and `execute-phase` are the skills. `orchestra idea` is the composer effort.

## Approach

Leave the verbs as skills (`cli-verbs-stay-skills`). Do not add `orchestra plan` or `orchestra run`. The plan view stays `orchestra view plan`. `orchestra idea` stays in the composer effort. Confirm `orchestra --help` and the README. Edit the README only where it contradicts that.

## Exit criteria

- `orchestra --help` offers neither `plan` nor `run`.
- The README names `plan-phase` and `execute-phase`, points the plan view at `orchestra view`, and does not document `orchestra plan` or `orchestra run`.
- Every acceptance passes.
