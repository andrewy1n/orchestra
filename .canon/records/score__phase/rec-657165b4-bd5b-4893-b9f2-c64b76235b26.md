## Problem

The composer pieces prove themselves only together: an idea is captured, triaged, shown on the roadmap and turned into an effort.

## Approach

Chosen: one test module drives the installed `orchestra` and `canon` entry points against a temporary store (`e2e-engage-coverage`). It runs `orchestra idea`, replays the documented triage, effort and promote `canon` calls, and checks `orchestra view roadmap` before and after promotion.

Session shape: one sitting. Waves: `composer-e2e-test` (subagent, Cursor worker); then `verify-composer-e2e`.

Human stops: plan review (approved in the user's auto-execute request). Push is not a stop. Review runs once; findings are fixed with tests.

Collision notes: the phase adds one test file and touches no product code. The suite gate is advisory (set by the user in `.canon/config.json`).

## Exit criteria

- `tests/test_composer_e2e.py` passes through the installed `orchestra` entry point.
- `canon validate` on the test store reports no errors.
- `scripts/test.sh` passes.
