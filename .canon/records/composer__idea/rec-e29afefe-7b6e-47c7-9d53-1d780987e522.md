orchestra check records failing_node_ids by splitting pytest summary lines at whitespace, so a parametrized node id that contains a space is cut. Example: tests/test_effort_brief.py::test_r3_...[Success measure] was stored as ...[Success. Freezing those ids into an acceptance writes an unrunnable verify_command. Parse the node id from the full FAILED line up to ' - ', or read it from a junit report. Found while freezing the effort-brief oracles; the parent corrected the ids by hand.
