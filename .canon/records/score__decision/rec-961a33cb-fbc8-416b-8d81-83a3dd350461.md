## Rationale

Affidavit packaging phase pyproject-pypi needs adaptive-artifacts installable via
`uv tool install git+…` without a sibling checkout. That requires a root
pyproject.toml, an installable import package (recommended
`src/adaptive_artifacts/`), and a console-script entry point named
`adaptive-artifacts`. Keep thin shims at `bin/adaptive-artifacts` and
`tools/artifacts.py` so plugin PATH installs and
`ADAPTIVE_ARTIFACTS_ROOT` discovery keep working. Do not publish to PyPI
in this change. Apply only after this decision is approved; do not merge
packaging commits mid-task without that approval.

## Counter-argument

Leaving the tools/ + sys.path layout alone avoids a large move, but then
git+ tool install cannot work and affidavit stays blocked on a checkout.
