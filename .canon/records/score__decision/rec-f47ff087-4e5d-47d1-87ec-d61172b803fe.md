## Rationale

This phase records the runner template and executes it. It does not hash the template or require a signed amendment when the template changes. `frozen-environment` already owns that check, together with support files and the no-assert lint. Putting the bytes in the manifest now gives that phase something to freeze.

## Counter-argument

Hashing the template in this phase would close the hole the template opens. An agent can set `runner` to a command that writes a passing JUnit file, and verdict will accept it until `frozen-environment` ships. The amendment check for oracle hashes already exists and could cover the template.
