## Rationale

`aff` must not import adaptive-artifacts Python modules (existing testing and package boundary). Recording and listing observations goes through the public `adaptive-artifacts` CLI as a subprocess, same pattern as the test suite. Claims remain git blobs; only the run trail is store-backed.

## Counter-argument

Teaching orchestra alone to capture stdout into the store would keep `aff` store-blind, but then trail/recheck live outside the evidence CLI and agents must use two tools for one interface. Subprocess CLI keeps verbs on `aff` while preserving the no-import rule.
