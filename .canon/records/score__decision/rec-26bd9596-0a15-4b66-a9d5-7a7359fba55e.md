## Rationale

CI calls the `uv run pytest` commands directly as parallel jobs, one per pass: canon, tuner, orchestra tree, and tmux. Each pass gets its own job name and log. `-n auto` uses the runner cores. The user chose to remove `scripts/test.sh` in this phase. `README.md` lists the same four commands for local runs. `CLAUDE.md` and `AGENTS.md` point to them. The phase suite command in `.canon/config.json` chains them. One selection, three places, no wrapper script.

## Counter-argument

A script or a pass selector keeps one source of truth for the pytest arguments. Copying them into YAML, the README and `config.json` lets the copies drift, for example when `component-tests` adds ignores. The drift risk is real. The only mitigation is that the commands are short and the structure test pins the YAML copy.
