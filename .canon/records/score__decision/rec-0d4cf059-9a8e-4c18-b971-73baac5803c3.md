## Rationale

Rule set `F` flags real defects: unused imports and variables, f-strings without placeholders. It reports 35 errors, and 33 have an autofix. Two need a hand fix. The set is narrow, so the blocking job stays low-noise and the phase touches few files. The user chose it.

## Counter-argument

`E4,E7,E9,F` also catches ambiguous names (E741) and lambda assignment (E731), and costs only 7 more manual fixes. A wider set from day one avoids a later widening phase. The cost is edits to code unrelated to CI, which raises merge conflicts with in-flight phases.
