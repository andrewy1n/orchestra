## Rationale

Two ways to install the same bindings double the maintenance and the docs. The user chose to remove `dashboard/tmux.conf` so the script is the only route. Non-TPM users run the script with `run-shell`.

## Counter-argument

Users who already follow the README have `source-file ~/se-workflow/dashboard/tmux.conf` in their config. Removing the file breaks their tmux startup with an error until they edit the line. A short-lived fallback conf that sources the script would avoid that break.
