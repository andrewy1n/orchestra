## Rationale

FastAPI is the HTTP layer in front of `dashboard.model` and the existing dismiss and backlog functions. Route functions, request bodies, and TestClient tests are how the write API stays explicit. Uvicorn serves it. The Svelte production build is static files on that same app. Script dependencies stay on the web launcher, the way Textual stays on the terminal launcher, and the installed `orchestra` package does not gain them.

## Counter-argument

The spike's standard-library server already serves the GET routes in a few hundred lines, and Starlette alone would mount static files and test routes without FastAPI's schema layer. This API has one client, which we write, so generated OpenAPI is a thin benefit against a new runtime dependency the dashboard has avoided.
