## Rationale

check.py, close_batch.py, aa.py, aa_resolve.py, policy.py, and affidavit.tmux exist to write workflow records. Moving them to orchestra leaves affidavit with git as its only state and no dependency on adaptive-artifacts. Orchestra keeps its close path and calls aff verdict for the gate answer.

## Counter-argument

Keeping them here as an optional add-on for the store avoids churning orchestra and keeps the runner-recorded check-run next to the code that defines evidence. Orchestra then has to carry and test the forgery fix (close-batch-store-verify) itself.
