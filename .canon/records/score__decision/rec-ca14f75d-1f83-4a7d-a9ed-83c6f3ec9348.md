## Rationale

The wheel already lists packages explicitly in `pyproject.toml`. Extending that list with `dashboard`, `dashboard.web`, `installer`, and `installer.adapters` matches the recorded placement: those import names stay top-level, and `installer.paths.source_root` stays the parent of the `installer` package. Required dependencies make the editable install provide `textual`, `rich`, `fastapi`, and `uvicorn` without an extra flag. Session code becomes `orchestra.sessions`, and `effort_rollup` becomes `orchestra.score.effort_rollup`, so `orchestra.sessions` stops inserting `scripts/` on `sys.path` and `orchestra/_scripts` can be deleted. `scripts/build_skills.py` and `scripts/check_orchestra_plugin_names.py` are repo tools, so they stay in `scripts/`.

## Counter-argument

Optional extras would leave a bare `uv tool install --editable` free of Textual and FastAPI. The dashboard launchers already declare those libraries in PEP 723 headers, and a documented install command could include the extras. That keeps canon-only use lighter. It also leaves the default install unable to import the dashboard, which is the failure this phase exists to close.
