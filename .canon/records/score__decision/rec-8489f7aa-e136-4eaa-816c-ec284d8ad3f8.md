## Rationale

shadcn-svelte copies source files into the repo and builds on the existing Tailwind 4 build. It gives tables, dialogs, tabs, and a command palette that the team owns.

## Counter-argument

daisyUI is CSS classes only and needs less glue code. shadcn-svelte adds many files and a larger upgrade surface.
