## Rationale

`plan-phase` already refuses plan review without `## Proof`, so a skill gate at plan review and at phase close follows an existing pattern. It fixes the real gap, an uncovered or phantom requirement id reaching execution, with a small change: one command and two skill edits. An engine gate on close-batch would couple a per-task close to a phase-wide check.

## Counter-argument

`evidence-authority` moved gates from skill prose into the engine because prose is forgeable. An agent can skip the `analyze` step and the plan still looks fine. The engine gate (close-batch or the phase transition refusing on errors) is the only version an agent cannot skip. If the skill gates get skipped in practice, that is the follow-up.
