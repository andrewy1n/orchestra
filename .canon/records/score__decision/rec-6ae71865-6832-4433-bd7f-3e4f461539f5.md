## Rationale

The gate allows zero findings. A clean tree needs no baseline file to maintain. The UI has about 90 findings today, mostly one style rule, so the cost of cleaning is small.

## Counter-argument

A committed baseline, like the basedpyright baseline, would block only new findings and is faster now. The UI will be restructured in phase `ui-structure`, so cleaning code that will move is partly wasted work.
