## Rationale

An opt-in flag keeps every existing verdict caller and fixture unchanged while a CI or orchestra caller turns the guarantee on. Failure reasons are fixed strings so tests and callers can tell ordering, paths, and signer apart.

## Counter-argument

Default-on would protect callers who forget the flag. It would also fail every history where the oracle and the first implementation share a commit, which includes all current fixtures, so it needs a migration this phase does not own.
