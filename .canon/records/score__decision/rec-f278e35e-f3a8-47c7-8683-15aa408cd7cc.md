## Rationale

CI runs Python 3.10 only. `pyproject.toml` sets `requires-python >=3.10`, so the floor is the version most likely to break. The `python-matrix` idea widens to 3.10 through 3.13 later.

## Counter-argument

Python 3.12 matches `tuner-verdict.yml` and the `.venv` used locally is newer than 3.10. A 3.12 run reflects what developers run. A break on newer Python reaches users unseen until the matrix lands.
