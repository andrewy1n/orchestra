## Rationale

The depth stops at four levels, which was the user's worry. The human-gate write buttons in the needs and backlog views stay in their modals, so the write surface does not move in a navigation phase. The existing overlay tests for those views stay valid.

## Counter-argument

Pages for the leaf views would make every level the same and give each record a shareable URL and a breadcrumb. Modals over a page are a second navigation model that readers must learn.
