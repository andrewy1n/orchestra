## Rationale

Committed default lets a repo pin shared policy (this dogfood repo pins local). A gitignored local override and env var cover machine-specific and one-shot needs without forcing every preference into git.

## Counter-argument

Machine-local only avoids committing policy, but then every clone of se-workflow would keep hitting an empty home store until each developer set a file by hand.
