## Rationale

The dashboard has its own dependencies (Textual, run through uv) and its own tests. It does not belong with the session-analysis scripts. A top-level package makes that boundary clear. The user chose this layout.

## Counter-argument

Keeping the code in scripts/ needs no change to sync-plugin.sh, the tmux conf, the README or any user status-line config. A move touches all of them and risks a broken install if one path is missed. Thin wrappers in scripts/ would cut that risk, but they leave two entry points to maintain.
