## Rationale

The evidence interface only helps if every technique writes the same observation envelope. Audit and probes already run as first-class `aff` techniques; recording unbound observations when a store is usable (same optional-store rule as verdict) makes the trail complete without turning advisory JSON into acceptance. Binding stays an explicit later act.

## Counter-argument

Opt-in `--record` would avoid surprising store writes on one-off audit runs. That safety costs default trail completeness: agents will omit the flag, and handoff will keep seeing stdout-only audit again — the gap this phase closes.
