## Rationale

Parallel agents and worktrees on one machine share one DB file, so writes need concurrency control, not merging. This also removes the stale-worktree store. The DB stays out of git, and `canon export` covers backup and review.

## Counter-argument

Many store copies with a merge rule, as git-bug does with Lamport clocks, would allow a second machine later. It costs a merge implementation that no current need justifies.
