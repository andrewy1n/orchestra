## Rationale

Python that already lives in these packages should call functions and get values or exceptions back. Agents, humans, and hooks are not inside the package, so they keep calling `adaptive-artifacts`, `aff`, and `orchestra` by name. A lazy import plus a declared optional dependency keeps `orchestra --help` working when affidavit is absent, which was the failure that made close-batch shell out.

## Counter-argument

The evidence-authority phase chose a CLI-only close path because a deferred `import affidavit` crashed an installed `orchestra --help` and because checkout path probing was a bad dependency. Staying on subprocess also lets each repo run without declaring the others. The cost is three store clients and exit-code protocols. This choice keeps the commands for skills and drops the subprocess only for Python callers.
