## Rationale

The workflow runs on push to `main` and `phase/**`, on `pull_request`, and on `workflow_dispatch`. This matches `tuner-verdict.yml`. A branch with a pull request runs once, not twice. Phase branches get a run before a pull request opens.

## Counter-argument

Push on all branches plus `pull_request` matches the effort goal ("every push") word for word. A feature branch pushed without a pull request gets no run under the chosen triggers. The cost of the all-branch option is a double run per pull request branch.
