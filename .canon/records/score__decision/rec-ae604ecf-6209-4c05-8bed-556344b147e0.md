## Context

Requirement R8 says init promotes an idea with its effort only. The design says an idea carries a phase ref when a phase exists. init creates placeholder phases, not a chosen phase.

## Options

- Keep R8: init sets the effort and leaves the phase ref empty.
- Have init set the first placeholder phase as the phase ref.

## Rationale

Keep R8. An empty phase ref is accurate until someone chooses a phase. A placeholder phase is a guess and can change.

## Counter-argument

A phase ref set at init means an idea is never missing one. But it would point at a phase nobody chose.

## Consequence

Ideas promoted through init carry an effort and no phase ref until a phase is chosen. No code changes.
