## Rationale

Lint catches agent tricks that hash equality cannot see. Keeping it advisory-or-separate from hash fails preserves a clear amendment path for deliberate support changes.

## Counter-argument

Failing the verdict on every new skip would be stricter. It also blocks legitimate skip cleanup unless every skip rides an amendment, which is heavier than the phase exit needs.
