## Rationale

One small command keeps a status line available for any status bar or Claude Code status line. It reuses the snapshot loader. Dropping the tmux flag and the stdin JSON mode removes code that only served the tmux plugin.

## Counter-argument

Dropping the status line completely removes the last tmux-era code and one command to maintain. A status line that one person uses may not justify the upkeep.
