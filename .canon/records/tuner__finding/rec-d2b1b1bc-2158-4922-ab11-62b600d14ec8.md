## Evidence

Observed on GitHub Actions after pushing three branches cut from main:
- phase/node-ci-type-error (run 40981149535): the web job fails at "Run npm run check" (R3).
- phase/node-ci-lint-finding (run 40981149551): the web job fails at "Run npm run lint" (R4).
- phase/node-ci-green (run 40982092037, commit 32a04669c): every job passes, including the web job.

The first green run failed for two reasons that local runs had missed. The web job's unused setup-uv step failed in its cache post step, and tests/test_web_gate.py r3 and r4 failed in test-orchestra because the runner has no node_modules. Commit 32a04669c removes the step and makes the tests install node_modules in their copy.

## Consequence

R3 and R4 are observed in CI.

## Follow-up

Add the web job to the required checks on GitHub. Delete the three test branches when no longer needed.
